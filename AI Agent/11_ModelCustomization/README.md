# 1. 模块定位

当 Prompt 与 RAG 都不够用时，才考虑微调。本模块讲清"何时该微调、怎么微调、怎么部署私有模型"，并给出 Java 侧的接入方式。

## 1.1 解决什么问题

本模块聚焦三类问题：

- 决策：Prompt、RAG、微调三者的边界在哪里。
- 实施：如何准备数据、选择微调方法、训练与对齐。
- 落地：如何部署、量化并接入业务系统。

## 1.2 边界与取舍

| 需求 | 首选方案 | 说明 |
|------|----------|------|
| 补充事实知识 | RAG | 知识可更新、可溯源 |
| 改变输出风格/格式 | Prompt / 微调 | 微调更稳定 |
| 提升领域能力 | 微调 | 需高质量数据 |
| 降低延迟/成本 | 量化 + 自部署 | 见量化章节 |

微调是"最后手段"，不是默认选项。

## 1.3 与其他模块的关系

```
2_LLM ──┐
5_RAG ──┼──→ 11_ModelCustomization ──→ 14_ProductionEngineering
12_Evaluation ──┘                    └─→ 16_Applications
```

上游提供原理、对比与评估方法，下游消费自部署模型与评测结论。

## 1.4 适用读者

- 需要自建私有模型的算法工程师。
- 需要在 Java 服务中接入自部署模型的后端工程师。
- 需要评估微调投入产出比的技术负责人。

# 5. 核心概念地图

## 5.1 微调方法谱系

```
全量微调（Full FT）
├─ 成本高、显存大
参数高效微调（PEFT）
├─ LoRA / QLoRA
├─ Adapter
├─ Prefix / Prompt Tuning
└─ IA3
对齐（Alignment）
├─ RLHF
├─ DPO
└─ GRPO
```

### 5.1.1 全量微调

更新全部参数，效果上限高但显存与成本大。

### 5.1.2 参数高效微调

只训练少量新增参数，代表是 LoRA / QLoRA。

### 5.1.3 偏好对齐

用偏好数据让模型更符合人类偏好，代表是 RLHF / DPO / GRPO。

## 5.2 部署与量化

| 方案 | 适用 | 接口 |
|------|------|------|
| vLLM | 高并发 GPU 服务 | OpenAI 兼容 |
| Ollama | 本地/边缘 | OpenAI 兼容 |
| llama.cpp | CPU / Mac | 本地进程 |

## 5.3 评估闭环

```
微调 → 评估（目标/通用/安全/格式） → 归因 → 再训练
```

评估是闭环的终点与下一轮的起点，详见 `11_model_evaluation.md`。

# 6. 常见误区

## 6.1 决策误区

### 6.1.1 顺序误区

未尝试 Prompt 与 RAG 就直接微调，往往投入大、收益小。

### 6.1.2 目标误区

把知识注入当成微调目标，正确做法是用 RAG 补充知识。

| 误区 | 纠正 |
|------|------|
| 一上来就微调 | 先试 Prompt 与 RAG |
| 用微调补知识 | 知识用 RAG |
| 追求大而全 | 聚焦单一目标能力 |

## 6.2 实施误区

| 误区 | 纠正 |
|------|------|
| 数据越多越好 | 质量优先于数量 |
| 只看训练损失 | 必须独立评测 |
| 不对比基座 | 无对比无结论 |
| 忽略安全回归 | 微调后重测安全 |

# 7. 关键知识点速览

## 7.1 核心结论

- 优先级：Prompt > RAG > 微调，微调是最后手段。
- LoRA/QLoRA 让消费级显卡也能微调。
- 数据质量决定微调上限，而非数量。
- 微调改变"风格与能力"，RAG 补充"知识"。
- 私有化部署首选 vLLM / Ollama，接口保持 OpenAI 兼容。

## 7.2 一句话总结

先判断要不要微调，再保证数据质量，最后用独立评测证明它比基座更好，量化部署后持续监控。

## 7.3 术语速查

| 术语 | 全称 | 含义 |
|------|------|------|
| SFT | Supervised Fine-Tuning | 指令微调 |
| PEFT | Parameter-Efficient Fine-Tuning | 参数高效微调 |
| LoRA | Low-Rank Adaptation | 低秩适配 |
| QLoRA | Quantized LoRA | 量化 + LoRA |
| RLHF | RL from Human Feedback | 人类反馈强化学习 |
| DPO | Direct Preference Optimization | 直接偏好优化 |
| GRPO | Group Relative Policy Optimization | 组相对策略优化 |
| PTQ | Post-Training Quantization | 训练后量化 |
