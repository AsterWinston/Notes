# 1. 什么是缩放定律

## 1.1 定义与直觉

**结论先行**：缩放定律（Scaling Law）描述模型损失与参数量、数据量、算力之间的幂律关系，让"堆规模"从赌博变成可预测的工程。

### 1.1.1 定义

**Scaling Law** = 模型性能与**参数量、数据量、算力**之间的幂律关系。

```
Loss ∝ N^(-α) + D^(-β) + ...

N：参数量
D：数据量
C：算力
```

> 它让"堆规模"变成可预测的工程，而非赌博。

### 1.1.2 为什么重要

| 价值 | 说明 |
|------|------|
| 可预测 | 小实验外推大模型效果 |
| 可规划 | 提前分配算力与数据 |
| 可决策 | 选规模、定预算 |
| 降风险 | 避免盲目堆参数 |

## 1.2 幂律形式

### 1.2.1 公式

```
L(N) = (Nc / N)^α        （固定数据，只增参数）
L(D) = (Dc / D)^β        （固定参数，只增数据）
L(N, D) = E + A·N^(-α) + B·D^(-β)
```

| 符号 | 含义 |
|------|------|
| N | 非嵌入参数量 |
| D | 训练 token 数 |
| E | 不可约损失（下界） |
| α, β | 幂指数 |

### 1.2.2 对数坐标直觉

```
log Loss
  │ ╲
  │  ╲___
  │      ╲____
  │           ╲____
  └──────────────────▶ log N
```

幂律在双对数坐标下近似为一条直线，斜率即 -α。

### 1.2.3 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 外推过头 | 小规模拟合不适用 | 限定范围 |
| 忽略下界 E | 以为可到 0 | 预留不可约损失 |
| 指标单一 | loss 不等于任务效果 | 结合下游评测 |

## 1.3 三条缩放轴

### 1.3.1 三条轴

| 轴 | 变量 | 幂律 | 说明 |
|----|------|------|------|
| 模型 | N | N^(-α) | 参数量 |
| 数据 | D | D^(-β) | token 数 |
| 算力 | C | C^(-γ) | 训练预算 |

### 1.3.2 联合约束

```
C ≈ 6 N D
→ 给定 C，N 与 D 存在权衡曲线
```

> 缩放定律的核心问题：在算力约束下，N 与 D 如何分配最省。

# 2. Kaplan 定律（2020）

## 2.1 核心结论

**结论先行**：Kaplan 等人发现，给定算力预算应优先扩大参数量，数据可以相对少。

### 2.1.1 结论

```
优先扩大参数量，数据可以相对少

结论：给定算力预算，大部分用于增大模型
```

### 2.1.2 曲线图

```
Loss
 │ ╲
 │  ╲___
 │      ╲____
 │           ╲____
 └──────────────────▶ 参数量（对数）
```

## 2.2 解读与边界

### 2.2.1 预算分配

| 策略 | 说明 |
|------|------|
| 优先参数 | 大部分算力给模型 |
| 数据从简 | 数据量相对小 |
| 依据 | 幂律指数差异 |

### 2.2.2 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 过度参数化 | 训练不足 | 参考 Chinchilla 修正 |
| 忽视数据 | 数据瓶颈 | 补足 token |
| 学习率未适配 | 结论偏差 | 同协议对比 |

> Kaplan 的结论后来被 Chinchilla 修正，但方法学奠基意义重大。

## 2.3 方法学贡献

### 2.3.1 贡献

| 贡献 | 说明 |
|------|------|
| 幂律拟合 | 用少量实验预测大模型 |
| 预算意识 | 首次量化算力分配 |
| 可复现 | 统一训练协议 |

### 2.3.2 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 协议不同 | 结论不可比 | 固定配置 |
| 数据未修正 | 低估数据价值 | 结合 Chinchilla |

# 3. Chinchilla 定律（2022）

## 3.1 核心结论

**结论先行**：Chinchilla 指出参数量与数据量应等比例扩大，最优比例约为 20 token/参数。

### 3.1.1 等比结论

```
推翻 Kaplan：参数量与数据量应等比例扩大

结论：约 20 token / 参数
```

### 3.1.2 公式

```
给定算力 C ≈ 6ND，最优时 N ∝ D
即 D* ≈ 20 · N
```

| 项 | 含义 |
|----|------|
| C | 训练算力 |
| N | 参数量 |
| D | 训练 token 数 |
| 20 | 经验最优比例 |

## 3.2 数据对比

### 3.2.1 token/参数表

| 模型 | 参数量 | 训练 token | token/参数 |
|------|:------:|:----------:|:----------:|
| GPT-3 | 175B | 300B | 1.7 |
| Chinchilla | 70B | 1.4T | 20 |
| LLaMA 2 | 70B | 2T | 28 |
| LLaMA 3 | 70B | 15T | 214 |

### 3.2.2 解读

> Chinchilla 表明：**很多大模型训练不足**（数据不够）。

```
GPT-3：1.7 token/参数 → 严重欠训练
Chinchilla：20 token/参数 → 算力最优
LLaMA 3：214 token/参数 → 为推理成本刻意过训练
```

### 3.2.3 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 照搬 20 倍 | 场景不同 | 按目标调 |
| 忽略推理 | 只看训练最优 | 结合部署成本 |
| 数据质量差 | 等效数据不足 | 先提质 |

## 3.3 最优分配推导

### 3.3.1 拉格朗日直觉

```
min L(N,D) = A·N^(-α) + B·D^(-β)
s.t. C = 6 N D
→ 对 N、D 求偏导，得 N ∝ D
```

### 3.3.2 结论

| 条件 | 结果 |
|------|------|
| 算力固定 | N 与 D 同比例增长 |
| 比例常数 | 约 20 token/参数 |

### 3.3.3 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 忽略 E | 极大规模偏差 | 含下界拟合 |
| 假设无瓶颈 | 数据可无限获取 | 考虑数据上限 |

# 4. 现代实践：过训练

## 4.1 为什么过训练

**结论先行**：现代模型刻意用远超 Chinchilla 比例的数据训练，因为推理成本远比训练成本更值得优化。

### 4.1.1 推理成本主导

```
LLaMA 3 用了远超 Chinchilla 的数据量（15T token）
原因：推理成本比训练成本更重要

小模型 + 大量数据 → 推理便宜、效果接近大模型
```

```
训练成本：一次性
推理成本：每次调用 × 长期
→ 用更多训练换取更小、更便宜的推理模型
```

### 4.1.2 结论

| 目标 | 结果 |
|------|------|
| 训练最优 | 大模型 + 少数据 |
| 推理最优 | 小模型 + 多数据 |

## 4.2 策略选择

### 4.2.1 目标表

| 目标 | 策略 |
|------|------|
| 训练成本最优 | Chinchilla 比例 |
| 推理成本最优 | 过训练（更多数据） |

### 4.2.2 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 过训练无收益 | 收益递减 | 监控边际收益 |
| 数据不足 | 无法过训练 | 合成/多模态 |
| 忽视延迟 | 只算成本 | 端到端评估 |

# 5. 涌现能力

## 5.1 现象

**结论先行**：某些能力在小模型上几乎为零，规模超过阈值后突然出现，称为涌现（Emergence）。

### 5.1.1 定义

```
某些能力在小模型上几乎没有，超过某规模后突然出现
```

### 5.1.2 曲线

```
准确率
 │              ╱────
 │         ╱───╯
 │    ────╯
 │────╯
 └──────────────────▶ 规模
        ↑ 涌现点
```

## 5.2 例子与争议

### 5.2.1 涌现能力表

| 涌现能力 | 说明 |
|----------|------|
| 多步推理 | 需要一定规模 |
| 指令遵循 | 规模足够才有效 |
| 思维链 | 小模型无效 |

### 5.2.2 争议

> 涌现的机制仍有争议，部分研究认为是评估指标造成的假象。

| 观点 | 论据 |
|------|------|
| 真涌现 | 能力突变、不可线性外推 |
| 度量假象 | 非线性指标放大跳变 |
| 连续提升 | 换用线性指标则平滑 |

### 5.2.3 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 神化涌现 | 忽视数据/对齐 | 全链路分析 |
| 只盯阈值 | 忽略平滑提升 | 多指标观察 |
| 小模型硬上 | 能力不足 | 选合适规模 |

## 5.3 度量的数学直觉

### 5.3.1 为什么可能"看起来突然"

```
指标 y = f(x)，若 f 为非线性（如 exact match）
真实能力线性提升 → 指标呈现 S 型跳变
```

### 5.3.2 平滑化

| 指标 | 特性 |
|------|------|
| 精确匹配 | 易呈跳变 |
| token 级准确率 | 较平滑 |
| log-likelihood | 连续变化 |

### 5.3.3 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 单指标定论 | 误判涌现 | 多指标 |
| 采样噪声 | 小样本抖动 | 增大样本 |

# 6. 算力估算

## 6.1 训练算力

**结论先行**：训练算力近似为 6ND，推理算力近似为 2N 乘以生成 token 数。

### 6.1.1 公式

```
训练 FLOPs ≈ 6 × N × D
  N：参数量
  D：训练 token 数

推理 FLOPs ≈ 2 × N × 生成 token 数
```

### 6.1.2 代码

```python
def training_flops(num_params, num_tokens):
    return 6 * num_params * num_tokens

# 例：7B 模型 × 2T token
flops = training_flops(7e9, 2e12)    # 8.4e22 FLOPs
```

## 6.2 推理算力

### 6.2.1 公式

```
推理 FLOPs ≈ 2 × N × T_out
  T_out：生成的 token 数
```

### 6.2.2 对比

| 项 | 系数 | 说明 |
|----|------|------|
| 训练/前向 | 2N | 每 token |
| 训练/反向 | 4N | 梯度 |
| 训练合计 | 6N | 每 token |
| 推理 | 2N | 每生成 token |

### 6.2.3 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 忽略注意力 | 长上下文额外开销 | 加 O(L²) 项 |
| 忽略 MoE | 只算激活参数 | 按激活量估 |
| 忽视显存 | 算力不是唯一瓶颈 | 一起评估 |

# 7. 数据瓶颈

## 7.1 高质量数据有限

**结论先行**：高质量文本数据是有限资源，网页数据可能在本世纪 20 年代耗尽，合成数据与多模态数据成为补充。

### 7.1.1 问题

```
高质量数据是有限的：
- 网页数据用尽（预计 2026~2032）
- 合成数据成为补充
- 多模态数据成为新来源
```

### 7.1.2 时间线

```
2020 ──▶ 2026 ──▶ 2032
数据充裕   紧张     可能耗尽高质量网页
```

## 7.2 应对

### 7.2.1 数据来源表

| 数据来源 | 特点 |
|----------|------|
| 网页 | 量大、质量参差 |
| 书籍 | 质量高、量少 |
| 代码 | 结构化、逻辑强 |
| 合成数据 | 可控、可能退化 |
| 多模态 | 新增长点 |

### 7.2.2 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 合成数据退化 | 自噬/同质化 | 混真实数据 |
| 版权风险 | 数据合规 | 授权/过滤 |
| 重复利用 | 收益递减 | 去重、换源 |

## 7.3 合成数据的风险

### 7.3.1 风险

```
模型生成 → 训练新模型 → 分布收窄 → 多样性下降
（模型自噬 / Model Collapse）
```

### 7.3.2 对策

| 风险 | 对策 |
|------|------|
| 同质化 | 混入真实数据 |
| 错误放大 | 人工/规则校验 |
| 分布偏移 | 控制合成比例 |

# 8. 缩放定律的实践意义

## 8.1 应用

**结论先行**：缩放定律用于预算分配、效果预测、模型选型与训练规划，是训练决策的量化依据。

### 8.1.1 应用表

| 应用 | 说明 |
|------|------|
| 预算分配 | 决定参数与数据比例 |
| 效果预测 | 小规模实验外推 |
| 模型选型 | 理解小模型为何能接近大模型 |
| 训练规划 | 预估算力与成本 |

## 8.2 决策流程

### 8.2.1 流程

```
① 定目标（训练最优 / 推理最优）
② 小规模实验拟合幂律
③ 外推候选规模的 loss
④ 结合推理成本选点
⑤ 预留数据与稳定性余量
```

### 8.2.2 边界与坑

| 坑 | 说明 | 对策 |
|----|------|------|
| 只看 loss | 忽视下游任务 | 加评测 |
| 忽略数据质量 | 幂律失真 | 同质量对比 |
| 预算拍脑袋 | 超支 | 6ND 估算 |

## 8.3 与其他规律结合

### 8.3.1 组合视角

| 规律 | 关注点 |
|------|--------|
| Scaling Law | 规模与损失 |
| Chinchilla | 最优分配 |
| 过训练 | 推理成本 |
| 数据瓶颈 | 可持续性 |

### 8.3.2 决策建议

- 先定部署目标，再选训练比例。
- 用 6ND 估算总预算并留余量。
- 数据受限时优先质量与合成补充。

# 9. 小结

- Scaling Law 描述性能与规模、数据的幂律关系。
- Kaplan 主张优先扩大参数量。
- Chinchilla 主张参数量与数据等比（20 token/参数）。
- 现代实践"过训练"以降低推理成本。
- 数据瓶颈推动合成数据与多模态。
- 训练算力 ≈ 6ND，推理算力 ≈ 2N×输出 token。
