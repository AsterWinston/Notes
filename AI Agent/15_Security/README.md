# 1. 模块定位

LLM/Agent 引入了传统 Web 安全之外的新攻击面：提示注入、越权工具调用、数据泄露。本模块覆盖风险识别、防御手段、权限控制与合规。

## 1.1 模块解决的问题

- 如何识别 LLM/Agent 特有的攻击面？
- 如何用护栏（Guardrails，护栏）做多层防御？
- 如何为 Agent 的工具调用做权限隔离？
- 如何满足合规要求并留下可追溯的审计？

## 1.2 覆盖范围

```
风险识别（1~3） → 数据与护栏（4~5） → 隔离与权限（6~10）
                                   → 合规与审计（11~12）
```

| 层次 | 关注点 | 对应文件 |
|------|--------|----------|
| 威胁 | 注入、越狱、供应链 | 1~3 |
| 数据 | PII、边界、内容安全 | 4~5 |
| 隔离 | 沙箱、工具、MCP | 6~9 |
| 权限 | 认证、授权、审计 | 8~10、12 |
| 合规 | 备案、出境、治理 | 11 |

## 1.3 适用读者

# 5. 常见误区

## 5.1 认知误区

| 误区 | 事实 |
|------|------|
| 加个系统提示就安全了 | 提示可被注入绕过 |
| 护栏能根治攻击 | 护栏是多层防御的一层 |
| 内部应用不需要安全 | 内部同样有越权与泄露风险 |
| 登录就等于安全 | 认证不等于授权 |
| 合规只是法务的事 | 合规需要工程落地 |

## 5.2 实践误区

- 只过滤输入，不过滤输出。
- 检索后再做权限过滤，导致敏感内容进入上下文。
- 审计日志记录完整 Prompt 与凭据。
- 工具权限按“全开”设计，缺少最小权限。
- 权限缓存未按租户隔离，导致越权命中。

## 5.3 反模式清单

| 反模式 | 后果 |
|--------|------|
| 信任模型输出 | 被注入内容诱导执行 |
| 前端传权限参数 | 可篡改越权 |
| 内部服务默认可信 | 横向移动 |
| 审计可采样 | 关键事件缺失 |
| 无保留期策略 | 超期存储违规 |

## 5.4 自查问题

- 我的系统里，哪些输入是“用户可控且会被拼接进 Prompt”的？
- 哪些工具具备“写”或“外发”能力，权限是否最小？
- 检索是否在检索阶段就做了权限过滤？
- 审计事件能否覆盖认证、数据、模型、工具四类？

# 6. 术语速查

## 6.1 核心术语

| 术语 | 英文 | 含义 |
|------|------|------|
| 提示注入 | Prompt Injection | 通过不可信输入操纵模型行为 |
| 越狱 | Jailbreaking | 绕过模型对齐与安全限制 |
| 护栏 | Guardrails | 输入输出过滤与校验机制 |
| 最小权限 | Least Privilege | 只授予必需权限 |
| 沙箱 | Sandbox | 隔离执行环境 |
| 审计日志 | Audit Log | 记录谁在何时做了什么 |

## 6.2 缩写对照

| 缩写 | 全称 | 含义 |
|------|------|------|
| PII | Personally Identifiable Information | 个人可识别信息 |
| RBAC | Role-Based Access Control | 基于角色的访问控制 |
| ABAC | Attribute-Based Access Control | 基于属性的访问控制 |
| MCP | Model Context Protocol | 模型上下文协议 |
| PIPL | Personal Information Protection Law | 个人信息保护法 |
| DPO | Data Protection Officer | 数据保护官 |

## 6.3 术语使用注意

- “认证”与“授权”不可混用：认证解决身份，授权解决权限。
- “脱敏”与“匿名化”程度不同：脱敏可逆，匿名化不可逆。
- “审计日志”与“应用日志”目的不同：前者追责，后者排障。

# 7. 关键知识点速览

## 7.1 核心结论

- 只要 Prompt 拼接了不可信内容，就存在注入风险。
- 护栏是"多层防御"，单点无法根治。
- Agent 权限要遵循最小权限原则，工具必须鉴权。
- MCP 场景下必须做 Tool 级权限隔离，防止越权调用。
- 审计日志是安全事件的最后一道追溯防线。

## 7.2 一句话记忆

```
输入不可信 → 加护栏；
工具要调用 → 先鉴权；
数据要出境 → 看分级；
出事要追责 → 查审计。
```

## 7.3 快速自查表

| 检查项 | 通过标准 |
|--------|----------|
| 输入护栏 | 覆盖直接与间接注入 |
| 输出护栏 | 覆盖内容与 PII |
| 工具鉴权 | 每次调用校验权限 |
| 最小权限 | 工具与数据均按需授权 |
| 合规 | 分级、出境、标识齐备 |
| 审计 | 可追溯、防篡改、有保留期 |
