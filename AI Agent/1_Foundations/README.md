# 1. 模块定位

**结论先行**：本模块是整套 AI Agent 笔记的起点，只保留与 AI Agent **强相关** 的基础知识：深度学习、Transformer、自然语言处理（NLP）。目标是在阅读大模型与 Agent 内容时，知道"模型内部到底发生了什么"，而不是把大语言模型（LLM）当成黑盒。

## 1.1 定位与范围

本模块只保留与 AI Agent **强相关** 的基础知识：深度学习、Transformer、NLP。目的是让你在阅读大模型与 Agent 内容时，知道"模型内部到底发生了什么"，而不是把 LLM 当成黑盒。

> 不包含传统机器学习算法与数学推导细节；如遇公式，会给出直观解释而非完整证明。

**原理**：Agent 的能力上限由底层模型决定，而模型的行为又由架构、训练目标与表示方式决定。掌握这些基础，才能在调试 Agent 时判断"问题出在提示词、检索、还是模型本身"。

# 2. 学习目标

**结论先行**：学完本模块，应能用自己的话解释神经网络如何学习、Transformer 如何处理序列、文本如何变成向量，并能把这些理解迁移到后续模块。

## 2.1 知识目标

- 理解神经网络如何通过反向传播学习。
- 理解注意力机制与 Transformer 的结构，尤其是 Decoder-only 架构。
- 理解文本如何变成 Token，Token 如何变成向量。
- 为 `2_LLM`、`5_RAG`（Embedding）、`8_Memory`（向量检索）打基础。

## 2.2 能力目标

**原理**：知识目标关注"知道是什么"，能力目标关注"能做什么"。二者结合，才算真正掌握。

### 2.2.1 解释与判断

能解释注意力公式各部分的含义，判断某个模型是 Encoder-only、Decoder-only 还是 Encoder-Decoder，并据此推断其适用任务。

### 2.2.2 估算与选型

能粗略估算上下文长度、Token 成本与 Embedding 维度的关系，为后续 RAG 的切块与检索策略提供依据。

| 能力 | 检验方式 |
|------|----------|
| 解释注意力 | 能写出公式并说明每一项 |
| 判断架构 | 看模型名能说出类型与适用场景 |
| 估算成本 | 能估算 Token 数与上下文占用 |

**边界与坑**：本模块不追求"能手推反向传播全部公式"或"能从头实现训练框架"，这些属于更高阶的专门内容。

**要点**：

- 知识目标：理解学习、注意力、Token 与向量。
- 能力目标：能解释、能判断、能估算。
- 不追求完整数学推导与框架实现。

# 6. 关键知识点速览

**结论先行**：以下公式与结论是后续模块的高频引用，建议牢记；遇到遗忘时回到对应笔记复习即可。

## 6.1 核心公式

- 注意力公式：`Attention(Q,K,V) = softmax(QKᵀ/√d_k)V`。
- Decoder-only + 因果掩码 = 自回归语言模型的基础。
- Token 是模型的最小处理单位，Token 数与成本、上下文长度直接相关。
- Embedding 是把语义映射到向量空间，是 RAG 与向量记忆的基石。

### 6.1.1 公式速查表

| 概念 | 公式/结论 |
|------|-----------|
| 注意力 | softmax(QKᵀ/√d_k)V |
| 因果掩码 | 上三角置为负无穷 |
| LayerNorm | γ(x−μ)/σ + β |
| RMSNorm | γx/√mean(x²) |
| RoPE | 对 Q/K 施加位置旋转 |

## 6.2 速记清单

| 主题 | 一句话记忆 |
|------|------------|
| 注意力 | 查询找键、加权取值 |
| Decoder-only | 因果掩码、自回归 |
| 位置编码 | 从绝对到相对，RoPE 主流 |
| 归一化 | Pre-Norm + RMSNorm |
| 激活 | SwiGLU 门控 |
| MoE | 稀疏激活、容量与计算解耦 |

**边界与坑**：速览表用于快速回忆，不能替代正文；不同模型的实现细节存在差异，实际使用时仍需回到对应笔记核对。

**要点**：

- 注意力公式是后续一切的基础。
- Token 与 Embedding 是 RAG 的前置概念。
- 速览表用于回忆，细节回正文。
