# 1. 为什么需要位置编码

**结论先行**：自注意力（Self-Attention）对输入顺序是置换不变（Permutation-Invariant）的，即打乱 Token 顺序后，注意力输出只是跟着一起打乱，模型无法感知"谁在前、谁在后"。因此必须显式注入位置信息，位置编码（Positional Encoding）正是承担这一职责的模块。

## 1.1 注意力的置换不变性

**原理**：注意力输出是值向量（Value）按注意力权重的加权和，而权重由查询（Query）与键（Key）的点积决定。若把输入序列的位置 i、j 互换，注意力矩阵相应行列互换，输出也只是同一组向量的重新排列，语义不发生变化。

```
置换不变性示意：

输入顺序 A：我  爱  你
输入顺序 B：你  爱  我

注意力计算：softmax(QKᵀ/√d_k) V
→ 两种顺序得到的是"同样的向量集合"
→ 模型无法区分"我爱"与"你爱"
```

**边界与坑**：置换不变性只针对"打乱顺序"这一操作；若同时改变内容，输出当然不同。关键是模型缺少"位置"这一维度的信息来源。

### 1.1.1 为什么置换等变还不够

置换等变（Permutation-Equivariance）意味着输出随输入同步置换，但对语言任务而言，我们期望的是**同一组词、不同顺序、不同含义**，等变本身无法提供这种区分，必须额外注入位置。

### 1.1.2 一个具体反例

```
句子："狗 咬 人" vs "人 咬 狗"

词袋相同 {狗, 咬, 人}
若模型只看词集合，二者不可区分
位置编码让"狗在首位"与"狗在末位"变成不同输入
```

## 1.2 位置信息的三个层次

| 层次 | 含义 | 代表方法 |
|------|------|----------|
| 绝对位置 | 第几个 Token | 正弦编码、可学习编码 |
| 相对位置 | 两个 Token 相距多远 | RoPE、ALiBi、相对偏置 |
| 内容相关位置 | 依内容决定关注多远 | 学习式相对注意力 |

**原理**：语言中"相对距离"往往比"绝对下标"更本质，例如"前一个词"这一关系与句子总长度无关，因此现代方法普遍转向相对位置建模。

### 1.2.1 绝对与相对的取舍

绝对编码实现简单、可解释，但难以外推到训练长度之外；相对编码更贴近语言结构、外推性更好，但实现与缓存更复杂。

### 1.2.2 内容相关位置

内容相关位置建模让"关注多远"由当前内容动态决定，典型如 T5 的相对位置桶（Relative Position Bucket），把距离分桶后学习偏置。

## 1.3 位置编码的评判标准

| 标准 | 说明 |
|------|------|
| 唯一性 | 不同位置编码应可区分 |
| 有界性 | 数值不随位置无限增大 |
| 外推性 | 可处理训练时未见过的长度 |
| 相对性 | 能自然表达相对距离 |
| 低参性 | 尽量不显著增加参数 |

**原理**：唯一性保证可区分，有界性保证数值稳定，外推性决定长上下文能力，相对性贴合语言结构，低参性控制成本。这些标准之间常存在取舍。

**要点**：

- 自注意力本身置换不变，必须注入位置信息。
- 位置信息分绝对、相对、内容相关三个层次。
- 评判位置编码看唯一性、有界性、外推性、相对性、低参性。

# 2. 绝对位置编码（正弦）

**结论先行**：原始 Transformer 用一组不同频率的正弦与余弦函数，为每个位置生成一个固定向量，直接加到词嵌入（Token Embedding）上。它无需学习、数值有界，且任意固定位移下存在线性变换关系。

## 2.1 公式与推导

**公式**：设位置为 pos、维度下标为 i、模型维度为 d_model：

```
PE(pos, 2i)   = sin(pos / 10000^(2i/d_model))
PE(pos, 2i+1) = cos(pos / 10000^(2i/d_model))
```

偶数维用 sin，奇数维用 cos，每个维度对对应一个不同频率的旋转。

**原理**：把 10000^(2i/d) 看作波长，i 越大波长越长、频率越低。最低频对应约 10000·2π 的周期，最高频对应约 2π，形成从粗到细的多尺度表示，类似二进制计数的各个位。

### 2.1.1 频率的几何级数

频率按几何级数排列：

```
波长_i = 2π · 10000^(2i/d_model)

i = 0    → 波长最短（变化最快，负责精细位置）
i = d/2  → 波长最长（变化最慢，负责全局位置）
```

不同频率叠加，使每个位置得到近似唯一的编码，且相似位置的编码在低频分量上接近。

### 2.1.2 为什么用三角函数

三角函数满足加法公式，使得 PE(pos+k) 可由 PE(pos) 经一个与 k 有关的线性变换得到，从而隐含表达相对位移，这是正弦编码被称为"优雅"的原因。

## 2.2 代码实现

```python
import math
import torch

def positional_encoding(seq_len, d_model):
    pe = torch.zeros(seq_len, d_model)
    position = torch.arange(0, seq_len).unsqueeze(1).float()
    div_term = torch.exp(torch.arange(0, d_model, 2).float()
                         * -(math.log(10000.0) / d_model))
    pe[:, 0::2] = torch.sin(position * div_term)
    pe[:, 1::2] = torch.cos(position * div_term)
    return pe
```

| 特点 | 说明 |
|------|------|
| 无需学习 | 固定函数 |
| 可外推 | 理论上可处理更长序列 |
| 表达力有限 | 后期被取代 |

## 2.3 相对位移的线性性质

**公式**：对任意固定位移 k，存在与 pos 无关的矩阵 M_k，使得：

```
PE(pos + k) = M_k · PE(pos)
```

**原理**：这是三角恒等式 sin(a+b)=sin a cos b + cos a sin b 的直接结果，说明正弦编码天然携带相对位置信息。

### 2.3.1 推导示意

```
sin(pos+k) = sin(pos)cos(k) + cos(pos)sin(k)
cos(pos+k) = cos(pos)cos(k) - sin(pos)sin(k)

写成矩阵（每对维度）：
[cos k  sin k] [sin pos]   [sin(pos+k)]
[-sin k cos k] [cos pos] = [cos(pos+k)]
```

**边界与坑**：该线性关系要求 sin 与 cos 成对出现（即按 2i / 2i+1 配对），若只取其中一支则不成立。这也是实现时 pe[:, 0::2] 与 pe[:, 1::2] 必须同步赋值的原因。

### 2.3.2 与词嵌入的相加

**原理**：正弦编码与词嵌入逐元素相加，而非拼接，因此两者维度必须一致。相加意味着位置信息与语义信息共享同一向量空间，模型需自行学会区分二者。

**要点**：

- 正弦编码固定、无需训练。
- 多尺度频率构成近似唯一的位置表示。
- 三角恒等式带来隐含的相对位移能力。
- 通常与词嵌入相加，而非拼接。

# 3. 可学习位置编码

**结论先行**：可学习位置编码（Learned Positional Embedding）把位置当作词表一样训练一个嵌入矩阵，实现简单、表达灵活，但无法外推到训练长度之外。

## 3.1 实现方式

```python
self.pos_embedding = nn.Embedding(max_seq_len, d_model)
x = token_embedding + self.pos_embedding(positions)
```

**原理**：为每个位置 0…max_seq_len-1 学习一个 d_model 维向量，与词嵌入逐元素相加后送入 Transformer。位置向量与词向量在同一优化过程中共同更新。

### 3.1.1 与正弦编码的等价性

有研究指出，可学习编码在训练后呈现类似正弦的周期性结构，说明两种方式在表达能力上并非天壤之别，差别主要集中在外推能力上。

### 3.1.2 初始化与训练

**原理**：位置嵌入通常随机初始化，训练早期就与词嵌入一起接受梯度；由于每个位置在每条样本中都被访问，短位置学得充分，长位置则相对稀疏。

## 3.2 优缺点

| 优点 | 缺点 |
|------|------|
| 灵活 | 无法外推到训练长度之外 |
| 简单 | 参数量随长度增长 |
| 与词嵌入统一训练 | 长位置样本少、学习不充分 |

> BERT、GPT-2 早期使用。

## 3.3 外推问题

**原理**：位置超出 max_seq_len 时没有对应向量，只能截断或随机初始化，导致性能骤降。这正是后续 RoPE、ALiBi 兴起的直接原因。

**边界与坑**：即便简单地把训练长度设得很长，长位置样本稀疏也会导致该区段向量训练不足，效果不如相对方法；此外参数表随长度线性增长，超长上下文下显存开销可观。

**要点**：

- 可学习编码把位置当作词表训练。
- 训练域内表现与正弦相当。
- 无法外推，是其主要短板。

# 4. RoPE（旋转位置编码）

**结论先行**：旋转位置编码（Rotary Position Embedding，RoPE）通过对查询与键向量施加与位置相关的旋转，使注意力分数只依赖二者的**相对**位置，是当前 LLM 的主流方案。

## 4.1 核心思想

```
核心思想：
  把位置信息编码为"旋转角度"
  两个位置的相对角度决定它们的相对位置
  → 自然表达相对位置
```

**原理**：把 d 维向量两两分组为 d/2 个二维平面，每个平面按位置乘以一个旋转角。查询旋转角 θ_i、键旋转角 θ_j，二者点积只依赖角度差 (θ_i − θ_j)，即相对位置。

### 4.1.1 二维旋转

**公式**：二维向量 (x1, x2) 旋转角度 θ：

```
[x1']   [cosθ  -sinθ] [x1]
[x2'] = [sinθ   cosθ] [x2]
```

点积满足 ⟨R(θ_i)q, R(θ_j)k⟩ = ⟨q, R(θ_j − θ_i)k⟩，仅与相对角有关。

### 4.1.2 高维分组

```
d 维向量 → d/2 个二维子空间
第 i 组旋转角 θ_i(pos) = pos · base^(-2i/d)
base 通常取 10000
```

不同子空间旋转快慢不同，形成多尺度相对位置感知：低频子空间区分远距离，高频子空间区分近距离。

## 4.2 数学推导

**公式**：设旋转频率 ω_i = base^(-2i/d)，位置 pos 的旋转矩阵为分块对角矩阵 R(pos)，则：

```
(R(m)q)ᵀ (R(n)k) = qᵀ R(m)ᵀ R(n) k
                 = qᵀ R(n - m) k
```

由于 R(m)ᵀ = R(−m)，且旋转矩阵相乘等于角度相加，故 R(m)ᵀR(n) = R(n−m)。因此注意力分数天然是相对位置 (n − m) 的函数。

### 4.2.1 与正弦编码的区别

正弦编码把位置**加到**嵌入上，RoPE 把位置**乘进** Q/K 的旋转中；前者是加性、绝对，后者是乘性、相对。

### 4.2.2 为什么只旋转 Q/K

**原理**：注意力分数只由 Q、K 的内积决定，因此只需让内积携带相对位置；V 不参与打分，旋转它对结果无益，反而增加计算。

## 4.3 代码实现

```python
def apply_rope(x, positions, base=10000):
    d = x.shape[-1]
    freqs = 1.0 / (base ** (torch.arange(0, d, 2) / d))
    angles = positions[:, None] * freqs[None, :]

    cos = torch.cos(angles)
    sin = torch.sin(angles)

    x1, x2 = x[..., 0::2], x[..., 1::2]
    rotated = torch.stack([x1 * cos - x2 * sin,
                           x1 * sin + x2 * cos], dim=-1)
    return rotated.flatten(-2)
```

## 4.4 优点

| 优点 | 说明 |
|------|------|
| 相对位置 | 自然表达相对距离 |
| 可外推 | 配合插值可扩展长度 |
| 无额外参数 | 不增加模型参数 |
| 兼容注意力 | 直接作用于 Q/K |

> RoPE 被 LLaMA、Qwen、DeepSeek 等广泛采用。

## 4.5 RoPE 的工程细节

### 4.5.1 与 KV Cache 的配合

RoPE 只旋转 Q、K，不改变 V，因此缓存 K 时通常缓存"旋转后"的键，避免每步重复旋转历史位置，从而降低推理开销。

### 4.5.2 base 的调整

**原理**：增大 base 会拉长低频波长，使模型在更长序列上仍保持可区分性，这是 NTK-aware 与 YaRN 的出发点。

### 4.5.3 常见实现错误

**边界与坑**：RoPE 作用在 Q/K 上会改变内积分布，若实现中漏乘或重复乘旋转矩阵，会造成训练与推理不一致的隐蔽错误；此外"交错式"与"分半式"维度排布必须与训练时一致。

**要点**：

- RoPE 用旋转把位置乘进 Q/K。
- 点积只依赖相对位置，天然相对。
- 无额外参数，是当前 LLM 主流。
- 实现需注意维度排布与缓存一致性。

# 5. ALiBi（线性偏置）

**结论先行**：ALiBi（Attention with Linear Biases）不修改嵌入，而是在注意力分数上直接加一个与相对距离成正比的负偏置，实现简单且外推性强。

## 5.1 核心思想

```
不加位置编码，而是在注意力分数上加一个与距离成正比的惩罚：

  score(i, j) = q_i · k_j - m × |i - j|

距离越远，惩罚越大
```

**原理**：用"近的更相关"这一先验，把距离惩罚线性地叠加到 logits 上，相当于给注意力一个随距离衰减的先验偏好，而不依赖任何可学习的位置参数。

### 5.1.1 与注意力掩码的区别

掩码是硬性的"置为负无穷"，ALiBi 是软性的线性惩罚；前者禁止关注，后者只是降低关注强度。

## 5.2 斜率设置

**公式**：不同头使用几何级数的斜率 m_h：

```
m_h = 2^(-(h+1)/H),  h = 0, 1, ..., H-1
```

**原理**：小斜率头关注远距离，大斜率头关注近距离，多尺度斜率让不同头覆盖不同范围，从而在不同尺度上提取信息。

```python
def alibi_bias(num_heads, seq_len):
    slopes = 2 ** (-torch.arange(1, num_heads + 1) / num_heads)
    bias = -slopes[:, None, None] * torch.arange(seq_len)[None, None, :]
    return bias
```

### 5.2.1 因果与非因果

因果注意力下 |i−j| 取 j≤i 的差；非因果（双向）则取绝对差。实现需与掩码保持一致，否则会引入错误的位置先验。

### 5.2.2 斜率的选取

**边界与坑**：斜率按 2 的负幂次设置是经验做法，头数改变时需重新推导；若斜率过大，远距离注意力被过度压制，模型可能退化为近似局部注意力。

## 5.3 优缺点

| 优点 | 说明 |
|------|------|
| 外推好 | 长序列表现稳定 |
| 实现简单 | 只加 bias |
| 无需编码 | 不修改 embedding |

| 缺点 | 说明 |
|------|------|
| 先验固定 | 距离衰减无法学习 |
| 表达受限 | 不如 RoPE 灵活 |
| 采用较少 | 主流转向 RoPE |

**边界与坑**：ALiBi 的线性衰减是硬先验，对"长距离强依赖"任务可能不利；且它不携带绝对位置，某些需要精确下标的场景会受限。

**要点**：

- ALiBi 用线性负偏置表达相对距离。
- 多头使用几何级数斜率，覆盖多尺度。
- 外推性好、实现极简。
- 先验固定，表达力不如 RoPE。

# 6. 长度外推

**结论先行**：长度外推（Length Extrapolation）指模型在超出训练长度的序列上保持性能。RoPE 类模型直接外推会因频率失配而崩溃，主流对策有位置插值、NTK-aware、YaRN 与长上下文微调。

## 6.1 问题来源

```
训练长度 4K，推理要用 32K → 直接外推效果会崩
```

**原理**：训练时每个频率分量只见过有限的角度范围，超出后角度进入"未见过的取值"，注意力分数分布漂移，导致困惑度（Perplexity）飙升。

### 6.1.1 为什么高频先崩

**原理**：高频分量周期短，角度很快超出训练范围；低频分量周期长，相对更稳。因此外推失败往往从高频开始。

## 6.2 位置插值（PI）

**公式**：把推理位置压缩回训练范围：

```
scaled_positions = positions * (train_len / inference_len)
```

```python
scaled_positions = positions * (train_len / inference_len)
```

**原理**：相当于把长序列"挤"进训练时见过的角度范围，只需极少微调即可恢复性能。

### 6.2.1 代价

压缩会降低相邻位置的角度差，牺牲高频分辨力，因此 PI 对短距离区分略有损失，表现为局部任务轻微退化。

## 6.3 NTK-aware

**原理**：不压缩位置，而是调整 RoPE 的 base，让低频分量变化更慢、高频基本不变，从频域上缓解失配。

```
base' = base × (inference_len / train_len)^(d/(d-2))
```

### 6.3.1 分频思想

高频维度负责局部次序，低频维度负责全局位置；NTK-aware 只"拉伸"低频，从而在保留局部精度的同时扩展全局范围。

### 6.3.2 动态 NTK

**原理**：动态 NTK 在推理时按当前序列长度实时调整 base，无需预先固定目标长度，适合变长上下文场景。

## 6.4 YaRN

**原理**：YaRN 把维度按频率分为三档：高频保持、低频插值、中频渐变，并引入温度缩放修正注意力分布，是当前较优的外推方案之一。

| 频段 | 处理 |
|------|------|
| 高频 | 不变 |
| 中频 | 渐变过渡 |
| 低频 | 插值压缩 |

### 6.4.1 温度缩放

**原理**：外推会改变注意力 logits 的方差，YaRN 用一个温度系数重新缩放，使 softmax 的尖锐程度回到训练时的水平。

## 6.5 长上下文微调

**原理**：直接用长文本继续训练，让模型适应目标长度；常与上述方法结合，效果最稳但成本最高。

| 方法 | 是否训练 | 效果 | 成本 |
|------|:--------:|:----:|:----:|
| PI | 少量 | 好 | 低 |
| NTK-aware | 少量 | 好 | 低 |
| YaRN | 少量 | 很好 | 中 |
| 长上下文微调 | 大量 | 最好 | 高 |

**边界与坑**：外推长度并非越大越好，超出太多时任何方法都会掉点；同时需注意"训练长度"应以微调后为准，而非原始预训练长度。

**要点**：

- 直接外推会因频率失配而崩溃。
- PI 压缩位置、NTK 调 base、YaRN 分频段。
- 长上下文微调效果最稳但最贵。

# 7. 对比与选型

**结论先行**：正弦与可学习属于绝对编码，RoPE 与 ALiBi 属于相对编码；当前 LLM 以 RoPE 为主，长上下文场景叠加 PI/NTK/YaRN。

## 7.1 综合对比

| 方法 | 类型 | 外推 | 参数 | 代表 |
|------|------|:----:|:----:|------|
| 正弦 | 绝对 | 中 | 无 | 原始 Transformer |
| 可学习 | 绝对 | 差 | 有 | BERT、GPT-2 |
| RoPE | 相对 | 好 | 无 | LLaMA、Qwen |
| ALiBi | 相对 | 好 | 无 | BLOOM、MPT |

## 7.2 选型建议

| 场景 | 推荐 |
|------|------|
| 从零训练 LLM | RoPE |
| 需要长上下文 | RoPE + YaRN / NTK |
| 极简实现 | ALiBi |
| 复现早期模型 | 正弦 / 可学习 |

### 7.2.1 组合策略

**原理**：位置编码可与注意力变体正交组合，例如 RoPE + GQA + FlashAttention 是现代开源模型的常见栈，各模块互不冲突。

**边界与坑**：组合时要注意各模块对 Q/K 的假设一致，例如 FlashAttention 需要知道是否已应用 RoPE，以及旋转发生在缓存之前还是之后。

**要点**：

- 绝对编码：正弦、可学习。
- 相对编码：RoPE、ALiBi。
- 当前默认是 RoPE，长上下文叠加外推技术。

# 8. 常见误区

**结论先行**：围绕位置编码的误解多集中在"是否需要""能否外推""是否影响缓存"三个方面。

## 8.1 关于必要性与效果

| 误区 | 澄清 |
|------|------|
| 有注意力就不需要位置编码 | 注意力置换不变，必须注入 |
| 位置编码可有可无 | 去掉后语言建模显著退化 |
| 可学习一定优于正弦 | 训练域内相近，外推更差 |

## 8.2 关于外推与实现

| 误区 | 澄清 |
|------|------|
| RoPE 天生能无限外推 | 直接外推仍会崩，需插值等技术 |
| ALiBi 不需要任何调整 | 斜率与头数需匹配 |
| 位置编码要加到每个隐藏状态 | 通常只加在输入嵌入上 |

**边界与坑**：不同框架对 RoPE 的实现细节（旋转维度排布、base、是否缓存旋转后的 K）不一致，跨框架迁移权重时需逐项核对，否则会出现"能跑但掉点"的问题。

**要点**：

- 位置编码是必需项，不是可选项。
- RoPE 并不自动具备无限外推能力。
- 跨框架迁移需核对实现细节。

# 9. 小结

**结论先行**：位置编码解决注意力的置换不变问题，历经绝对编码到相对编码的演进，RoPE 成为现代 LLM 标配，长度外推依赖插值与频域调整。

## 9.1 核心要点

- 注意力本身无序，必须注入位置信息。
- 绝对编码（正弦、可学习）表达固定位置。
- RoPE 通过旋转注入相对位置，是当前主流。
- ALiBi 用线性偏置，外推性好。
- 长度外推需位置插值、NTK、YaRN 等技术。

## 9.2 记忆口诀

```
正弦无参但有界，学习灵活难外推
RoPE 旋转看相对，主流 LLM 都在用
ALiBi 线性加偏置，斜率多尺度外推
长文外推怎么办，插值 NTK 加 YaRN
```

**要点**：

- 一根主线：从绝对到相对。
- 一个标配：RoPE。
- 一组外推：PI、NTK、YaRN。
