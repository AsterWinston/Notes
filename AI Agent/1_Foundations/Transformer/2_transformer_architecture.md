# 1. 原始架构

**结论先行**：Transformer 由编码器（Encoder）与解码器（Decoder）两部分组成，各自堆叠 N 层；它彻底抛弃循环（Recurrent）与卷积（Convolution），只用注意力（Attention）建模序列依赖。

## 1.1 论文背景与核心主张

**原理**：2017 年论文《Attention Is All You Need》面向机器翻译（Machine Translation）任务，提出用自注意力（Self-Attention）替代 RNN 的时序递推，从而获得并行计算能力。

### 1.1.1 序列建模的历史包袱

在 Transformer 之前，序列到序列（Seq2Seq）任务主要依赖循环神经网络（RNN）及其变体 LSTM、GRU。它们按时间步（Time Step）串行计算：

```
h_t = f(h_{t-1}, x_t)
```

其中 h_t 是时刻 t 的隐藏状态（Hidden State），x_t 是输入。其问题有三：

- 无法并行：t 时刻必须等 t-1 完成，GPU 利用率低。
- 长程依赖衰减：信息需要逐跳传递，距离越远越容易丢失。
- 梯度问题：反向传播路径长，易梯度消失或爆炸。

### 1.1.2 自注意力（Self-Attention）的提出

自注意力让序列中任意两个位置直接交互，信息路径长度为 O(1)：

```
RNN：  x1 → x2 → x3 → x4     路径长度随距离增长
Self： x1 ←→ x2 ←→ x3 ←→ x4  任意两位置一步直达
```

这带来两个直接好处：并行计算（所有位置同时算）和全局感受野（Receptive Field）。

## 1.2 编码器-解码器总览

**结论先行**：编码器把输入序列编码为一组上下文表示，解码器在每一步基于已生成内容与该表示逐步输出。

```
┌─────────────┐     ┌─────────────┐
│   Encoder   │────▶│   Decoder   │
│  × N 层      │     │  × N 层      │
└─────────────┘     └─────────────┘
  输入序列            输出序列
```

| 部分 | 输入 | 输出 | 职责 |
|------|------|------|------|
| 编码器 | 源序列 | 上下文表示 | 理解输入 |
| 解码器 | 已生成序列 + 编码器输出 | 下一 Token 概率 | 生成输出 |

## 1.3 与 RNN/CNN 的对比

| 维度 | RNN | CNN | Transformer |
|------|-----|-----|-------------|
| 并行性 | 差 | 好 | 好 |
| 最大路径长度 | O(n) | O(log n) | O(1) |
| 每层复杂度 | O(n·d²) | O(k·n·d²) | O(n²·d) |
| 长程依赖 | 弱 | 中 | 强 |

**边界与坑**：Transformer 的代价是注意力复杂度随序列长度平方增长（O(n²)），长序列显存与计算开销显著上升。

**要点**：

- 原始 Transformer 是编码器-解码器结构。
- 核心创新是自注意力，任意两位置路径长度为 O(1)。
- 代价是注意力 O(n²) 复杂度。

# 2. 整体结构

**结论先行**：无论编码器还是解码器，其基本单元都是"注意力 + 前馈网络 + 残差 + 归一化"的堆叠块，区别只在解码器多了一层交叉注意力（Cross-Attention）和因果掩码（Causal Mask）。

## 2.1 数据流全景

```
输入 → [Embedding + 位置编码]
         │
    ┌────▼────┐
    │ Encoder │ × N
    │  ├─ 多头自注意力
    │  ├─ 残差 + LayerNorm
    │  ├─ 前馈网络
    │  └─ 残差 + LayerNorm
    └────┬────┘
         │
    ┌────▼────┐
    │ Decoder │ × N
    │  ├─ 掩码自注意力
    │  ├─ 残差 + LayerNorm
    │  ├─ 交叉注意力（关注 Encoder 输出）
    │  ├─ 残差 + LayerNorm
    │  ├─ 前馈网络
    │  └─ 残差 + LayerNorm
    └────┬────┘
         ▼
    线性层 + Softmax
         ▼
     输出概率
```

## 2.2 张量形状变化

**原理**：记批大小 B、序列长度 n、模型维度 d_model，则各阶段张量形状如下。

| 阶段 | 张量形状 | 说明 |
|------|----------|------|
| 输入 Token | (B, n) | 整数索引 |
| Embedding | (B, n, d_model) | 查表得到向量 |
| + 位置编码 | (B, n, d_model) | 逐元素相加 |
| 编码器输出 | (B, n, d_model) | 与输入同形状 |
| 解码器输出 | (B, m, d_model) | m 为目标长度 |
| 线性层 | (B, m, V) | V 为词表大小 |

## 2.3 超参数配置

| 超参数 | Base | Big | 含义 |
|--------|:----:|:---:|------|
| d_model | 512 | 1024 | 隐层维度 |
| N（层数） | 6 | 6 | 堆叠层数 |
| 注意力头数 | 8 | 16 | 多头数量 |
| d_ff | 2048 | 4096 | 前馈隐层维度 |
| Dropout | 0.1 | 0.3 | 丢弃率 |

**边界与坑**：d_model 必须能被注意力头数整除，否则每个头的 head_dim 不是整数。

**要点**：

- 结构块 = 注意力 + 前馈 + 残差 + 归一化。
- 解码器额外有交叉注意力与因果掩码。
- 输出层把 d_model 投影到词表维度。

# 3. 编码器层

**结论先行**：编码器层只做两件事——让所有位置互相交换信息（自注意力），再对每个位置独立做非线性变换（前馈网络）；两者都包在残差与归一化里。

## 3.1 结构组成

| 组件 | 作用 |
|------|------|
| 多头自注意力 | 捕捉序列内依赖 |
| 前馈网络 | 逐位置非线性变换 |
| 残差连接 | 缓解梯度消失 |
| LayerNorm | 稳定训练 |

## 3.2 代码实现

```python
class EncoderLayer(nn.Module):
    def __init__(self, d_model, num_heads, d_ff):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff),
            nn.ReLU(),
            nn.Linear(d_ff, d_model))
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)

    def forward(self, x):
        x = self.norm1(x + self.self_attn(x))     # 残差 + 归一化
        x = self.norm2(x + self.ffn(x))
        return x
```

## 3.3 数学表达

**公式**：编码器层的两步可写成（Post-LN 形式）：

```
z = LayerNorm(x + SelfAttn(x))
y = LayerNorm(z + FFN(z))
```

若为 Pre-LN，则归一化先于子层：

```
z = x + SelfAttn(LayerNorm(x))
y = z + FFN(LayerNorm(z))
```

### 3.3.1 自注意力的置换等变性

自注意力本身对输入顺序是置换等变的（Permutation Equivariant），因此必须靠位置编码注入顺序信息，否则打乱输入顺序结果不变。

**边界与坑**：编码器没有因果掩码，每个位置可以看到全部位置，因此它适合理解类任务，但不能直接用于自回归生成。

**要点**：

- 编码器层 = 自注意力 + 前馈网络，各带残差与归一化。
- 注意力混合位置，前馈变换特征。
- 编码器是双向的，无因果掩码。

# 4. 解码器层

**结论先行**：解码器层比编码器层多一个交叉注意力子层，共三个子层，且第一个自注意力必须加因果掩码，保证只能看到已生成的位置。

## 4.1 三明治结构

```
Decoder Layer
 ├─ ① 掩码多头自注意力   (Q=K=V=解码器输入)
 ├─ ② 交叉注意力         (Q=解码器, K=V=编码器输出)
 └─ ③ 前馈网络
每层子层外均包裹 残差 + LayerNorm
```

## 4.2 掩码自注意力

**原理**：解码时第 i 个位置不能看到 i 之后的位置，否则训练会"偷看答案"。做法是在注意力分数上加一个上三角为负无穷的掩码：

```
scores = Q·Kᵀ / √d_k
scores = scores + mask        # mask 上三角为 -inf
attn   = softmax(scores)      # 被 -inf 的位置权重为 0
```

## 4.3 交叉注意力

**原理**：查询（Query）来自解码器当前表示，键（Key）和值（Value）来自编码器输出。它让解码器在生成每个 Token 时"回看"源序列。

| 子层 | Q 来源 | K/V 来源 |
|------|--------|----------|
| 自注意力 | 解码器 | 解码器 |
| 交叉注意力 | 解码器 | 编码器 |

```python
class DecoderLayer(nn.Module):
    def __init__(self, d_model, num_heads, d_ff):
        super().__init__()
        self.self_attn = MultiHeadAttention(d_model, num_heads)
        self.cross_attn = MultiHeadAttention(d_model, num_heads)
        self.ffn = nn.Sequential(
            nn.Linear(d_model, d_ff), nn.ReLU(),
            nn.Linear(d_ff, d_model))
        self.norm1 = nn.LayerNorm(d_model)
        self.norm2 = nn.LayerNorm(d_model)
        self.norm3 = nn.LayerNorm(d_model)

    def forward(self, x, encoder_out):
        # ① 掩码自注意力（不能看到未来）
        x = self.norm1(x + self.self_attn(x))
        # ② 交叉注意力（Q 来自解码器，K/V 来自编码器）
        x = self.norm2(x + self.cross_attn(x, encoder_out))
        # ③ 前馈
        x = self.norm3(x + self.ffn(x))
        return x
```

**边界与坑**：交叉注意力通常不加因果掩码，因为它关注的是完整的源序列；但它需要对源序列的填充（Padding）位置做掩码，否则会关注到无意义的填充符。

**要点**：

- 解码器层有三个子层：掩码自注意力、交叉注意力、前馈。
- 掩码保证因果性，交叉注意力连接源与目标。
- 填充掩码与因果掩码是两种不同的掩码。

# 5. 前馈网络

**结论先行**：前馈网络（FFN）是逐位置的两层全连接网络，承担了模型大部分参数，被认为是存储事实知识的主要位置。

## 5.1 定义与公式

**公式**：

```
FFN(x) = max(0, xW₁ + b₁)W₂ + b₂

通常 d_ff = 4 × d_model
```

其中 W₁ 形状为 (d_model, d_ff)，W₂ 形状为 (d_ff, d_model)。

| 符号 | 形状 | 含义 |
|------|------|------|
| x | (n, d_model) | 单个样本的序列表示 |
| W₁ | (d_model, d_ff) | 升维投影 |
| W₂ | (d_ff, d_model) | 降维投影 |

## 5.2 为什么需要 FFN

**原理**：注意力是线性加权组合，本身不含非线性（Softmax 只是归一化权重）。若只有注意力，整个模型近似线性，表达能力受限。FFN 提供逐位置的非线性变换，且其隐藏维度更大，形成"先升维再降维"的瓶颈结构。

### 5.2.1 逐位置独立

FFN 对每个位置独立作用，位置之间不交互，因此可写成矩阵乘法，天然并行。

## 5.3 参数占比

**公式**：单层 FFN 参数量约为 2 × d_model × d_ff = 2 × d_model × (4·d_model) = 8·d_model²。

| 模块 | 单层参数 | 占比 |
|------|----------|:----:|
| 注意力（Q/K/V/O） | 4·d_model² | 1/3 |
| 前馈网络 | 8·d_model² | 2/3 |

**边界与坑**：d_ff 过大导致参数与显存激增；现代模型用门控激活（如 SwiGLU）替代 ReLU，此时 d_ff 常取约 8/3·d_model 以保持参数量相当。

**要点**：

- FFN 是逐位置的两层全连接，d_ff 通常为 4×d_model。
- 它提供非线性并存储知识。
- 参数量约占单层 2/3。

# 6. 残差与归一化

**结论先行**：残差连接（Residual Connection）保证梯度可以跨层直通，LayerNorm 稳定每层激活分布；两者组合的摆放位置（Post-LN 还是 Pre-LN）深刻影响训练稳定性。

## 6.1 残差连接

**原理**：子层输出与其输入相加：

```
y = x + Sublayer(x)
```

好处：

- 梯度直通：反向传播时有一项恒为 1 的路径，缓解梯度消失。
- 恒等映射：子层只需学习"增量"，优化更容易。
- 深层可训练：没有残差，几十层的 Transformer 难以收敛。

### 6.1.1 维度一致

残差要求 x 与 Sublayer(x) 形状一致，均为 (B, n, d_model)，因此所有子层输入输出维度必须保持 d_model 不变。

## 6.2 LayerNorm 原理

**公式**：对单个样本的特征维度做归一化：

```
μ = mean(x)          # 对最后一维求均值
σ² = var(x)          # 对最后一维求方差
y = γ · (x - μ) / √(σ² + ε) + β
```

| 项 | 作用 |
|----|------|
| μ、σ² | 统计量，逐样本逐位置计算 |
| γ、β | 可学习缩放与平移 |
| ε | 防止除零的小常数 |

与批归一化（BatchNorm）不同，LayerNorm 不跨样本统计，因此对批大小与变长序列更友好。

## 6.3 Post-LN vs Pre-LN

```
Post-LN（原始）：
  x = LayerNorm(x + Sublayer(x))

Pre-LN（现代主流）：
  x = x + Sublayer(LayerNorm(x))
```

| 类型 | 特点 |
|------|------|
| Post-LN | 原始论文，需 warmup |
| Pre-LN | 更稳定，现代主流 |

**边界与坑**：Post-LN 在深层网络中梯度尺度不稳定，必须配合学习率预热（Warmup）；Pre-LN 更稳定但最终层输出尺度可能偏大，通常需在最后加一个归一化。

**要点**：

- 残差提供梯度直通路径。
- LayerNorm 逐样本归一化，适合变长序列。
- Pre-LN 是现代主流，更稳定。

# 7. 三种架构变体

**结论先行**：按使用编码器、解码器还是两者兼用，Transformer 分为三种架构：Encoder-only、Decoder-only、Encoder-Decoder，分别对应理解、生成与序列到序列任务。

## 7.1 Encoder-only

| 项目 | 说明 |
|------|------|
| 组成 | 只用编码器 |
| 代表 | BERT |
| 注意力 | 双向 |
| 任务 | 分类、抽取、匹配 |

**原理**：双向注意力让每个位置同时看到左右上下文，适合需要完整理解输入的任务。典型预训练目标是掩码语言建模（Masked Language Modeling，MLM）。

## 7.2 Decoder-only

| 项目 | 说明 |
|------|------|
| 组成 | 只用解码器 |
| 代表 | GPT、LLaMA |
| 注意力 | 因果（单向） |
| 任务 | 生成、对话、通用 LLM |

**原理**：因果掩码保证自回归一致性，训练目标（下一 Token 预测）与推理过程完全一致，是当前大语言模型（LLM）的主流。

## 7.3 Encoder-Decoder

| 项目 | 说明 |
|------|------|
| 组成 | 编码器 + 解码器 |
| 代表 | T5、原始 Transformer |
| 注意力 | 编码器双向 + 解码器因果 |
| 任务 | 翻译、摘要、序列到序列 |

**边界与坑**：三种架构并非能力高低之分，而是任务适配之别。用 Encoder-only 做开放式生成、或用 Decoder-only 做双向理解，都需要额外的结构改造。

**要点**：

- Encoder-only 适合理解，Decoder-only 适合生成。
- Encoder-Decoder 适合序列到序列。
- Decoder-only 是 LLM 主流。

# 8. 参数分布

**结论先行**：Transformer 的参数主要分布在注意力的四个投影矩阵与前馈网络的两个矩阵上，其中前馈网络约占三分之二。

## 8.1 单层参数拆解

以 d_model = d 计：

| 模块 | 参数矩阵 | 参数量 |
|------|----------|--------|
| 注意力 | W_q、W_k、W_v、W_o | 4·d² |
| 前馈 | W₁、W₂ | 2·d·d_ff = 8·d² |
| 归一化 | γ、β | 4·d |
| 合计 | - | ≈ 12·d² |

## 8.2 总参数估算

**公式**：

```
总参数 ≈ 12 × L × d_model² + V × d_model
```

其中 L 为层数，V 为词表大小，最后一项为词表投影（常与 Embedding 共享）。

## 8.3 实例对照

```
以 Transformer-Base 为例（d_model=512, 6 层）：
  注意力：约 1/3 参数
  前馈网络：约 2/3 参数
```

| 模型 | d_model | L | 约算参数 |
|------|:-------:|:-:|:--------:|
| Base | 512 | 6 | 44M |
| Big | 1024 | 6 | 155M |

**边界与坑**：上述估算是量级近似，忽略了偏置、归一化与词表项；当 V 很大时，词表投影不可忽略。

**要点**：

- 前馈网络占参数大头（约 2/3）。
- 总参数近似 12·L·d_model²。
- 词表投影在大词表下不可忽略。

# 9. 为什么 Transformer 成功

**结论先行**：Transformer 成功的关键在于并行性、全局交互、可扩展性与通用性四点的叠加。

## 9.1 并行性与全局感受野

| 特性 | 优势 |
|------|------|
| 并行计算 | 不像 RNN 串行 |
| 全局注意力 | 任意位置直接交互 |

**原理**：训练时整个序列一次前向，充分利用 GPU 的矩阵运算能力；注意力让任意两位置一步可达，长程依赖不再衰减。

## 9.2 可扩展性与通用性

| 特性 | 优势 |
|------|------|
| 可扩展 | 加深加宽即可 |
| 通用 | 适配多种模态 |

**原理**：结构规整、无归纳偏置（Inductive Bias）过强，使得同一套结构能处理文本、图像、音频、代码；缩放定律（Scaling Law）表明参数、数据、算力同步增长可预测地提升性能。

## 9.3 局限与代价

**边界与坑**：

- O(n²) 复杂度限制超长上下文。
- 数据需求大，小数据下易过拟合。
- 缺乏显式结构先验，需要大量数据弥补。

**要点**：

- 并行 + 全局交互是效率基础。
- 可扩展 + 通用是规模基础。
- O(n²) 与数据需求是主要代价。

# 10. 常见误区

**结论先行**：理解 Transformer 时，若干直觉容易出错，澄清它们有助于正确建立心智模型。

## 10.1 关于注意力

| 误区 | 澄清 |
|------|------|
| 注意力权重就是可解释性 | 权重高不代表因果重要 |
| 多头等于多套独立模型 | 各头共享同一投影空间，最后拼接 |
| 注意力本身有非线性 | 注意力是加权求和，非线性来自 FFN 与 Softmax |

## 10.2 关于归一化与残差

| 误区 | 澄清 |
|------|------|
| LayerNorm 跨样本统计 | 它只在单样本特征维统计 |
| 残差可有可无 | 深层模型没有残差几乎无法训练 |
| Pre-LN 与 Post-LN 等价 | 梯度尺度与稳定性不同 |

**边界与坑**：不同实现对 LayerNorm 的 ε 位置、注意力缩放因子（1/√d_k）放置略有差异，迁移代码时需核对。

**要点**：

- 注意力权重不等于解释。
- LayerNorm 是逐样本的。
- 残差是深层训练的前提。

# 11. 小结

**结论先行**：Transformer 以"注意力 + 前馈 + 残差 + 归一化"为基本块，通过堆叠与变体适配理解、生成与序列到序列任务。

## 11.1 核心结论

- Transformer = 编码器 + 解码器（各 N 层）。
- 每层：注意力 + 前馈网络 + 残差 + 归一化。
- 前馈网络占参数大头。
- Pre-LN 是现代主流，更稳定。
- Decoder-only 是 LLM 的主流架构。

## 11.2 记忆口诀

```
理解用 Encoder，生成用 Decoder
注意换位置，前馈换特征
残差保梯度，Norm 稳分布
参数看前馈，稳定看 Pre-LN
```

**要点**：

- 掌握结构块即可推导各种变体。
- 记住参数与稳定性的两个关键点。
