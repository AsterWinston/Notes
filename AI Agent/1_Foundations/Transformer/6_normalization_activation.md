# 1. 为什么需要归一化

**结论先行**：深层网络的每一层都在改变输入的分布，导致后续层需要不断"追赶"新的分布，训练因此不稳定、收敛慢、对学习率敏感。归一化（Normalization）把每层的激活值重新标准化，使分布稳定，从而**加速收敛、允许更大学习率**。

## 1.1 内部协变量偏移

```
深层网络的问题：
- 各层输入分布不断变化（内部协变量偏移）
- 梯度消失/爆炸
- 训练不稳定
```

**原理**：随着前层参数更新，后层看到的输入分布持续漂移，这种现象被称为内部协变量偏移（Internal Covariate Shift）。它迫使后层不断适应新分布，削弱了参数更新的有效性。

### 1.1.1 一个直观类比

```
想象你在学开车，但每天的"方向盘转角"含义都在变：
  今天打 30 度左转，明天打 30 度却右转
→ 你永远学不会，因为规则一直在漂移

内部协变量偏移就是这种"规则漂移"
```

### 1.1.2 偏移从何而来

**原理**：每层输出的均值和方差依赖于该层权重，权重一更新，输出分布就变化；层数越深，累积漂移越明显。

## 1.2 梯度问题

**原理**：若激活值尺度过大，反向传播时梯度随之放大，容易爆炸；若尺度过小，梯度逐层衰减，容易消失。归一化把激活值拉回稳定尺度，使梯度保持在合理区间。

```
未归一化：
  激活值尺度失控 → 梯度爆炸 / 消失

归一化后：
  激活值尺度稳定 → 梯度稳定 → 可训练更深
```

## 1.3 归一化的收益

| 收益 | 说明 |
|------|------|
| 收敛更快 | 每步更新更有效 |
| 学习率更大 | 对尺度不敏感 |
| 更深网络 | 梯度稳定 |
| 初始化更鲁棒 | 对权重初始化不敏感 |

**边界与坑**：归一化并非万能，它增加了计算与显存开销；在极小的 batch 或序列长度下，统计量估计不稳，效果可能变差。

**要点**：

- 深层网络面临分布漂移与梯度问题。
- 归一化稳定分布，加速收敛。
- 代价是额外的计算开销。

# 2. LayerNorm

**结论先行**：层归一化（Layer Normalization，LayerNorm）对**单个样本的特征维度**做标准化，与 batch 大小无关，因此天然适合变长序列与自回归模型。

## 2.1 公式与原理

```
对每个样本的特征维度做归一化：

  μ = mean(x)
  σ = std(x)
  y = (x - μ) / σ × γ + β
```

**公式**：

```
LayerNorm(x) = γ ⊙ (x - μ) / √(σ² + ε) + β
μ = (1/d) Σ x_i
σ² = (1/d) Σ (x_i - μ)²
```

其中 γ、β 是可学习的缩放与平移参数，ε 是防止除零的小常数。

### 2.1.1 为什么用可学习的 γ、β

**原理**：强制标准化会限制表达力，γ、β 让网络在需要时恢复原始尺度与偏移，即"归一化但保留可调自由度"。

### 2.1.2 归一化维度

```
输入形状 (batch, seq_len, d_model)

LayerNorm 对最后一维 d_model 归一化：
  每个 (batch, seq_len) 位置各自独立统计
  → 与 batch、序列长度均无关
```

## 2.2 代码实现

```python
class LayerNorm(nn.Module):
    def __init__(self, d_model, eps=1e-5):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d_model))
        self.beta = nn.Parameter(torch.zeros(d_model))
        self.eps = eps

    def forward(self, x):
        mean = x.mean(-1, keepdim=True)
        std = x.std(-1, keepdim=True)
        return self.gamma * (x - mean) / (std + self.eps) + self.beta
```

| 特点 | 说明 |
|------|------|
| 按特征归一化 | 与 batch 无关 |
| 训练/推理一致 | 不依赖 batch |
| 适合序列 | RNN/Transformer |

## 2.3 与 BatchNorm 的对比

| 项目 | BatchNorm | LayerNorm |
|------|-----------|-----------|
| 统计维度 | batch 维度 | 特征维度 |
| 依赖 batch | 是 | 否 |
| 变长序列 | 不适配 | 适配 |
| 训练/推理 | 行为不同 | 行为一致 |
| 典型场景 | CNN | RNN/Transformer |

### 2.3.1 为什么 Transformer 选 LayerNorm

**原理**：序列长度可变，batch 内样本长度不一，BatchNorm 的 batch 统计量会被 padding 污染；LayerNorm 逐样本计算，天然规避该问题。

## 2.4 优缺点

| 优点 | 缺点 |
|------|------|
| 与 batch 无关 | 额外计算开销 |
| 训练推理一致 | 序列极短时统计不稳 |
| 适合变长序列 | 需额外的 γ、β 参数 |

**边界与坑**：实现中 std 是否加 eps、eps 加在根号内还是外，不同框架略有差异；迁移权重时需与训练实现一致。

**要点**：

- LayerNorm 按特征维度归一化。
- 与 batch 无关，适合序列。
- 是 Transformer 的标准归一化。

# 3. RMSNorm

**结论先行**：均方根归一化（Root Mean Square Normalization，RMSNorm）去掉均值中心化，只做缩放，用更少的计算获得与 LayerNorm 相当甚至更好的效果，是当前 LLM 的主流。

## 3.1 公式与原理

```
  rms = sqrt(mean(x²))
  y = x / rms × γ
```

**公式**：

```
RMSNorm(x) = γ ⊙ x / √(mean(x²) + ε)
```

**原理**：RMSNorm 假设"重新缩放"才是归一化的关键，而"重新居中"贡献有限，因此省去均值计算，只保留方差（均方根）缩放。

### 3.1.1 为什么可以去掉均值

**原理**：Transformer 中前后通常有残差连接，均值偏移可由后续线性层与残差自然吸收；实验也表明去掉中心化后效果不降反升，且更省算力。

## 3.2 代码实现

```python
class RMSNorm(nn.Module):
    def __init__(self, d_model, eps=1e-6):
        super().__init__()
        self.gamma = nn.Parameter(torch.ones(d_model))
        self.eps = eps

    def forward(self, x):
        rms = torch.sqrt(x.pow(2).mean(-1, keepdim=True) + self.eps)
        return x / rms * self.gamma
```

## 3.3 LayerNorm 与 RMSNorm 对比

| 对比 | LayerNorm | RMSNorm |
|------|-----------|---------|
| 均值中心化 | 有 | 无 |
| 参数 | γ, β | 只有 γ |
| 速度 | 慢 | 快（约 10%~20%） |
| 效果 | 好 | 相当或更好 |

> LLaMA、Qwen、DeepSeek 都用 RMSNorm。

### 3.3.1 计算量差异

**原理**：LayerNorm 需要算均值与方差两次归约，RMSNorm 只需算一次平方均值，减少了归约与同步开销，在 GPU 上体现为可观的吞吐提升。

## 3.4 数值稳定性

**边界与坑**：RMSNorm 的 eps 通常加在根号内，且比 LayerNorm 更小（如 1e-6）；若 eps 过大，会削弱归一化强度，导致深层训练不稳。

**要点**：

- RMSNorm 去掉均值中心化，只保留缩放。
- 参数更少、速度更快。
- 效果与 LayerNorm 相当或更好。
- 是 LLaMA、Qwen、DeepSeek 的选择。

# 4. Pre-LN 与 Post-LN

**结论先行**：归一化放在子层之前（Pre-LN）还是之后（Post-LN），决定了残差路径是否"干净"。Pre-LN 的残差是恒等通路，训练更稳定、无需 warmup，是现代主流。

## 4.1 Post-LN（原始设计）

```
Post-LN（原始）：
  x = LayerNorm(x + Sublayer(x))
  → 需 warmup，深层不稳定
```

**原理**：归一化位于残差相加之后，残差通路上每层都被归一化，梯度需穿过这些归一化层，深层时容易衰减，因此需要学习率预热（warmup）来稳定训练。

## 4.2 Pre-LN（现代设计）

```
Pre-LN（现代）：
  x = x + Sublayer(LayerNorm(x))
  → 更稳定，无需 warmup
```

**原理**：归一化只作用于子层输入，残差路径是一条不被改动的恒等通路，梯度可无损回传，因此训练稳定、对学习率不敏感。

### 4.2.1 结构对比图

```
Post-LN：               Pre-LN：
  ┌─────────┐             ┌─────────┐
  │ Sublayer│             │  Norm   │
  │    +    │             │ Sublayer│
  │  Norm   │             │    +    │
  └─────────┘             └─────────┘

Post-LN 归一化在残差之后
Pre-LN  归一化在残差之前
```

### 4.2.2 输出层归一化

**原理**：Pre-LN 的残差累加会使最终隐藏状态尺度随深度增长，因此现代实现常在最后一层加一个额外的归一化（final norm），再送入输出投影。

## 4.3 对比

| 类型 | 稳定性 | 是否需 warmup | 采用 |
|------|:------:|:-------------:|------|
| Post-LN | 差 | 需要 | 早期 |
| Pre-LN | 好 | 不需要 | 现代主流 |

## 4.4 其他变体

| 变体 | 思路 |
|------|------|
| Sandwich-LN | 子层前后各一次归一化 |
| DeepNorm | 调整残差缩放以支持超深网络 |
| Pre+Post 混合 | 兼顾稳定性与表达 |

### 4.4.1 DeepNorm 的缩放

**原理**：DeepNorm 在残差分支上乘一个小于 1 的缩放系数 α，抑制残差累积，使上千层的网络也能稳定训练。

**边界与坑**：Pre-LN 虽稳定，但在某些任务上略逊于精心调参的 Post-LN；切换结构需同步调整初始化与学习率策略。

**要点**：

- Post-LN 归一化在残差之后，需 warmup。
- Pre-LN 归一化在残差之前，稳定无需 warmup。
- 现代主流是 Pre-LN + 最终归一化。

# 5. 激活函数

**结论先行**：激活函数为网络引入非线性，是深层表达能力的来源。从 ReLU 到 GELU 再到 SiLU，趋势是"更平滑"；在 Transformer 中，门控激活 SwiGLU 已成为主流。

## 5.1 ReLU

**公式**：

```
ReLU(x) = max(0, x)
```

**原理**：计算简单、正区间梯度恒为 1，缓解梯度消失；但负区间梯度为 0，存在"神经元死亡"问题。

### 5.1.1 优点与局限

| 优点 | 局限 |
|------|------|
| 计算极快 | 负区间梯度为 0 |
| 稀疏激活 | 可能神经元死亡 |
| 缓解梯度消失 | 输出非零均值 |

## 5.2 GELU

**公式**：

```
GELU(x) = x · Φ(x)
```

其中 Φ(x) 是标准正态分布的累积分布函数。

**原理**：GELU 用概率方式对输入做"软门控"，接近 0 的输入被平滑压制，负值不会被硬性截断，因此比 ReLU 更平滑、更利于优化。

### 5.2.1 近似实现

```
GELU(x) ≈ 0.5x(1 + tanh(√(2/π)(x + 0.044715x³)))
```

该近似在工程中被广泛使用，兼顾精度与速度。

## 5.3 SiLU / Swish

**公式**：

```
SiLU(x) = x · sigmoid(x)
```

**原理**：SiLU（又称 Swish）同样是平滑非单调函数，负区间有小的负值输出，梯度不会完全消失，实验上常优于 ReLU。

## 5.4 激活函数对比

| 函数 | 公式 | 特点 | 代表模型 |
|------|------|------|----------|
| ReLU | max(0, x) | 简单，主流 | ResNet |
| GELU | x·Φ(x) | 平滑 | BERT/GPT |
| SiLU/Swish | x·sigmoid(x) | 平滑 | EfficientNet |
| SwiGLU | 门控变体 | LLM 主流 | LLaMA |

**边界与坑**：激活函数的选择与模型规模、初始化、归一化方式耦合，不能孤立比较；同一函数在不同框架下的默认实现也可能有细微差异。

**要点**：

- 激活函数提供非线性。
- 趋势是从 ReLU 到更平滑的 GELU、SiLU。
- 门控激活 SwiGLU 是 LLM 主流。

# 6. SwiGLU

**结论先行**：SwiGLU 是一种门控线性单元（Gated Linear Unit，GLU），用一路 SiLU 激活的结果去"门控"另一路线性变换，表达力更强；代价是需要三个权重矩阵，因此前馈维度需相应缩小以控制参数。

## 6.1 门控思想

```
门控（Gating）：
  一路输出作为"阀门"，逐元素控制另一路的通过量

  y = 激活(A(x)) ⊙ B(x)

⊙ 表示逐元素相乘
```

**原理**：门控让网络可以按输入动态调节信息流，相当于给每个通道一个数据相关的软开关，比固定非线性更灵活。

## 6.2 公式与维度

```
SwiGLU(x) = Swish(xW₁) ⊙ (xW₃) · W₂

需要三个权重矩阵（而非两个）
为保持参数量，d_ff 通常取 8/3 × d_model（而非 4×）
```

**公式**：

```
FFN_SwiGLU(x) = W₂ ( SiLU(W₁ x) ⊙ W₃ x )
```

### 6.2.1 为什么 d_ff 取 8/3

**原理**：标准 FFN 用两个矩阵（d→4d、4d→d），参数约 8d²；SwiGLU 用三个矩阵，若仍取 4d 则参数约 12d²。取 d_ff = (8/3)d 可使参数回到约 8d²，保持公平对比。

### 6.2.2 参数计算

```
标准 FFN：2 × d × 4d = 8d²
SwiGLU ：3 × d × (8/3)d = 8d²
→ 两者参数量相当
```

## 6.3 代码实现

```python
class SwiGLU(nn.Module):
    def __init__(self, d_model, d_ff):
        super().__init__()
        self.W1 = nn.Linear(d_model, d_ff, bias=False)
        self.W3 = nn.Linear(d_model, d_ff, bias=False)
        self.W2 = nn.Linear(d_ff, d_model, bias=False)

    def forward(self, x):
        return self.W2(F.silu(self.W1(x)) * self.W3(x))
```

> SwiGLU 被 LLaMA、PaLM 等采用，效果优于 ReLU。

## 6.4 为什么有效

**原理**：门控提供了乘法交互，使 FFN 能表达输入依赖的非线性；同时去掉了偏置项，减少参数并简化实现。多组实验表明，在同等参数量下 SwiGLU 的困惑度更低。

**边界与坑**：三个矩阵使前馈层的矩阵乘数量增加，虽然总参数持平，但实现上需要更高效的分组或融合核函数，否则吞吐可能下降。

**要点**：

- SwiGLU 用门控增强前馈网络表达力。
- 三个权重矩阵，d_ff 取 8/3 d_model。
- 参数量与标准 FFN 相当。
- 是 LLaMA、PaLM 的选择。

# 7. 现代 LLM 的典型配置

**结论先行**：现代 Decoder-only LLM 普遍采用"Pre-Norm + RMSNorm + SwiGLU + 去偏置"的组合，形成稳定、高效且易于扩展的逐层结构。

## 7.1 逐层结构

```
每个 Decoder 层：
  x = x + Attention(RMSNorm(x))       # Pre-Norm + RMSNorm
  x = x + SwiGLU(RMSNorm(x))          # Pre-Norm + SwiGLU
```

**原理**：两条残差支路分别接注意力与前馈，归一化放在各自输入侧，残差保持恒等通路，梯度稳定回传。

## 7.2 组件选择

| 组件 | 选择 |
|------|------|
| 归一化 | RMSNorm |
| 位置 | Pre-LN |
| 激活 | SwiGLU |
| 偏置 | 通常去掉 |

### 7.2.1 为什么去掉偏置

**原理**：归一化与残差已提供足够的偏移能力，线性层偏置贡献有限，去掉后可减少参数、提升访存效率，且对质量影响很小。

## 7.3 参数与开销

| 组件 | 参数占比（粗略） |
|------|:----------------:|
| 注意力 | 约 1/3 |
| 前馈 | 约 2/3 |
| 归一化 | 可忽略 |

**原理**：前馈层参数量通常是注意力的两倍左右，因此 MoE 等扩容手段主要作用于前馈层。

**边界与坑**：不同模型在归一化位置、是否使用 QK-Norm、是否保留偏置上存在差异，照搬某一模型的结构到另一模型可能不最优。

**要点**：

- 现代配置：Pre-Norm + RMSNorm + SwiGLU。
- 残差保持恒等通路。
- 偏置通常去掉。
- 前馈层是参数大头。

# 8. 常见误区

**结论先行**：关于归一化与激活的常见误解，多集中在"归一化作用对象""Pre/Post 优劣"与"激活可否随意替换"上。

## 8.1 关于归一化

| 误区 | 澄清 |
|------|------|
| LayerNorm 就是 BatchNorm | 统计维度不同，前者按特征 |
| RMSNorm 是近似 LayerNorm | 它主动去掉中心化，是有意设计 |
| 归一化一定提升精度 | 主要提升稳定性与速度 |

## 8.2 关于激活与结构

| 误区 | 澄清 |
|------|------|
| 激活函数可随意替换 | 与初始化、归一化耦合 |
| Pre-LN 全面优于 Post-LN | 稳定性更好，表达可能略降 |
| SwiGLU 参数量更大 | 调整 d_ff 后总参数持平 |

**边界与坑**：结构与激活的最优选择依赖规模与任务，小模型上的结论未必能外推到大模型，选型应以实测为准。

**要点**：

- LayerNorm 与 BatchNorm 维度不同。
- RMSNorm 是有意设计的简化。
- 激活与结构需整体考量。

# 9. 小结

**结论先行**：归一化稳定训练、激活引入非线性，二者共同支撑深层 Transformer；现代 LLM 收敛到 Pre-Norm + RMSNorm + SwiGLU 的稳定组合。

## 9.1 核心要点

- 归一化稳定训练、加速收敛。
- LayerNorm 按特征归一化，适合序列。
- RMSNorm 去掉均值中心化，更快，是 LLM 主流。
- Pre-LN 比 Post-LN 更稳定。
- SwiGLU 是现代 LLM 的主流激活。

## 9.2 记忆口诀

```
归一化稳分布，LayerNorm 按特征
RMSNorm 省均值，快上一两成
Pre-LN 走残差，梯度不衰减
激活要平滑，门控 SwiGLU
```

**要点**：

- 一根主线：稳定分布与梯度。
- 一个标配：Pre-Norm + RMSNorm。
- 一个激活：SwiGLU。
