# 1. 从离散到连续

**结论先行**：词向量（Word Embedding）把离散的词符号映射为低维稠密向量，让"语义相近"变成"距离相近"。

## 1.1 One-hot 表示

### 1.1.1 定义与示例

```
One-hot：每个词是一个高维稀疏向量
  "猫" → [0,0,1,0,...,0]   （词表 10000 维）
  问题：维度爆炸、无语义关系
```

### 1.1.2 数学形式

```
词表大小 V，第 i 个词的 one-hot 向量 e_i ∈ R^V：
  e_i[j] = 1  当 j = i
  e_i[j] = 0  当 j ≠ i
任意两个不同词的向量内积恒为 0
```

## 1.2 稠密词向量

### 1.2.1 定义

```
词向量：低维稠密向量
  "猫" → [0.2, -0.5, 0.8, ...]   （300 维）
  优点：维度低、有语义
```

### 1.2.2 为什么稠密更好

| 维度 | One-hot | 稠密向量 |
|------|---------|----------|
| 维度 | V（很大） | d（如 300） |
| 取值 | 0/1 | 实数 |
| 相似度 | 恒为 0 或 1 | 有连续含义 |
| 泛化 | 无 | 有 |

## 1.3 分布假设与表示学习

**结论先行**：稠密词向量的理论依据是分布假设——上下文相似的词，语义相似。

```
你吃了一个苹果
你吃了一个香蕉
→ 苹果与香蕉上下文相似 → 向量相近
```

```
表示学习：不手工设计特征，让模型从数据中学习向量
```

**边界与坑**：分布假设会混淆反义词（"好/坏"上下文相似），需要额外约束。

**要点**：One-hot 只有"是否同一个词"，稠密向量才有"有多像"。

# 2. One-hot 的问题

**结论先行**：One-hot 的四个致命问题是维度高、稀疏、无语义、无法泛化。

## 2.1 四个核心问题

| 问题 | 说明 |
|------|------|
| 维度高 | 词表多大就多少维 |
| 稀疏 | 只有一个 1 |
| 无语义 | 任意两词距离相同 |
| 无法泛化 | 同义词无关联 |

### 2.1.1 维度与稀疏

```
V = 100000 时，一个 one-hot 向量 99.999% 是 0
存储与计算浪费严重，且无法用于深层网络
```

### 2.1.2 无语义与无法泛化

```
"猫" 与 "狗" 的内积 = 0
"猫" 与 "汽车" 的内积 = 0
→ 模型无法知道前两者更相近
```

## 2.2 相似度视角

```
余弦相似度： cos(a, b) = (a · b) / (|a| · |b|)
One-hot：任意不同词 cos = 0，同词 cos = 1
→ 相似度矩阵是单位矩阵，不含任何语义
```

## 2.3 要点

**要点**：One-hot 是"符号的数字化"，不是"语义的向量化"。

# 3. Word2Vec

**结论先行**：Word2Vec 用"预测任务"训练词向量，让共现上下文相似的词获得相近向量。

## 3.1 核心思想

### 3.1.1 用上下文预测

**核心思想**：用上下文预测词（或反之），学习词向量。

```
不需要人工标注：语料本身就是监督信号（自监督）
输入一个词/上下文 → 预测另一个 → 反向传播更新向量
```

## 3.2 两种模型

### 3.2.1 CBOW

```
CBOW：用上下文预测中心词
  [我, ?, 学习] → 爱
```

### 3.2.2 Skip-gram

```
Skip-gram：用中心词预测上下文
  爱 → [我, ?, 学习]
```

| 模型 | 输入 | 输出 | 特点 |
|------|------|------|------|
| CBOW | 上下文词 | 中心词 | 快、平滑 |
| Skip-gram | 中心词 | 上下文词 | 慢、稀有词更好 |

## 3.3 训练目标与公式

### 3.3.1 Skip-gram 目标

```python
# Skip-gram 目标
# 最大化：log P(上下文词 | 中心词)
for center, context in windows(corpus):
    for ctx in context:
        loss = -log P(ctx | center)
```

```
目标函数：
  J = Σ_t Σ_{j∈[-m, m], j≠0} log P(w_{t+j} | w_t)
```

其中概率用 softmax 定义：

```
P(o | c) = exp(v_o · v_c) / Σ_{w∈V} exp(v_w · v_c)
```

### 3.3.2 负采样

```
softmax 分母要遍历整个词表，代价高
负采样：只从"噪声词"中抽 k 个，把多分类变成二分类
```

```
损失（负采样）：
  J = log σ(v_o · v_c) + Σ_{i=1..k} log σ(-v_{n_i} · v_c)
```

### 3.3.3 层次 Softmax

```
用霍夫曼树把 V 分类变成 log V 次二分类
→ 每步只需计算路径上的节点
```

## 3.4 著名的向量运算

### 3.4.1 类比

```
king - man + woman ≈ queen
巴黎 - 法国 + 日本 ≈ 东京
```

> 说明词向量捕捉到了**语义关系**。

### 3.4.2 为何成立

```
若"性别""国都"等语义维度在向量空间中近似线性可分，
则类比关系表现为向量加减
```

**边界与坑**：类比并非总是成立，低频词与多义词上误差较大。

## 3.5 超参数与技巧

| 参数 | 常用值 | 说明 |
|------|--------|------|
| 向量维度 | 100~300 | 越大表达越强 |
| 窗口大小 | 2~10 | 越大越偏主题 |
| 负采样数 | 5~20 | 平衡速度与质量 |
| 最小词频 | 5 | 过滤罕见词 |

**要点**：Word2Vec 把词向量学习变成自监督预测任务，是表示学习的开端。

# 4. GloVe

**结论先行**：GloVe 用全局共现矩阵分解得到词向量，强调"全局统计"而非局部窗口。

## 4.1 核心思想

### 4.1.1 全局共现

```
基于全局共现统计：
  构建词-词共现矩阵
  分解矩阵得到词向量
```

```
X_ij = 词 j 出现在词 i 上下文中的次数
```

### 4.1.2 目标函数

```
J = Σ_{i,j} f(X_ij) · (v_i · v_j + b_i + b_j - log X_ij)^2
f 为加权函数，抑制高频对的过大权重
```

## 4.2 与 Word2Vec 对比

| 对比 | Word2Vec | GloVe |
|------|----------|-------|
| 信息 | 局部窗口 | 全局共现 |
| 训练 | 预测任务 | 矩阵分解 |
| 目标 | 预测概率 | 拟合共现对数 |

**边界与坑**：GloVe 需先统计全量共现矩阵，内存开销大；二者效果接近。

**要点**：Word2Vec 看局部，GloVe 看全局，都是静态词向量。

# 5. 静态词向量的局限

**结论先行**：静态词向量对每个词只有一个向量，无法处理一词多义。

## 5.1 一词多义

### 5.1.1 问题

```
一词多义问题：
  "苹果"（水果）与 "苹果"（公司）用同一个向量
```

### 5.1.2 例子

| 词 | 义项 1 | 义项 2 |
|----|--------|--------|
| 苹果 | 水果 | 科技公司 |
| 银行 | 金融机构 | 河岸 |
| 打 | 打人 | 打车 |

> 这催生了**上下文相关表示**（ELMo、BERT）。

## 5.2 其他局限

| 局限 | 说明 |
|------|------|
| 多义 | 一词一向量 |
| 静态 | 不随语境变化 |
| 词表固定 | 未登录词无向量 |
| 无词形 | 大小写、时态不敏感 |

## 5.3 要点

**要点**：静态词向量是"词的平均语义"，丢失了语境信息。

# 6. 上下文相关表示

**结论先行**：上下文相关表示让同一个词在不同句子中得到不同向量，解决了多义问题。

## 6.1 从静态到动态

### 6.1.1 ELMo

```
ELMo：用双向 LSTM 提取上下文化表示
  不同层的输出加权求和，得到该词在当前句中的向量
```

### 6.1.2 BERT

```
BERT：同一词在不同语境得到不同向量
  "我去银行取钱"     → 银行₁（金融机构）
  "河边的银行"       → 银行₂（河岸）
```

### 6.1.3 GPT

```
GPT：自回归 Transformer，同样产生上下文化表示
  更擅长生成，也可取中间层向量用于理解
```

## 6.2 静态与动态对比

| 类型 | 特点 | 代表 |
|------|------|------|
| 静态 | 一词一向量 | Word2Vec、GloVe |
| 动态 | 随上下文变化 | ELMo、BERT、GPT |

## 6.3 获取上下文向量的方法

```
① 取最后一层隐藏状态
② 取多层加权（如 ELMo）
③ 取 [CLS]/[EOS] 作为句表示
④ 取所有 token 向量的平均/池化
```

## 6.4 要点

**要点**：动态表示质量更高，但推理成本与缓存复杂度也更高。

# 7. 句向量

**结论先行**：句向量把整句编码为一个向量，是对比学习训练的结果，是 RAG 检索的基础。

## 7.1 从词向量到句向量

```
词向量 → 平均/池化 → 句向量
BERT → [CLS] token 的向量 → 句向量
```

| 方法 | 说明 |
|------|------|
| 平均词向量 | 简单但效果一般 |
| [CLS] 向量 | BERT 的做法 |
| 对比学习 | 专门训练的句向量模型（推荐） |

### 7.1.1 平均池化

```
s = (1/n) · Σ_i v_i
优点：简单、无需训练
缺点：忽略语序与重点
```

### 7.1.2 [CLS] 向量

```
BERT 在句首插入 [CLS]，其输出被设计为句表示
缺点：原始 BERT 的 [CLS] 未针对相似度优化
```

### 7.1.3 对比学习

```
正样本对（相似句）拉近，负样本对（不相似句）推远
常用 InfoNCE 损失
```

```
InfoNCE：
  L = -log [ exp(sim(q, k+)/τ) / Σ_i exp(sim(q, k_i)/τ) ]
τ 为温度系数，控制分布尖锐程度
```

> 现代 RAG 用**对比学习训练的句向量模型**（BGE、E5、GTE），详见 `5_embedding_models.md`。

## 7.2 相似度度量

### 7.2.1 余弦相似度

```
cos(a, b) = (a · b) / (|a| · |b|)
取值 [-1, 1]，只关心方向，不关心长度
```

### 7.2.2 点积与欧氏距离

| 度量 | 公式 | 特点 |
|------|------|------|
| 余弦 | a·b / (\|a\|\|b\|) | 归一化后等价于点积 |
| 点积 | a·b | 受长度影响 |
| 欧氏 | \|\|a-b\|\| | 受长度影响 |

## 7.3 常见句向量模型

| 模型 | 特点 |
|------|------|
| BGE | 中文强、多尺寸 |
| E5 | 英文强、指令式 |
| GTE | 通用、多语言 |

## 7.4 边界与坑

```
坑：用生成模型的原始输出直接做检索 → 效果差
坑：不同模型向量空间不可混用
坑：未归一化就做点积 → 长度主导相似度
```

## 7.5 要点

**要点**：句向量模型与生成模型是两套用途，RAG 检索要用专门训练的句向量。

# 8. 词向量的用途

**结论先行**：词/句向量的核心用途是语义相似度、语义检索、聚类与下游特征。

## 8.1 语义相似度

| 用途 | 说明 |
|------|------|
| 语义相似度 | 计算向量距离 |
| 同义改写检测 | 判断两段文本是否等价 |

## 8.2 语义检索

| 用途 | 说明 |
|------|------|
| 语义检索 | RAG 的基础 |
| 向量数据库 | 近邻搜索（ANN） |

```
查询向量 → ANN 检索 → Top-K 文档 → 交给 LLM
```

## 8.3 聚类与特征

| 用途 | 说明 |
|------|------|
| 聚类 | 相似词聚类 |
| 特征 | 下游任务输入 |
| 可视化 | t-SNE / UMAP 观察语义结构 |

## 8.4 要点

**要点**：Embedding 是"把语义变成可计算距离"的通用工具。

# 9. 演进脉络

**结论先行**：从 One-hot 到多模态 Embedding，演进主线是"表示越来越依赖上下文、越来越通用"。

## 9.1 阶段总览

```
One-hot（无语义）
  ↓
Word2Vec/GloVe（静态语义）
  ↓
ELMo/BERT（上下文相关）
  ↓
句向量模型（BGE/E5/GTE，RAG 用）
  ↓
多模态 Embedding（CLIP 等）
```

| 阶段 | 表示单位 | 代表 |
|------|----------|------|
| 离散 | 词 | One-hot |
| 静态 | 词 | Word2Vec、GloVe |
| 动态 | 词 | ELMo、BERT |
| 句级 | 句/段 | BGE、E5、GTE |
| 多模态 | 图/文 | CLIP |

## 9.2 多模态 Embedding

```
CLIP：把图像与文本映射到同一向量空间
  相似图文距离近 → 支持以文搜图、零样本分类
```

## 9.3 要点

**要点**：表示粒度从词到句再到多模态，统一趋势是"共享向量空间"。

# 10. 小结

- 词向量把离散词映射为低维稠密向量，捕捉语义。
- One-hot 维度高、稀疏、无语义、无法泛化。
- Word2Vec（CBOW/Skip-gram）与 GloVe 是静态词向量，无法处理一词多义。
- BERT/GPT 产生上下文相关表示，同一词随语境变化。
- 句向量模型是对比学习训练，用于 RAG 检索。
- 词向量的用途：相似度、检索、聚类、下游特征。
- 演进：One-hot → 静态 → 动态 → 句向量 → 多模态。
