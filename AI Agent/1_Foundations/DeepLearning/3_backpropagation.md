# 1. 训练的目标

## 1.1 损失最小化

### 1.1.1 目标函数

**结论先行**：训练就是找到使损失函数最小的参数。

**原理**：把参数 θ 看作自变量，损失 L(θ) 是优化目标。

```
找到一组参数，使损失函数最小：
  θ* = argmin L(θ)
```

**边界与坑**：损失是训练代理指标，最小化损失不保证业务指标最优。

**要点**：训练 = 数值优化问题。

### 1.1.2 优化视角

**结论先行**：深度学习是非凸、高维、随机优化。

**原理**：参数空间维度可达数十亿，且每次只用一批数据估计梯度。

**边界与坑**：非凸意味着只能求局部最优，但实践中足够好。

**要点**：接受近似最优，关注泛化。

## 1.2 参数与超参数

**结论先行**：参数由训练得到，超参数由人设定。

**原理**：参数是权重与偏置；超参数控制训练过程本身。

| 类别 | 例子 | 来源 |
|------|------|------|
| 参数 | 权重、偏置 | 训练学习 |
| 超参数 | 学习率、批大小 | 人工/搜索 |

**边界与坑**：混淆两者会导致错误的调优思路。

**要点**：分清"学"与"调"。

# 2. 计算图

## 2.1 前向与反向

### 2.1.1 计算图表示

**结论先行**：计算图把前向计算表示成有向图，反向沿图回传梯度。

**原理**：每个节点是一个运算，边传递张量。

```
前向：x → [×W] → [＋b] → [ReLU] → [×W2] → ŷ → [Loss]
反向：← 梯度逐层回传 ←───────────────────────────────
```

**边界与坑**：图在每次前向时动态构建（PyTorch），需注意内存释放。

**要点**：反向传播 = 在计算图上用链式法则求梯度。

### 2.1.2 反向模式自动微分

**结论先行**：反向模式一次前向即可求出所有参数梯度。

**原理**：反向模式（reverse-mode autodiff）从标量损失出发，自后向前应用链式法则，复杂度与参数量近似线性。

**边界与坑**：需要保存前向中间结果，显存占用大。

**要点**：反向模式适合"多参数、单输出"的神经网络。

## 2.2 自动微分实践

**结论先行**：框架自动完成求导，用户只需搭前向。

```python
loss.backward()          # 自动求所有梯度
optimizer.step()         # 更新参数
```

**原理**：张量记录计算历史，反向时自动回放。

**边界与坑**：推理时用 torch.no_grad() 关闭建图以省显存。

**要点**：理解原理，善用自动微分。

# 3. 链式法则

## 3.1 单变量链式法则

### 3.1.1 公式

**结论先行**：复合函数的导数等于各层导数相乘。

**原理**：链式法则（chain rule，链式法则）是反向传播的数学核心。

```
若 y = f(g(x))，则：
  dy/dx = dy/dg · dg/dx
```

**边界与坑**：连乘会导致数值过大或过小，是梯度问题的根源。

**要点**：链式法则是反向传播的全部。

### 3.1.2 多层展开

**结论先行**：多层网络逐层应用链式法则。

**原理**：梯度从损失开始，一层层向前传播。

```
多层网络中逐层应用：
  ∂L/∂W1 = ∂L/∂y · ∂y/∂h · ∂h/∂W1
```

**边界与坑**：中间项写错一个就会导致整个梯度错误。

**要点**：逐层复用上游梯度可避免重复计算。

## 3.2 向量与矩阵情形

**结论先行**：向量情形下链式法则对应雅可比矩阵相乘。

**原理**：设 y = f(z)、z = Wx，则 ∂L/∂W = (∂L/∂y) (∂y/∂z) xᵀ。

**边界与坑**：矩阵乘法顺序与转置极易写错，需用形状反推。

**要点**：用维度检查矩阵求导顺序。

# 4. 反向传播示例

## 4.1 前向与反向

### 4.1.1 前向计算

**结论先行**：先完整前向并保存中间量。

```python
# 前向
z1 = x @ W1 + b1
h1 = relu(z1)
z2 = h1 @ W2 + b2
y  = softmax(z2)
loss = cross_entropy(y, target)
```

**原理**：z1、h1、z2、y 都要保留供反向使用。

**边界与坑**：不保存中间量则无法求梯度。

**要点**：前向保存中间结果。

### 4.1.2 反向计算

**结论先行**：从损失开始逐层回传梯度。

```python
# 反向
dL_dz2 = y - target                    # softmax + 交叉熵的梯度
dL_dW2 = h1.T @ dL_dz2
dL_db2 = dL_dz2.sum(axis=0)
dL_dh1 = dL_dz2 @ W2.T
dL_dz1 = dL_dh1 * (z1 > 0)             # ReLU 导数
dL_dW1 = x.T @ dL_dz1
dL_db1 = dL_dz1.sum(axis=0)
```

**原理**：每一步都是链式法则的矩阵化表达。

**边界与坑**：偏置梯度要对 batch 维度求和。

**要点**：反向顺序与前向严格相反。

## 4.2 关键梯度推导

### 4.2.1 softmax 与交叉熵

**结论先行**：softmax 加交叉熵的梯度就是"预测减标签"。

**原理**：两者组合后雅可比被极大简化。

```
∂L/∂z = ŷ - y
```

**边界与坑**：分开实现会丢失这一简化并带来数值不稳定。

**要点**：softmax 与交叉熵应联合使用。

### 4.2.2 ReLU 导数

**结论先行**：ReLU 的导数是 0 或 1 的掩码。

**原理**：正区导数为 1，负区为 0。

```
ReLU'(z) = 1 (z > 0), 0 (z ≤ 0)
```

**边界与坑**：z = 0 处不可导，实践中取 0 即可。

**要点**：用掩码实现即可。

# 5. 梯度下降

## 5.1 更新规则

### 5.1.1 公式

**结论先行**：沿负梯度方向更新参数。

```
θ ← θ - η · ∂L/∂θ
```

| 符号 | 含义 |
|------|------|
| θ | 参数 |
| η | 学习率 |
| ∂L/∂θ | 梯度 |

**原理**：负梯度是损失下降最快的方向。

**边界与坑**：η 过大震荡，过小收敛慢。

**要点**：梯度下降是训练的基本更新规则。

### 5.1.2 几何直觉

**结论先行**：像下山一样沿最陡方向走一步。

```
        Loss
         │    ╱
         │   ╱
         │  ●  ← 当前位置
         │ ╱ ↘ 梯度方向
         │╱   ↘
         └────────▶ θ
```

**原理**：梯度指向上升方向，故取反方向下降。

**边界与坑**：非凸地形中可能陷入鞍点或局部极小。

**要点**：负梯度方向保证局部下降。

## 5.2 收敛与步长

**结论先行**：步长决定收敛速度与稳定性。

**原理**：合适的 η 兼顾速度与稳定。

**边界与坑**：学习率调度通常优于固定学习率。

**要点**：学习率是最重要的超参数。

# 6. 三种梯度下降

## 6.1 类型对比

### 6.1.1 三种方式

**结论先行**：按每次使用的样本数划分。

| 类型 | 每次用 | 特点 |
|------|--------|------|
| 批量（BGD） | 全部数据 | 稳定但慢 |
| 随机（SGD） | 单样本 | 快但震荡 |
| 小批量（Mini-batch） | 一批 | 平衡（主流） |

**原理**：样本越多梯度越准，但单步越慢。

**边界与坑**：批过小噪声大，批过大显存不足且泛化可能变差。

**要点**：小批量是工业界默认选择。

### 6.1.2 选择建议

**结论先行**：优先小批量并配合合适学习率。

**原理**：小批量在噪声与效率间取得平衡，还能利用 GPU 并行。

**边界与坑**：改变批大小通常需要同步调整学习率。

**要点**：批大小与学习率联合调优。

## 6.2 小批量实现

**结论先行**：一轮循环即可实现小批量训练。

```python
for batch in dataloader:      # batch_size = 32
    loss = compute_loss(model, batch)
    loss.backward()
    optimizer.step()
```

**原理**：每个 batch 更新一次参数。

**边界与坑**：别忘了 optimizer.zero_grad()。

**要点**：小批量训练是主流范式。

# 7. 优化器

## 7.1 从 SGD 到自适应

### 7.1.1 动量

**结论先行**：动量（Momentum）累积历史梯度以加速收敛。

**原理**：v ← βv + ∇L，θ ← θ - ηv，抑制震荡。

**边界与坑**：动量过大可能越过最优点。

**要点**：动量显著加速并平滑训练。

### 7.1.2 自适应学习率

**结论先行**：AdaGrad/RMSProp 按参数自适应调整步长。

**原理**：用历史梯度平方的滑动平均缩放每个参数的步长。

**边界与坑**：AdaGrad 累积过久会使步长趋零。

**要点**：自适应方法减少调参负担。

## 7.2 现代优化器

### 7.2.1 Adam 与 AdamW

**结论先行**：Adam 结合动量与自适应，AdamW 修正权重衰减。

| 优化器 | 特点 |
|--------|------|
| SGD | 基础，需调学习率 |
| SGD + Momentum | 加动量，加速收敛 |
| AdaGrad | 自适应学习率 |
| RMSProp | 改进 AdaGrad |
| Adam | 动量 + 自适应（常用） |
| AdamW | Adam + 权重衰减修正（LLM 常用） |

```python
# AdamW
optimizer = torch.optim.AdamW(
    model.parameters(), lr=1e-4, weight_decay=0.01)
```

**原理**：AdamW 将权重衰减与梯度更新解耦，正则更有效。

**边界与坑**：Adam 有时泛化略逊于调好的 SGD+Momentum。

**要点**：默认用 AdamW，追求极致可试 SGD。

### 7.2.2 选择建议

**结论先行**：快速实验用 AdamW，精调可用 SGD。

**原理**：自适应方法收敛快，SGD 在部分视觉任务上泛化更好。

**边界与坑**：切换优化器后需重新调学习率。

**要点**：优化器与任务强相关。

# 8. 学习率调度

## 8.1 常见策略

### 8.1.1 固定与衰减

**结论先行**：训练后期降低学习率有助于收敛。

**原理**：早期大步探索，后期小步精调。

```
学习率过大：震荡不收敛
学习率过小：收敛慢、易陷局部最优
```

| 策略 | 说明 |
|------|------|
| 固定 | 简单 |
| 衰减 | 随训练降低 |
| Warmup | 先升后降（LLM 常用） |
| Cosine | 余弦退火 |

**边界与坑**：衰减过快会导致欠拟合。

**要点**：衰减是通用有效手段。

### 8.1.2 Warmup 与 Cosine

**结论先行**：Warmup 加 Cosine 是现代 LLM 的标准调度。

**原理**：先线性升温避免早期发散，再按余弦曲线退火。

**边界与坑**：Warmup 步数过短起不到稳定作用。

**要点**：大规模训练几乎必用 Warmup。

## 8.2 实践

**结论先行**：调度器可直接调用现成实现。

```python
# Warmup + Cosine
scheduler = get_cosine_schedule_with_warmup(
    optimizer, num_warmup_steps=1000,
    num_training_steps=100000)
```

**原理**：每个 step 后调用 scheduler.step()。

**边界与坑**：忘记调用 scheduler.step() 调度不会生效。

**要点**：调度器需按步更新。

# 9. 梯度问题

## 9.1 消失与爆炸

### 9.1.1 成因

**结论先行**：深层连乘使梯度指数级缩小或放大。

**原理**：每层导数小于 1 则连乘趋零，大于 1 则趋无穷。

| 问题 | 现象 | 对策 |
|------|------|------|
| 梯度消失 | 深层不更新 | ReLU、残差连接、归一化 |
| 梯度爆炸 | 参数发散 | 梯度裁剪、归一化 |

**边界与坑**：两者常同时出现，需综合治理。

**要点**：梯度问题是深层网络的核心挑战。

### 9.1.2 对策

**结论先行**：残差、归一化、合适初始化共同缓解。

**原理**：残差提供恒等捷径，归一化稳定分布。

**边界与坑**：单一手段往往不足，需组合使用。

**要点**：工程手段与架构设计并重。

## 9.2 梯度裁剪

**结论先行**：裁剪把梯度的范数限制在阈值内。

**原理**：超阈值时按比例缩放，防止单步更新过大。

```python
# 梯度裁剪
torch.nn.utils.clip_grad_norm_(
    model.parameters(), max_norm=1.0)
```

**边界与坑**：阈值过小会拖慢训练，需按任务设定。

**要点**：RNN/Transformer 训练常用梯度裁剪。
