# 1. 神经元

## 1.1 结构与公式

### 1.1.1 单个神经元

**结论先行**：神经元 = 加权求和 + 偏置 + 激活函数。

**原理**：先对输入做线性组合，再经非线性变换输出。

```
        x1 ──w1──┐
        x2 ──w2──┼──▶ Σ + b ──▶ f(·) ──▶ 输出
        x3 ──w3──┘
```

```
输出 = 激活函数( w1·x1 + w2·x2 + w3·x3 + b )
```

**边界与坑**：偏置 b 不可省，否则决策面被迫经过原点，表达能力受限。

**要点**：神经元是最小计算单元。

### 1.1.2 符号与矩阵视角

**结论先行**：多个神经元可用矩阵乘法一次算完。

**原理**：z = Wx + b，W 的每一行对应一个神经元的权重向量。

| 符号 | 含义 |
|------|------|
| x | 输入 |
| w | 权重（可学习） |
| b | 偏置（可学习） |
| f | 激活函数 |

**边界与坑**：批量输入维度为 (batch, features)，矩阵方向写反会广播错误。

**要点**：矩阵化是高效实现的基础。

## 1.2 为什么需要激活函数

### 1.2.1 线性退化的证明

**结论先行**：没有激活函数，多层网络等价于单层。

**原理**：线性映射的复合仍是线性映射。

```
没有激活函数：
  多层线性变换 = 一层线性变换（无法拟合非线性）

有激活函数：
  引入非线性 → 网络可以拟合任意复杂函数
```

**边界与坑**：输出层用于回归时可保持线性，但隐藏层必须非线性。

**要点**：隐藏层的非线性不可省。

### 1.2.2 非线性的作用

**结论先行**：非线性让决策边界可以弯曲。

**原理**：激活函数逐元素变换线性输出，改变特征空间的几何形状。

**边界与坑**：非线性过强或选择不当会导致训练不稳定。

**要点**：非线性决定表达能力。

# 2. 常用激活函数

## 2.1 经典函数

### 2.1.1 Sigmoid 与 Tanh

**结论先行**：两者都是 S 形压缩函数，易梯度消失。

**原理**：Sigmoid 把实数压到 (0,1)，Tanh 压到 (-1,1)。

```
σ(x) = 1 / (1 + e^(-x))
tanh(x) = (e^x - e^(-x)) / (e^x + e^(-x))
```

**边界与坑**：输入绝对值大时导数趋近 0，深层网络梯度消失。

**要点**：适合输出层概率，不适合深层隐藏层。

### 2.1.2 ReLU

**结论先行**：ReLU 简单且缓解梯度消失，是主流选择。

**原理**：负半轴置零，正半轴恒等，导数在正区恒为 1。

```
ReLU(x) = max(0, x)
```

```python
def relu(x):
    return max(0, x)
```

**边界与坑**：负区梯度为零，可能"神经元死亡"，可用 LeakyReLU 缓解。

**要点**：默认隐藏层激活函数。

## 2.2 现代变体

### 2.2.1 GELU

**结论先行**：GELU 平滑，Transformer 常用。

**原理**：用高斯累积分布函数 Φ(x) 做门控。

```
GELU(x) = x · Φ(x)
```

```python
# GELU（近似）
def gelu(x):
    return 0.5 * x * (1 + math.tanh(
        math.sqrt(2 / math.pi) * (x + 0.044715 * x ** 3)))
```

**边界与坑**：计算比 ReLU 略贵，但训练更平滑。

**要点**：Transformer 的默认选择。

### 2.2.2 SwiGLU 与门控

**结论先行**：门控变体用两条支路相乘，表达力更强。

**原理**：SwiGLU 将 Swish 与线性门控结合。

```
SwiGLU(x) = Swish(W1 x) ⊙ (W2 x)
```

**边界与坑**：引入额外参数与计算，需权衡。

**要点**：LLM 中广泛使用。

## 2.3 对比与选择

**结论先行**：按层类型与任务选择激活函数。

| 函数 | 公式 | 特点 |
|------|------|------|
| Sigmoid | 1/(1+e⁻ˣ) | 输出 0~1，易梯度消失 |
| Tanh | (eˣ-e⁻ˣ)/(eˣ+e⁻ˣ) | 输出 -1~1，仍会消失 |
| ReLU | max(0, x) | 简单、缓解梯度消失（主流） |
| GELU | x·Φ(x) | 平滑，Transformer 常用 |
| SwiGLU | 门控变体 | LLM 常用 |

**边界与坑**：不要在所有层机械使用同一激活函数；输出层要匹配任务。

**要点**：隐藏层用 ReLU/GELU，输出层用任务对应形式。

# 3. 前向传播

## 3.1 从单层到多层

### 3.1.1 单层计算

**结论先行**：单层 = 矩阵乘 + 偏置 + 激活。

**原理**：h = f(Wx + b)。

```python
def linear(x, W, b):
    return W @ x + b

def layer(x, W, b):
    return relu(linear(x, W, b))
```

**边界与坑**：矩阵维度需满足 (out, in) @ (in, batch)。

**要点**：层是前向传播的积木。

### 3.1.2 网络堆叠

**结论先行**：多层堆叠即前向传播。

**原理**：上一层的输出是下一层的输入。

```
输入 → 隐藏层1 → 隐藏层2 → ... → 输出层
每一层：线性变换 + 激活函数
```

**边界与坑**：层数增加会累积数值误差，需要归一化。

**要点**：前向传播逐层计算直到输出。

## 3.2 实现示例

### 3.2.1 两层网络

**结论先行**：两层网络一次前向只需两次线性变换。

```python
# 两层网络的前向传播
def forward(x, W1, b1, W2, b2):
    h = relu(W1 @ x + b1)      # 隐藏层
    y = softmax(W2 @ h + b2)   # 输出层
    return y
```

**原理**：隐藏层提取特征，输出层给出类别概率。

**边界与坑**：softmax 应配合交叉熵一起使用以保证数值稳定。

**要点**：隐藏层 + 输出层是最小完整网络。

### 3.2.2 形状检查

**结论先行**：调试网络先看张量形状。

| 变量 | 形状 | 说明 |
|------|------|------|
| x | (batch, in) | 输入 |
| W1 | (hidden, in) | 第一层权重 |
| h | (batch, hidden) | 隐藏表示 |
| W2 | (out, hidden) | 第二层权重 |
| y | (batch, out) | 输出概率 |

**边界与坑**：形状不匹配是新手最常见的报错来源。

**要点**：先核对形状，再谈训练。

# 4. 损失函数

## 4.1 分类：交叉熵

### 4.1.1 原理

**结论先行**：交叉熵衡量两个概率分布的差异。

**原理**：模型输出概率越接近真实标签，损失越小。

```
L = -Σ_i y_i · log(p_i)
```

**边界与坑**：softmax 与交叉熵合并实现可避免溢出。

**要点**：分类任务的标准损失。

### 4.1.2 代码

**结论先行**：一行即可实现交叉熵。

```python
# 交叉熵（分类）
def cross_entropy(pred, target):
    return -sum(target[i] * math.log(pred[i])
                for i in range(len(pred)))
```

**边界与坑**：pred 为 0 时 log 溢出，需加极小值或使用框架实现。

**要点**：优先用框架的稳定实现。

## 4.2 回归：MSE

**结论先行**：均方误差适合连续值预测。

**原理**：对残差平方求平均。

```
MSE = (1/n) Σ_i (y_i - ŷ_i)^2
```

| 任务 | 损失函数 | 说明 |
|------|----------|------|
| 分类 | 交叉熵 | 衡量概率分布差异 |
| 回归 | MSE | 均方误差 |
| 生成 | 交叉熵 | 下一 token 预测 |

**边界与坑**：异常值会显著拉大 MSE，可改用 MAE/Huber。

**要点**：损失与任务输出形式匹配。

## 4.3 生成任务

**结论先行**：生成任务通常也归结为交叉熵。

**原理**：自回归模型预测下一个 token 的分布，与真实 token 比较。

```
L = -log p(token_t | token_<t)
```

**边界与坑**：token 级损失不等价于句子级质量。

**要点**：LLM 预训练即下一 token 预测。

# 5. 网络结构

## 5.1 层与宽度

### 5.1.1 基本概念

**结论先行**：层数决定深度，神经元数决定宽度。

```
输入层        隐藏层        输出层
  ●  ────────  ●  ────────  ●
  ●  ────────  ●  ────────  ●
  ●  ────────  ●
                ●
```

| 概念 | 说明 |
|------|------|
| 层数 | 网络的深度 |
| 神经元数 | 每层的宽度 |
| 参数量 | 权重 + 偏置总数 |
| 全连接 | 每层神经元与上层全部相连 |

**边界与坑**：过宽易过拟合，过深难训练，需按数据规模权衡。

**要点**：深度与宽度共同决定容量。

### 5.1.2 全连接层

**结论先行**：全连接层每个输出与全部输入相连。

**原理**：参数量为 in × out + out。

**边界与坑**：全连接参数量大，图像任务常用卷积替代。

**要点**：全连接是最基础的层类型。

## 5.2 参数量估算

### 5.2.1 公式

**结论先行**：参数量为各层权重与偏置之和。

```
参数量 ≈ Σ (上一层神经元数 × 本层神经元数 + 本层偏置)
```

**原理**：每个连接一个权重，每个输出神经元一个偏置。

**边界与坑**：估算不含激活与归一化参数。

**要点**：参数量决定显存与过拟合风险。

### 5.2.2 示例计算

**结论先行**：784 → 128 → 10 共约 10 万参数。

```
例：784 → 128 → 10
  第一层：784×128 + 128 = 100,480
  第二层：128×10 + 10 = 1,290
  总计：101,770
```

**边界与坑**：输入维度改变会线性影响第一层参数量。

**要点**：手工估算有助于预判模型规模。

# 6. 一个完整示例

## 6.1 从零实现

### 6.1.1 类定义

**结论先行**：用 NumPy 即可实现两层网络。

```python
import numpy as np

class NeuralNetwork:
    def __init__(self, input_size, hidden_size, output_size):
        self.W1 = np.random.randn(input_size, hidden_size) * 0.01
        self.b1 = np.zeros(hidden_size)
        self.W2 = np.random.randn(hidden_size, output_size) * 0.01
        self.b2 = np.zeros(output_size)
```

**原理**：小随机数初始化权重，偏置初始化为零。

**边界与坑**：全部初始化为零会导致对称性无法打破。

**要点**：随机初始化是训练的前提。

### 6.1.2 前向与损失

**结论先行**：前向计算隐藏层与输出层。

```python
    def forward(self, x):
        self.h = np.maximum(0, x @ self.W1 + self.b1)   # ReLU
        self.y = softmax(self.h @ self.W2 + self.b2)
        return self.y
```

**原理**：ReLU 隐藏层 + softmax 输出。

**边界与坑**：需保存中间量供反向传播使用。

**要点**：前向保存中间结果，反向才能复用。

## 6.2 用框架实现

### 6.2.1 PyTorch 版本

**结论先行**：框架自动完成求导，代码更短。

```python
import torch

model = torch.nn.Sequential(
    torch.nn.Linear(784, 128),
    torch.nn.ReLU(),
    torch.nn.Linear(128, 10),
)
loss_fn = torch.nn.CrossEntropyLoss()
```

**原理**：框架内置反向传播与优化器。

**边界与坑**：CrossEntropyLoss 内含 softmax，勿重复添加。

**要点**：框架省去手写梯度。

### 6.2.2 常见错误

**结论先行**：多数错误源于形状、损失与激活搭配。

| 错误 | 现象 | 对策 |
|------|------|------|
| 形状不匹配 | 广播报错 | 核对维度 |
| 损失重复 softmax | 收敛差 | 二选一 |
| 忘记清零梯度 | 梯度累积 | zero_grad |
| 学习率过大 | 损失发散 | 调小学习率 |

**边界与坑**：这些错误在小模型上就应排查清楚。

**要点**：先跑通小模型，再放大规模。

# 7. 常见误区

## 7.1 激活与输出层

**结论先行**：输出层激活必须匹配任务。

**原理**：回归用线性，二分类用 Sigmoid，多分类用 softmax。

**边界与坑**：在回归任务上用 softmax 会限制输出范围。

**要点**：输出层不是隐藏层的简单复制。

## 7.2 初始化与训练

**结论先行**：初始化与归一化显著影响可训练性。

**原理**：方差过大导致爆炸，过小导致消失。

**边界与坑**：深层网络建议用 Xavier/He 初始化并配合归一化。

**要点**：初始化与归一化是稳定训练的基石。
