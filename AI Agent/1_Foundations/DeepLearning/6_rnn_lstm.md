# 1. 为什么需要序列模型

**结论先行**：序列数据有顺序、变长、前后依赖三个特征，要求模型具备"记忆"能力并能处理任意长度输入。全连接与 CNN 都难以自然满足，于是催生了 RNN。

## 1.1 序列数据的特点

```
序列数据：文本、语音、时间序列
特点：有顺序、变长、前后依赖
```

- 顺序性：`x1, x2, x3` 的排列改变语义。
- 变长性：句子长度不一，模型不能假设固定长度。
- 依赖：当前输出依赖上下文，可能跨越很长距离。

## 1.2 序列任务类型

| 类型 | 输入→输出 | 例子 |
|------|-----------|------|
| 一对一 | 固定→固定 | 图像分类 |
| 一对多 | 固定→序列 | 图像描述 |
| 多对一 | 序列→固定 | 情感分类 |
| 多对多 | 序列→序列 | 机器翻译 |

## 1.3 其他方案的局限

- 全连接：无法处理变长序列，且不共享时间维参数。
- CNN：局部窗口天然适合局部模式，但长距离依赖需堆很多层。

全连接网络无法处理变长序列，CNN 不擅长长距离依赖。

## 1.4 序列建模的通用框架

任何序列模型都可抽象为"编码—记忆—解码"三段：

```
输入序列 → [编码] → [记忆/状态] → [解码] → 输出序列
```

- 编码：把每个时刻的输入映射为向量。
- 记忆：维护一个随时间的状态（RNN 的 h_t，或注意力缓存）。
- 解码：从状态生成输出。

# 2. RNN 的基本结构

**结论先行**：RNN 用一个随时间传递的隐藏状态 `h_t` 编码历史信息，并在所有时刻共享同一组权重。

## 2.1 展开图

```
      h0 ──▶ h1 ──▶ h2 ──▶ h3
             │      │      │
             ▼      ▼      ▼
            x1     x2     x3
```

把循环结构按时间展开，得到一条深度等于序列长度的计算链。

## 2.2 前向公式

```
h_t = tanh(W_h · h_{t-1} + W_x · x_t + b)
y_t = W_y · h_t
```

| 符号 | 含义 |
|------|------|
| h_t | 时刻 t 的隐藏状态（记忆） |
| x_t | 时刻 t 的输入 |
| W_h, W_x | 共享权重 |

## 2.3 权重共享

> **权重共享**：同一组参数处理每个时刻。

参数量与序列长度无关，这是 RNN 处理变长序列的关键。

## 2.4 输出方式

- 每个时刻都输出：多对多（如序列标注）。
- 仅最后时刻输出：多对一（如分类）。
- 用最后隐状态初始化解码器：编码器-解码器（seq2seq）。

## 2.5 编码器-解码器与 seq2seq

### 2.5.1 结构

```
编码器 RNN: x1..xn → 上下文向量 c = h_n
解码器 RNN: 以 c 为初始状态，逐步生成 y1..ym
```

### 2.5.2 信息瓶颈

整句信息被压缩进单个固定维度向量 `c`，句子越长信息损失越大，这直接推动了注意力机制的诞生。

## 2.6 两种计算视角

| 视角 | 描述 | 用途 |
|------|------|------|
| 展开图 | 按时间展开成深网络 | 理解 BPTT |
| 状态机 | 反复应用同一单元 | 理解权重共享 |

二者描述的是同一个模型，前者便于推导梯度，后者便于理解参数复用。

# 3. RNN 的问题

**结论先行**：RNN 的梯度是雅可比矩阵的连乘，导致长序列上梯度指数衰减或爆炸；同时时间步串行使训练无法并行。

## 3.1 梯度消失

### 3.1.1 BPTT 推导

沿时间反向传播（BPTT）中，跨越 `k` 步的梯度含因子：

```
∂h_t / ∂h_{t-k} = ∏_{i=0}^{k-1} ∂h_{t-i} / ∂h_{t-i-1}
                = ∏ (W_h^T · diag(1 - tanh^2(·)))
```

### 3.1.2 连乘直觉

```
梯度消失的直觉：
  反向传播要连乘很多个 W_h
  若 ||W_h|| < 1 → 指数衰减 → 早期信息丢失
```

反之 `||W_h|| > 1` 则指数增长，形成梯度爆炸。

## 3.2 梯度爆炸

| 问题 | 说明 |
|------|------|
| 梯度消失 | 长序列梯度衰减，学不到长依赖 |
| 梯度爆炸 | 梯度累积放大 |
| 串行计算 | 无法并行，训练慢 |

对策：梯度裁剪、使用门控结构（LSTM/GRU）、残差连接。

### 3.2.1 梯度裁剪

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=5.0)
```

把梯度范数限制在阈值内，是训练 RNN 的常用保险。

## 3.3 串行计算

时刻 `t` 依赖 `t-1`，无法在时间维并行，GPU 利用率低，长序列训练慢。

## 3.4 长依赖的路径长度

| 模型 | 两位置间信息路径长度 |
|------|:--------------------:|
| RNN | O(n) |
| CNN（堆叠） | O(log n) |
| Transformer | O(1) |

路径越长，梯度越容易被反复的矩阵乘法稀释，这正是长依赖难学的根本原因。

# 4. LSTM

**结论先行**：LSTM（长短期记忆，Long Short-Term Memory）用三个门控制信息的写入、遗忘与输出，并用一条加性的细胞状态通道让梯度稳定回传，从而学到长依赖。

## 4.1 门控思想

```
┌─────────────────────────────────────┐
│  遗忘门：决定丢弃哪些旧信息          │
│  输入门：决定写入哪些新信息          │
│  输出门：决定输出哪些信息            │
│  细胞状态：长期记忆通道              │
└─────────────────────────────────────┘
```

门是 `sigmoid` 输出的 0~1 向量，充当软开关。

## 4.2 核心公式

### 4.2.1 遗忘门

```
f_t = sigmoid(W_f @ [h_{t-1}, x_t] + b_f)
```

控制上一时刻细胞状态 `c_{t-1}` 保留多少。

### 4.2.2 输入门与候选

```
i_t = sigmoid(W_i @ [h_{t-1}, x_t] + b_i)
c̃_t = tanh(W_c @ [h_{t-1}, x_t] + b_c)
c_t = f_t * c_{t-1} + i_t * c̃_t
```

### 4.2.3 输出门

```
o_t = sigmoid(W_o @ [h_{t-1}, x_t] + b_o)
h_t = o_t * tanh(c_t)
```

## 4.3 细胞状态为何缓解梯度消失

细胞状态更新是加性的 `c_t = f_t ⊙ c_{t-1} + ...`，其梯度含因子 `f_t` 而非矩阵连乘。当 `f_t ≈ 1` 时梯度可近乎无损地跨多步传播，形成"梯度高速公路"。

```python
# LSTM 核心公式
f_t = sigmoid(W_f @ [h_{t-1}, x_t])    # 遗忘门
i_t = sigmoid(W_i @ [h_{t-1}, x_t])    # 输入门
c_t = f_t * c_{t-1} + i_t * tanh(W_c @ [h_{t-1}, x_t])  # 更新细胞状态
o_t = sigmoid(W_o @ [h_{t-1}, x_t])    # 输出门
h_t = o_t * tanh(c_t)                   # 输出
```

> **细胞状态**是一条"高速公路"，让梯度更好地回传。

## 4.4 实现

```python
self.lstm = nn.LSTM(input_size, hidden_size, num_layers=1, batch_first=True)
out, (h_n, c_n) = self.lstm(x)
```

## 4.5 梯度传播细节

### 4.5.1 门控的梯度

对 `c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t` 求偏导：

```
∂c_t / ∂c_{t-1} = f_t + (其他项对 c_{t-1} 的依赖)
```

主导项是 `f_t`（对角矩阵，逐元素），而非 `W_h` 的连乘。当遗忘门学得接近 1，梯度可跨越数百步。

### 4.5.2 与残差的联系

`c_t = c_{t-1} + Δ` 与残差连接 `y = x + F(x)` 同构，都是加性恒等通路。区别在于 LSTM 用门控动态决定保留比例，残差则恒定保留。

## 4.6 LSTM 变体

| 变体 | 特点 |
|------|------|
| Peephole | 门可看到细胞状态 |
| 多层 LSTM | 堆叠提升容量 |
| 双向 LSTM | 融合双向上下文 |
| Coupled 门 | 遗忘与输入门联动 |

多数场景标准 LSTM 已足够，变体收益有限。

# 5. GRU

**结论先行**：GRU（门控循环单元，Gated Recurrent Unit）把 LSTM 的遗忘门与输入门合并为更新门，并合并细胞状态与隐藏状态，参数更少、速度更快，效果通常相当。

## 5.1 结构

```
重置门：控制忽略多少历史
更新门：控制保留多少历史
```

## 5.2 公式

```
z_t = sigmoid(W_z @ [h_{t-1}, x_t])          # 更新门
r_t = sigmoid(W_r @ [h_{t-1}, x_t])          # 重置门
h̃_t = tanh(W @ [r_t * h_{t-1}, x_t])        # 候选状态
h_t = (1 - z_t) * h_{t-1} + z_t * h̃_t        # 插值更新
```

## 5.3 LSTM vs GRU

| 对比 | LSTM | GRU |
|------|:----:|:---:|
| 门数 | 3 | 2 |
| 参数量 | 多 | 少 |
| 效果 | 好 | 相当 |
| 速度 | 慢 | 快 |

实践中常先试 GRU，数据量大或任务复杂时再试 LSTM。

## 5.4 GRU 实现

```python
self.gru = nn.GRU(input_size, hidden_size, batch_first=True)
out, h_n = self.gru(x)
```

注意 GRU 只返回隐藏状态 `h_n`，没有独立的细胞状态。

## 5.5 选择建议

- 数据少、追求速度：GRU。
- 需要更强记忆、长依赖明显：LSTM。
- 两者差距通常小于 1~2 个点，优先用验证集实测。

# 6. 双向 RNN

**结论先行**：双向 RNN 同时从正反两个方向编码序列，输出拼接了两个方向的信息，适合需要完整上下文的"理解类"任务。

## 6.1 结构

```
正向：x1 → x2 → x3 → x4
反向：x1 ← x2 ← x3 ← x4
        └──── 拼接 ────┘
```

## 6.2 适用场景

> 同时利用上文与下文信息，适合理解类任务（如 NER）。

- 命名实体识别、词性标注、情感分类（整句已给定）。
- 不适用：自回归生成，因为生成时未来不可见。

## 6.3 注意事项

- 参数量约为单向的两倍。
- 双向与自回归解码冲突，编码器可用、解码器不可用。

## 6.4 堆叠与深层 RNN

```
输入 → RNN层1 → RNN层2 → ... → 输出
```

- 多层堆叠可提升表达能力，但超过 2~3 层易过拟合且难训练。
- 需配合 dropout、残差与 LayerNorm 才能稳定加深。

## 6.5 输出拼接方式

| 方式 | 公式 | 说明 |
|------|------|------|
| 拼接 | [h_fwd, h_bwd] | 最常用 |
| 求和 | h_fwd + h_bwd | 降维 |
| 平均 | (h_fwd + h_bwd)/2 | 平滑 |

拼接后维度翻倍，接分类头时需相应调整输入维度。

# 7. RNN 的局限

**结论先行**：即使有门控，RNN 仍受串行计算、固定隐状态瓶颈与长依赖衰减的限制，这些正是 Transformer 的出发点。

## 7.1 串行

| 局限 | 说明 |
|------|------|
| 串行 | 无法并行训练 |
| 长依赖 | 即使 LSTM 也有限 |
| 固定隐状态 | 信息瓶颈 |
| 训练慢 | 长序列很慢 |

## 7.2 长依赖

门控虽缓解梯度消失，但所有历史必须压缩进固定维度的 `h_t`，距离越远信息越易被覆盖。

## 7.3 信息瓶颈

编码器把整句压成一个向量，长句信息必然损失；注意力机制通过直接访问所有位置缓解此问题。

> 这些局限直接催生了 **Transformer**（并行 + 全局注意力）。

## 7.4 其他序列建模块

| 结构 | 核心思想 | 并行性 |
|------|----------|:------:|
| TCN | 因果空洞卷积 | 好 |
| Transformer | 自注意力 | 好 |
| SSM / Mamba | 状态空间递推 | 好 |

这些结构都在保留"记忆"的同时摆脱时间步串行。

## 7.5 何时仍选 RNN

- 序列短、数据少、算力受限的嵌入式场景。
- 需要严格流式、低延迟在线推理的场合。
- 作为基线快速验证任务可行性。

# 8. 从 RNN 到 Transformer

**结论先行**：Transformer 用自注意力替代循环，让任意两个位置直接交互，从而同时获得并行性与强长依赖建模能力。

## 8.1 动机

```
RNN：逐步传递隐状态 → 串行、长依赖弱
Transformer：全局注意力 → 并行、长依赖强
```

## 8.2 注意力对比

```
RNN:          h1 → h2 → h3 → h4
Transformer:  x1 ↔ x2 ↔ x3 ↔ x4  （任意两两直接交互）
```

信息从 O(序列长度) 步传递缩短为 O(1) 步。

## 8.3 位置编码

注意力本身无序，需加位置编码（positional encoding）注入顺序信息，常见正弦编码或可学习编码。

| 维度 | RNN | Transformer |
|------|-----|-------------|
| 并行 | 否 | 是 |
| 路径长度 | O(n) | O(1) |
| 长依赖 | 弱 | 强 |
| 复杂度 | O(n·d^2) | O(n^2·d) |

## 8.4 注意力机制公式

### 8.4.1 缩放点积注意力

```
Attention(Q, K, V) = softmax(Q K^T / sqrt(d_k)) V
```

`Q` 查询、`K` 键、`V` 值均由输入线性变换得到，任意两位置直接交互，路径长度为 O(1)。

### 8.4.2 多头注意力

把 `Q/K/V` 拆成多个子空间并行做注意力，再拼接，使模型能同时关注不同位置的不同关系。

```
MultiHead = Concat(head_1, ..., head_h) W_O
```

## 8.5 训练与掩码细节

- 变长批需用 padding mask，避免把填充位计入注意力。
- 自回归生成需用因果掩码（causal mask），防止看到未来。
- 位置编码注入顺序信息，否则注意力对排列不敏感。

# 9. 小结

## 9.1 关键要点

- RNN 通过隐状态处理序列，权重共享。
- 梯度消失导致长依赖学习困难。
- LSTM/GRU 用门控机制缓解，细胞状态是"记忆高速路"。
- RNN 串行计算，无法并行。
- 双向 RNN 利用双向上下文，适合理解类任务。
- Transformer 用注意力替代循环，是当前主流。

## 9.2 实践建议

- 短序列、小数据：LSTM/GRU 仍是稳健选择。
- 长序列、大数据：优先 Transformer 或 SSM。
- 理解类任务可上双向；生成类任务只能用因果结构。
- 序列任务务必用掩码（padding mask）处理变长批。
