# 1. 过拟合与欠拟合

**结论先行**：训练深度模型的核心矛盾是"拟合能力"与"泛化能力"的平衡。欠拟合说明模型容量不足，过拟合说明模型记住了训练噪声。二者对应偏差（bias）与方差（variance）两个方向，诊断靠对比训练集与验证集的损失曲线。

## 1.1 偏差-方差视角

### 1.1.1 偏差与方差的定义

- 偏差（Bias）：模型预测的期望与真实目标之间的差距，反映模型假设的强弱。高偏差 = 欠拟合。
- 方差（Variance）：模型在不同训练集上预测的波动程度，反映对数据噪声的敏感度。高方差 = 过拟合。

### 1.1.2 误差分解公式

期望泛化误差可分解为：

```
E[(y - f(x))^2] = Bias(f)^2 + Var(f) + σ^2
                  ↑           ↑         ↑
                欠拟合项     过拟合项   不可约噪声
```

其中 `σ^2` 是数据本身的噪声，任何模型都无法消除。增加模型容量会降低偏差、抬高方差；正则化则相反。

## 1.2 学习曲线诊断

### 1.2.1 训练/验证损失曲线

```
Loss
 │  ╲  训练损失
 │   ╲________
 │    ╲
 │     ╲___ 验证损失（先降后升 = 过拟合）
 │      ↗
 └──────────────▶ epoch
```

- 两条曲线都高且接近：欠拟合。
- 训练低、验证先降后升：过拟合。
- 训练低、验证低但有小间隙：健康。

### 1.2.2 数据量曲线

```
误差
 │ ─────────  训练误差（随数据量缓慢上升）
 │
 │  ╲
 │   ╲_____  验证误差（随数据量下降并趋近训练误差）
 └──────────────▶ 训练样本数
```

若验证误差仍在大幅下降，说明"更多数据"比"更复杂模型"更有效。

## 1.3 常见误区

- 误区一：只要训练损失降到 0 就是好模型。实际可能是记住了噪声。
- 误区二：验证集表现差一定是过拟合，也可能是数据分布不一致。
- 误区三：正则化越强越好。过强会导致欠拟合。

# 2. 正则化

**结论先行**：正则化通过对模型复杂度施加约束来缩小泛化间隙。L1/L2 约束权重大小，Dropout 约束特征协同，早停约束训练步数，数据增强约束输入分布。

## 2.1 L1/L2 正则化

### 2.1.1 数学形式

在损失中加入权重惩罚项：

```
L_total = L_data + λ · R(W)

L2:  R(W) = (1/2) Σ w_i^2
L1:  R(W) = Σ |w_i|
```

梯度更新：

```
L2:  w ← w - η(∂L/∂w + λ w)
L1:  w ← w - η(∂L/∂w + λ sign(w))
```

### 2.1.2 几何直觉

- L2 使权重整体缩小、趋向平滑，产生"分布式"表示。
- L1 的次梯度在 0 附近为常数，会把小权重压到 0，产生稀疏解，可用于特征选择。

## 2.2 Dropout

### 2.2.1 原理与训练/推理差异

训练时以概率 `p` 随机将神经元置零，并对保留单元按 `1/(1-p)` 缩放；推理时不做丢弃。这等价于对指数多个子网络的隐式集成（ensemble）。

```
训练:  h = m ⊙ a / (1-p),   m ~ Bernoulli(1-p)
推理:  h = a
```

### 2.2.2 伪代码

```python
# 训练
mask = (torch.rand_like(a) > p).float()
h = a * mask / (1 - p)

# 推理
h = a
```

```python
# PyTorch
self.dropout = nn.Dropout(p=0.1)
h = self.dropout(relu(...))
model.eval()   # 自动关闭 dropout
```

## 2.3 早停与数据增强

| 方法 | 机制 | 代价 |
|------|------|------|
| 早停 | 验证损失回升即停止 | 需验证集，可能停早 |
| 数据增强 | 扩充有效样本分布 | 需领域设计 |

## 2.4 权重衰减与 L2 的区别

权重衰减（weight decay）在优化器层面把权重按 `w ← w(1 - ηλ)` 收缩；对 SGD 它与 L2 等价，但对 Adam 等自适应优化器二者不等价，需用 AdamW 才能实现真正的解耦权重衰减。

| 项 | L2 正则 | 权重衰减 |
|----|---------|----------|
| 施加位置 | 损失函数 | 优化器更新 |
| SGD 下 | 等价 | 等价 |
| Adam 下 | 不等价 | 更合理（AdamW） |

## 2.5 其他正则化手段

| 手段 | 机制 | 适用 |
|------|------|------|
| 标签平滑 | 把硬标签变软 | 分类 |
| 随机深度 | 随机跳过残差块 | 深层网络 |
| 早停 | 验证回升即停 | 通用 |
| 权重约束 | 限制范数上界 | RNN |

标签平滑把 `[0,1,0]` 变为 `[0.05,0.9,0.05]`，抑制过度自信。

# 3. 归一化

**结论先行**：归一化把每层激活拉回稳定分布，缓解内部协变量偏移（internal covariate shift），允许更大学习率、更快收敛。选择取决于数据的统计维度。

## 3.1 BatchNorm

### 3.1.1 公式

对一个 mini-batch 内同一通道的激活做归一化：

```
μ_B = (1/m) Σ x_i
σ_B^2 = (1/m) Σ (x_i - μ_B)^2
x̂_i = (x_i - μ_B) / sqrt(σ_B^2 + ε)
y_i = γ x̂_i + β
```

`γ, β` 是可学习的缩放与平移参数。

### 3.1.2 训练/推理

训练时用当前 batch 统计量，同时用滑动平均累积全局均值方差；推理时使用累积统计量。

```
训练:  用 batch 统计
推理:  用 running_mean / running_var
```

## 3.2 LayerNorm

对单个样本的所有特征维度归一化，与 batch 大小无关，适合变长序列（RNN/Transformer）。

```python
self.ln = nn.LayerNorm(hidden_size)
h = self.ln(x)
```

## 3.3 RMSNorm

去掉均值中心化，只按均方根缩放，计算更省：

```
RMS(x) = sqrt((1/n) Σ x_i^2 + ε)
y = γ · x / RMS(x)
```

## 3.4 对比与选择

| 方法 | 归一化维度 | 适用 | 依赖 batch |
|------|------------|------|:----------:|
| BatchNorm | batch × 空间 | CNN | 是 |
| LayerNorm | 特征维 | RNN/Transformer | 否 |
| RMSNorm | 特征维（无均值） | LLM | 否 |
| GroupNorm | 通道分组 | 小 batch CNN | 否 |

> **归一化显著提升训练稳定性**，是深度网络的标配。

# 4. 残差连接

**结论先行**：残差连接让梯度有一条恒等通路直接回传，使超深网络可训练。它是 ResNet 与 Transformer 的共同基石。

## 4.1 原理与梯度分析

```
输入 x ──┬──▶ [层] ──▶ + ──▶ 输出
         └────────────┘
        （跳跃连接）
```

前向：`y = x + F(x)`。反向对 `x` 求导：

```
∂y/∂x = I + ∂F/∂x
```

恒等项 `I` 保证梯度不会因多层连乘而消失。

## 4.2 实现变体

```python
def forward(self, x):
    return x + self.layer(x)      # 残差
```

- 预激活（pre-activation）：`x + F(Norm(x))`，梯度更干净。
- 后激活（post-activation）：`Norm(x + F(x))`，原始 ResNet。

## 4.3 误区

- 误区：残差一定能加深网络。若维度不匹配需投影 `W_s x`，否则无法相加。
- 误区：残差消除梯度爆炸。它主要缓解消失，爆炸仍需梯度裁剪。

# 5. 学习率调度

**结论先行**：学习率是最重要的超参数。Warmup 让初期参数平稳进入训练区，衰减让后期精细收敛。

## 5.1 Warmup

训练前若干步线性升温，避免随机初始化下的大梯度破坏参数。

## 5.2 衰减策略

### 5.2.1 余弦退火

学习率按余弦曲线从峰值平滑降到接近 0。

### 5.2.2 阶梯与指数

- 阶梯衰减：每 N 个 epoch 乘以 0.1。
- 指数衰减：`lr = lr0 · γ^t`。

## 5.3 代码实现

```python
# 1. Warmup（前 N 步线性升温）
# 2. 然后余弦衰减
def lr_lambda(step):
    if step < warmup_steps:
        return step / warmup_steps
    progress = (step - warmup_steps) / (total_steps - warmup_steps)
    return 0.5 * (1 + math.cos(math.pi * progress))
```

| 阶段 | 作用 |
|------|------|
| Warmup | 避免初期不稳定 |
| 衰减 | 后期精细收敛 |

# 6. 初始化

**结论先行**：初始化决定信号在前向与反向传播中的方差是否稳定。目标是让每层激活方差大致恒定。

## 6.1 为什么初始化重要

- 全零初始化：所有神经元对称，无法打破对称性。
- 过大：激活饱和、梯度消失。
- 过小：信号逐层衰减。

## 6.2 常用方法

### 6.2.1 Xavier

适用于 tanh/sigmoid，令前向与反向方差一致：

```
Var(W) = 2 / (fan_in + fan_out)
```

### 6.2.2 Kaiming

适用于 ReLU，考虑其只保留一半激活：

```
Var(W) = 2 / fan_in
```

## 6.3 Transformer 初始化

```python
# 常用初始化
nn.init.xavier_uniform_(self.W)     # 适合 tanh/sigmoid
nn.init.kaiming_normal_(self.W)     # 适合 ReLU
# Transformer 常用：正态分布，std=0.02
```

> 初始化不当会导致训练不收敛或梯度问题。

# 7. 混合精度训练

**结论先行**：用低精度（FP16/BF16）存储与计算、FP32 做参数更新，兼顾速度、显存与数值稳定。

## 7.1 原理

矩阵乘等算子用半精度加速，权重主副本保持 FP32。BF16 动态范围与 FP32 相同，通常无需损失缩放。

## 7.2 损失缩放

FP16 下小梯度会下溢为 0，需把损失放大 `S` 倍再反传，更新前再除回：

```
loss' = S · loss
grad  = (1/S) · ∂loss'/∂w
```

## 7.3 代码

```python
# FP16/BF16 混合精度：省显存、加速
scaler = torch.cuda.amp.GradScaler()

with torch.cuda.amp.autocast():
    output = model(input)
    loss = loss_fn(output, target)

scaler.scale(loss).backward()
scaler.step(optimizer)
scaler.update()
```

| 精度 | 显存 | 速度 | 稳定性 |
|------|:----:|:----:|:------:|
| FP32 | 高 | 慢 | 最好 |
| FP16 | 低 | 快 | 需 scaler |
| BF16 | 低 | 快 | 好（推荐） |

# 8. 数据相关技巧

**结论先行**：数据质量与分布往往比模型结构更决定上限。增强、清洗、平衡、批大小都是低成本高回报的手段。

## 8.1 数据增强

| 技巧 | 说明 |
|------|------|
| 数据增强 | 图像翻转/裁剪、文本改写 |
| 数据清洗 | 去噪、去重 |
| 类别平衡 | 重采样、加权损失 |
| 批大小 | 影响训练稳定性 |

## 8.2 数据清洗与去重

- 去除标签错误与重复样本，防止模型学到错误映射。
- 训练集与验证集去重，避免数据泄漏导致虚高指标。

## 8.3 类别不平衡

| 策略 | 做法 | 风险 |
|------|------|------|
| 重采样 | 过采样少数类/欠采样多数类 | 过采样易过拟合 |
| 加权损失 | 按类频率加权 | 权重需调 |
| Focal Loss | 降低易分样本权重 | 需调参 |

## 8.4 批大小

- 批太小：梯度噪声大、训练不稳。
- 批太大：泛化可能变差，需配合学习率缩放。
- 常用线性缩放：批大小翻倍，学习率翻倍（或平方根缩放）。

## 8.5 自监督与课程学习

- 自监督预训练（如掩码语言模型、对比学习）能在无标注数据上学习通用表示。
- 课程学习（curriculum learning）先易后难安排样本，帮助模型稳定收敛。
- 二者常与微调结合，是当前大模型训练的标准范式。

# 9. 梯度问题与对策

**结论先行**：深层网络梯度是雅可比矩阵连乘，连乘导致指数衰减或爆炸。残差与归一化缓解消失，裁剪与缩放缓解爆炸。

## 9.1 梯度消失/爆炸

```
梯度消失：||∂h_t/∂h_{t-1}|| < 1 → 连乘 → 指数衰减
梯度爆炸：||∂h_t/∂h_{t-1}|| > 1 → 连乘 → 指数增长
```

## 9.2 梯度裁剪

按全局范数裁剪，限制单步更新幅度：

```python
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

## 9.3 组合策略

| 问题 | 首选 | 备选 |
|------|------|------|
| 梯度消失 | 残差 + 归一化 | 换激活（GELU） |
| 梯度爆炸 | 梯度裁剪 | 降学习率 |
| 训练不稳 | Warmup + 归一化 | 减小批或学习率 |

# 10. 常见问题排查

## 10.1 损失不降

- 学习率太小：收敛极慢。
- 学习率太大：震荡甚至发散。
- 数据/标签错配：检查预处理与对齐。

## 10.2 损失变 NaN

- 梯度爆炸：裁剪 + 降学习率。
- 除零/对数零：检查损失中的 `log` 与归一化 `ε`。

## 10.3 汇总表

| 现象 | 可能原因 | 对策 |
|------|----------|------|
| Loss 不降 | 学习率太小/太大 | 调学习率 |
| Loss 变 NaN | 梯度爆炸 | 梯度裁剪、降学习率 |
| 训练集好测试差 | 过拟合 | 正则化、增数据 |
| 训练慢 | 批太小/无加速 | 增大批、混合精度 |
| 不稳定 | 无归一化 | 加归一化 |

## 10.4 调参优先级

1. 先调学习率与 Warmup。
2. 再看批大小与归一化。
3. 然后加正则化与数据增强。
4. 最后尝试初始化与混合精度。

# 11. 小结

## 11.1 关键要点

- 过拟合用正则化、Dropout、早停、数据增强。
- 归一化（LayerNorm/RMSNorm）是深度网络标配。
- 残差连接解决深层网络梯度问题。
- 学习率调度（Warmup + 衰减）提升稳定性。
- 混合精度训练省显存、提速。
- 初始化、梯度裁剪、数据处理是稳定训练的必要环节。

## 11.2 实践清单

- 训练前固定随机种子并切分验证集。
- 用学习率扫描确定量级，再精调。
- 监控梯度范数与激活分布。
- 保存最优验证权重，配合早停。
