# 1. 什么是深度学习

## 1.1 定义与核心思想

### 1.1.1 定义

**结论先行**：深度学习（Deep Learning）是用多层神经网络从数据中自动学习特征表示的方法。

**原理**：传统机器学习由人设计特征；深度学习把特征提取也交给模型，通过多层非线性变换逐级构造表示（representation，表示）。

```
传统机器学习：人工设计特征 → 模型
深度学习：      原始数据 → 神经网络自动学习特征 → 输出
```

**边界与坑**：深度指层数多，不等于更聪明；自动特征依赖大量数据。

**要点**：深度学习 = 表示学习 + 多层非线性变换。

### 1.1.2 与人工智能、机器学习的关系

**结论先行**：三者是包含关系，而非并列关系。

**原理**：人工智能包含机器学习，机器学习包含深度学习。

```
人工智能
└── 机器学习
    ├── 传统方法（SVM、决策树、随机森林）
    └── 深度学习（神经网络）
        ├── CNN（图像）
        ├── RNN/LSTM（序列）
        └── Transformer（通用，含 LLM）
```

**边界与坑**：并非所有 AI 都是机器学习（如专家系统）。

**要点**：AI ⊃ 机器学习 ⊃ 深度学习。

## 1.2 为什么需要"深"

### 1.2.1 非线性是前提

**结论先行**：没有非线性，多层线性变换等价于一层。

**原理**：y = W2(W1x + b1) + b2 = (W2W1)x + 常数，仍是线性函数，故须插入激活函数（activation function，激活函数）。

```python
W = W2 @ W1
b = W2 @ b1 + b2          # 两层退化为单层
```

**边界与坑**：非线性是深度的前提，缺少它网络容量等同浅层模型。

**要点**：线性堆叠无效，非线性赋予表达力。

### 1.2.2 分层抽象

**结论先行**：浅层学简单特征，深层学抽象特征。

**原理**：网络逐层组合低层模式，形成高层语义；对某些函数，深层所需神经元随深度指数下降。

```
原始像素 → 边缘 → 纹理 → 部件 → 物体
（浅层学简单特征，深层学抽象特征）
```

| 网络类型 | 表达同一函数所需规模 | 特点 |
|----------|----------------------|------|
| 浅层宽网络 | 指数级神经元 | 参数多 |
| 深层窄网络 | 多项式级神经元 | 参数少、可复用 |

**边界与坑**：过深会梯度消失与退化，需残差、归一化配合。

**要点**：深度 = 特征抽象的层次。

# 2. 与机器学习的关系

## 2.1 概念谱系

### 2.1.1 主要分支

**结论先行**：架构随数据类型演化，Transformer 成为通用骨架。

**原理**：不同数据结构对应不同归纳偏置（inductive bias，归纳偏好）。

| 架构 | 擅长数据 | 关键机制 |
|------|----------|----------|
| MLP | 表格/向量 | 全连接 |
| CNN | 图像/网格 | 卷积、权值共享 |
| RNN/LSTM | 序列 | 循环、门控 |
| Transformer | 通用 | 自注意力 |
| GNN | 图结构 | 消息传递 |

**边界与坑**：架构与数据结构不匹配会浪费算力。

**要点**：数据形态决定架构，Transformer 最通用。

### 2.1.2 特征工程与特征学习

**结论先行**：传统方法靠人工特征，深度学习靠自动特征。

**原理**：人工特征依赖领域知识、可解释性强；自动特征省人力，但需要数据与算力。

| 维度 | 传统机器学习 | 深度学习 |
|------|--------------|----------|
| 特征 | 人工设计 | 自动学习 |
| 数据量 | 中小规模 | 大规模 |
| 算力 | 低 | 高（GPU） |
| 可解释性 | 较强 | 较弱 |

**边界与坑**：小数据上深度学习易过拟合，传统方法更稳。

**要点**：选择取决于数据、算力与可解释性。

## 2.2 数据规模的拐点

**结论先行**：数据超过某个拐点后，深度学习优势才明显。

**原理**：传统模型性能随数据增长很快饱和，深度模型可持续受益。

```
性能
 │        ______  深度学习
 │      /
 │  ___/________  传统方法
 │ /
 └──────────────────▶ 数据量
      拐点
```

**边界与坑**：数据不足却硬上深度学习，常得不偿失。

**要点**：数据是深度学习发挥作用的前提。

# 3. 为什么深度学习有效

## 3.1 四大原因

### 3.1.1 核心优势

**结论先行**：自动特征、强表达、可扩展、通用性是其四大优势。

**原理**：端到端（end-to-end）训练把特征与任务联合优化。

| 原因 | 说明 |
|------|------|
| 自动特征 | 无需人工设计特征 |
| 表达能力强 | 深层网络可拟合复杂函数 |
| 可扩展 | 数据与算力越多，效果越好 |
| 通用性 | 同一架构适配多种任务 |

**边界与坑**：自动特征不代表免预处理，归一化与清洗仍必要。

**要点**：端到端替代人工流水线。

### 3.1.2 通用逼近与规模定律

**结论先行**：足够宽的神经网络可逼近任意连续函数，且性能随规模按幂律提升。

**原理**：通用逼近定理（Universal Approximation Theorem）保证"存在"；规模定律（Scaling Law）描述损失随参数 N、数据 D、算力 C 下降。

```
L ∝ N^(-α) + D^(-β) + C^(-γ)
```

**边界与坑**：逼近定理只保证存在，不保证可训练与泛化；单一要素扩大收益递减。

**要点**：表达力是理论保证，规模需协同扩展。

## 3.2 涌现能力

**结论先行**：规模到一定程度，模型会突然具备训练中未显式教的能力。

**原理**：涌现（emergence）指某些能力在小模型上接近随机，超过阈值后快速上升。

**边界与坑**：涌现的度量存在争议，可能受评价指标平滑性影响。

**要点**：规模带来质变，是 LLM 的重要经验。

# 4. 神经网络的直觉

## 4.1 分层计算

### 4.1.1 基本单元

**结论先行**：每层做一次"线性变换 + 非线性激活"。

**原理**：线性部分负责旋转/缩放空间，非线性部分弯折空间，使决策边界可弯曲。

```
输入 → [线性变换 + 非线性激活] × N 层 → 输出
```

**边界与坑**：层数过多会累积数值误差，需归一化稳定。

**要点**：层是"线性 + 非线性"的重复单元。

### 4.1.2 逐层特征

**结论先行**：每层输出都是对输入的再编码。

**原理**：设 h0 = x，则 h_l = σ(W_l h_{l-1} + b_l)，逐层构造更抽象表示。

```python
def layer(h, W, b):
    return relu(W @ h + b)

h1 = layer(x, W1, b1)
h2 = layer(h1, W2, b2)
```

**边界与坑**：并非越深越好，无残差的过深网络会退化。

**要点**：表示逐层抽象，深度即抽象层级。

## 4.2 常见误区

**结论先行**：深度不等于简单堆叠，深度学习也不是万能。

**原理**：理论上更深不应更差，但优化困难；残差连接 y = F(x) + x 让网络易学恒等映射。

```
y = F(x) + x   # 残差块
```

**边界与坑**：依赖数据分布假设，分布外（out-of-distribution）数据易失效，且缺乏可靠不确定性估计。

**要点**：深需技巧，且要认清适用边界。

# 5. 三类基本任务

## 5.1 分类

### 5.1.1 定义与损失

**结论先行**：分类输出离散类别，常用交叉熵损失。

**原理**：网络输出各类别得分，经 softmax 转概率，再与真实标签比较。

```
p_i = exp(z_i) / Σ_j exp(z_j)
L = -Σ_i y_i · log(p_i)
```

**边界与坑**：类别极不平衡时需加权或重采样。

**要点**：分类 = 概率建模 + 交叉熵。

### 5.1.2 典型例子

**结论先行**：图像分类与情感分析最常见。

| 任务 | 输入 | 输出 | 例子 |
|------|------|------|------|
| 图像分类 | 图片 | 类别 | 猫/狗 |
| 情感分析 | 文本 | 正/负 | 评论极性 |

**边界与坑**：多标签与多类别不同，损失设计需区分。

**要点**：按输出形式选择损失。

## 5.2 回归

**结论先行**：回归输出连续值，常用均方误差。

**原理**：直接拟合实数值目标。

```
L = (1/n) Σ_i (y_i - ŷ_i)^2
```

| 损失 | 特点 | 适用 |
|------|------|------|
| MSE | 对大误差敏感 | 一般回归 |
| MAE | 稳健 | 有异常值 |
| Huber | 折中 | 噪声较多 |

**边界与坑**：异常值对 MSE 影响大；量纲差异大时需标准化。

**要点**：回归看误差分布选损失。

## 5.3 生成

**结论先行**：生成任务输出新样本，学习数据分布。

**原理**：模型学习 p(x) 或条件分布 p(x|c)，再采样生成。

| 任务 | 模型 | 例子 |
|------|------|------|
| 文本生成 | GPT 类 | 对话、写作 |
| 图像生成 | 扩散模型 | 文生图 |

**边界与坑**：生成质量难量化，可能产生幻觉或不当内容。

**要点**：生成 = 分布建模 + 采样，是 LLM 的核心能力。

# 6. 训练的基本流程

## 6.1 五个步骤

### 6.1.1 前向与损失

**结论先行**：先用当前参数算出预测，再用损失衡量误差。

**原理**：逐层前向得到 ŷ，损失 L(ŷ, y) 是标量目标。

```
① 前向传播：输入 → 预测输出
② 计算损失：预测 vs 真实
```

**边界与坑**：训练与推理时某些层行为不同（如 Dropout）。

**要点**：前向 = 从输入到预测。

### 6.1.2 反向与更新

**结论先行**：用链式法则求梯度，再沿负梯度更新参数。

**原理**：反向传播逐层回传误差，梯度下降更新参数。

```
③ 反向传播：计算梯度
④ 更新参数：梯度下降
⑤ 重复 ①~④ 直到收敛
```

**边界与坑**：忘记清零梯度会导致梯度累加。

**要点**：损失 → 反向 → 更新构成闭环。

## 6.2 完整伪代码

**结论先行**：一个 epoch 内循环处理所有批次。

**原理**：顺序为前向、损失、反向、更新、清零。

```python
# 伪代码
for epoch in range(epochs):
    for batch in data:
        pred = model(batch.x)              # ① 前向
        loss = loss_fn(pred, batch.y)      # ② 损失
        loss.backward()                    # ③ 反向
        optimizer.step()                   # ④ 更新
        optimizer.zero_grad()
```

| 超参数 | 作用 | 常见取值 |
|--------|------|----------|
| 学习率 | 更新步长 | 1e-3 ~ 1e-5 |
| 批大小 | 每批样本数 | 32 ~ 512 |
| 轮数 | 遍历次数 | 依任务 |
| 正则 | 防过拟合 | Dropout、权重衰减 |

**边界与坑**：学习率过大发散，过小收敛慢。

**要点**：zero_grad 须在下次 backward 之前调用。

# 7. 与传统编程的区别

## 7.1 两种范式

### 7.1.1 规则驱动

**结论先行**：传统编程由人写规则。

**原理**：程序员明确描述"如何做"。

```
传统编程：规则 + 数据 → 答案
```

**边界与坑**：规则复杂时维护成本高，难以覆盖长尾。

**要点**：规则驱动依赖人工逻辑。

### 7.1.2 数据驱动

**结论先行**：机器学习由数据反推规则。

**原理**：从"输入-输出"对中学习映射函数。

```
机器学习：数据 + 答案 → 规则（模型）
```

**边界与坑**：数据有偏则模型有偏。

**要点**：深度学习是"从数据中学习规则"，而非"编写规则"。

## 7.2 范式对比

**结论先行**：两者互补而非替代。

| 维度 | 传统编程 | 机器学习 |
|------|----------|----------|
| 输入 | 规则 + 数据 | 数据 + 答案 |
| 输出 | 答案 | 规则/模型 |
| 维护 | 改代码 | 重训练 |
| 长尾 | 难覆盖 | 数据可覆盖 |

**边界与坑**：安全关键逻辑仍宜用显式规则兜底；垃圾数据进，垃圾模型出（garbage in, garbage out）。

**要点**：按场景混合使用，数据质量决定上限。

# 8. 与 LLM 的关系

## 8.1 技术脉络

### 8.1.1 Transformer 的崛起

**结论先行**：Transformer（2017）以自注意力取代循环，成为通用骨架。

**原理**：自注意力（self-attention，自注意力）并行建模任意位置依赖，适合大规模训练。

```
深度学习
  └── 神经网络
      └── Transformer（2017）
          └── 预训练语言模型（BERT、GPT）
              └── 大语言模型（GPT-4、Claude、Qwen）
```

**边界与坑**：注意力计算量随序列长度平方增长。

**要点**：Transformer 是 LLM 的基座。

### 8.1.2 从预训练到 LLM

**结论先行**：预训练 + 微调/对齐构成现代 LLM 范式。

**原理**：先在大规模语料上自监督学习，再通过指令微调与人类反馈对齐。

| 阶段 | 目标 | 数据 |
|------|------|------|
| 预训练 | 学语言规律 | 海量无标注文本 |
| 指令微调 | 学会遵循指令 | 指令-回答对 |
| 对齐 | 符合人类偏好 | 偏好数据 |

**边界与坑**：对齐可能引入过度拒答等副作用。

**要点**：预训练打基础，对齐定行为。

## 8.2 为什么深度学习是基础

**结论先行**：LLM 的核心概念与训练直觉都源于深度学习。

**原理**：梯度下降、反向传播、注意力、归一化等直接沿用；损失曲线、过拟合、学习率调度等现象一致。

**边界与坑**：忽略基础会导致只会调 API、无法诊断问题；LLM 规模还带来分布式工程复杂度。

**要点**：理解深度学习是理解 LLM 的基础。

# 9. 学习建议

## 9.1 学习路径

### 9.1.1 阶段划分

**结论先行**：按入门、进阶、深入、应用四阶段推进。

| 阶段 | 内容 |
|------|------|
| 入门 | 神经元、激活函数、前向传播 |
| 进阶 | 反向传播、优化器、正则化 |
| 深入 | 各类架构（CNN/RNN/Transformer） |
| 应用 | 用框架（PyTorch）实践 |

**边界与坑**：跳过基础直接学大模型，容易知其然不知其所以然。

**要点**：循序渐进，基础优先。

### 9.1.2 实践建议

**结论先行**：动手实现比只看公式更有效。

**原理**：从零实现小网络，能建立对梯度与张量形状的直觉。

```python
# 建议：先手写两层网络，再用框架复现
model = torch.nn.Sequential(
    torch.nn.Linear(784, 128),
    torch.nn.ReLU(),
    torch.nn.Linear(128, 10),
)
```

**边界与坑**：只调库不理解原理，遇到 bug 无从下手。

**要点**：手写 + 框架双轨并行。

## 9.2 工具与注意事项

**结论先行**：重视数据与评估，而非只盯模型。

**原理**：多数效果提升来自数据质量与训练细节。

| 框架 | 特点 |
|------|------|
| PyTorch | 动态图、生态好 |
| TensorFlow | 生产部署成熟 |
| JAX | 函数式、高性能 |

**边界与坑**：频繁切换框架分散精力；忽略验证集会导致过拟合而不自知。

**要点**：选定一个深入，数据、评估、复现同样重要。
