# 1. 模块定位

本模块是整个笔记的**理论核心**：讲清楚"什么是 Agent、它如何思考与行动、为什么会失败"。所有框架本质上都是这里模式的工程化封装，理解原理才能不被框架绑架。

## 1.1 本模块解决什么问题

- 定义清楚 Agent 与工作流（Workflow）的边界，避免"用 Agent 做工作流就能做的事"。
- 拆解 Agent 的构成要素：模型、工具、记忆、规划、循环。
- 归纳推理-行动范式（ReAct、Reflexion、ToT、LATS 等）的共性与差异。
- 建立失败模式与设计原则的清单，作为生产化的前置知识。

## 1.2 在整个笔记中的位置

```
PromptEngineering → LLMEngineering → AgentCore(本模块)
                                        ↓
        ToolsAndProtocols / Memory / Frameworks / MultiAgent
                                        ↓
                    ProductionEngineering / Security / Applications
```

本模块处于"理论 → 工程"的枢纽位置：向上承接模型与提示工程，向下引出工具、记忆、框架与生产化。

## 1.3 与其他模块的边界

| 模块 | 关注点 | 与本模块的边界 |
|------|--------|----------------|
| `3_PromptEngineering` | 如何写提示 | 本模块关注"何时、为何调用模型" |
| `4_LLMEngineering` | 模型选型、推理优化 | 本模块把模型当作一个组件 |
| `7_ToolsAndProtocols` | 工具与 MCP 协议 | 本模块讲工具在循环中的角色 |
| `14_ProductionEngineering` | 生产化工程 | 本模块只做全景引出 |

## 1.4 阅读前提

- 具备基本的 Java 编程能力（本模块示例使用 JDK 17/21）。
- 了解 LLM 的基本调用方式（提示、温度、Token 等概念）。
- 最好先读过 `3_PromptEngineering` 与 `4_LLMEngineering`。

若只想快速了解"Agent 是什么"，可先读 `1`、`2`、`4`、`15` 四篇。

# 2. 学习目标

## 2.1 知识目标

- 能区分"工作流"与"Agent"，并据此选型。
- 理解 Agent Loop、规划、推理模式、反思机制。
- 理解自主性分级及其五个控制维度。
- 认识 Agent 的失败模式与设计原则。

## 2.2 能力目标

- 从零用 Java 实现一个可运行的 ReAct Agent。
- 能为一类任务选择合适的自主性档位与约束。
- 能识别一个 Agent 设计中的风险点并给出改进方向。

## 2.3 非目标

- 不追求覆盖所有框架 API（框架会变，原理相对稳定）。
- 不深入模型训练与微调（属于 `4_LLMEngineering`）。
- 不展开多 Agent 协作细节（属于 `10_MultiAgent`）。

## 2.4 学习成果验收

完成本模块后，应能独立回答以下问题：

| 序号 | 问题 | 对应篇章 |

| 2 | 一次 Agent 循环包含哪些步骤？ | `4` |
| 3 | ReAct 与 Reflexion 有何不同？ | `7`、`8` |
| 4 | 如何为任务选择自主性档位？ | `3` |

# 5. 关键知识点速览

## 5.1 核心结论

- Agent = LLM（大脑）+ 工具（手脚）+ 记忆（经验）+ 规划（策略）。
- Agent 与工作流的本质区别是"谁来决定下一步"。
- ReAct 是最基础的推理-行动范式，绝大多数框架都源于此。
- 反思与自我批判是提升成功率的关键增量。
- 生产环境里，Agent 的失败大多来自状态、工具与循环控制，而非模型本身。

## 5.2 术语表

| 术语 | 含义 |
|------|------|
| Agent | 能自主决策并调用工具完成目标的系统 |
| Workflow | 由代码固定编排的流程 |
| ReAct | 推理（Reason）与行动（Act）交替的范式 |
| Reflexion | 通过自我反思改进后续尝试的机制 |
| ToT | 思维树（Tree of Thoughts），多分支搜索 |
| LATS | 语言 Agent 树搜索（Language Agent Tree Search） |
| HITL | 人机协同（Human-in-the-Loop） |
| Autonomy | 自主性，系统可自主决策的程度 |
