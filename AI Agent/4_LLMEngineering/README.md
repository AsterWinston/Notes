# 1. 模块定位

## 1.1 本模块解决什么问题

本模块讲"如何用 Java 把一个 LLM 应用真正写出来"，是连接「模型能力」与「工程实现」的桥梁。所有示例优先使用 Spring AI 与 LangChain4j，并给出原生 HTTP 实现作为对照。

换句话说：前序模块告诉你"模型能做什么"，本模块告诉你"工程上怎么把它稳定、可观测、可回滚地跑在生产里"。

```
┌──────────────┐   ┌──────────────┐   ┌──────────────┐
│  模型能力层   │ → │  本模块：工程层 │ → │  生产运行层   │
│  LLM / Embed │   │  调用·结构化  │   │  部署·监控    │
└──────────────┘   └──────────────┘   └──────────────┘
```

本模块聚焦的工程问题：

| 问题 | 对应文件 |
|------|----------|
| 怎么调通模型接口 | 1、2 |
| 怎么把结果流式返回 | 3 |
| 怎么拿到可靠的结构化数据 | 4 |
| 怎么让模型调用工具 | 5 |
| 怎么控制成本 | 6、7、9 |
| 怎么保证不崩 | 8、10 |
| 怎么组织代码 | 11 |
| 怎么验证正确 | 12 |
| 怎么管理 Prompt | 13 |

## 1.2 与其他模块的边界

|----------|----------------|
| `2_LLM` | 假定已知模型能力与采样参数含义 |
| `3_PromptEngineering` | 假定已知提示词编写与结构化技巧 |

### 1.2.2 下游影响

| 下游模块 | 承接内容 |
|----------|----------|
| `5_RAG` | 复用调用、流式、缓存、重试能力 |
| `6_AgentCore` | 复用函数调用与结构化输出 |
| `9_Frameworks` | 在框架之上做工程化封装 |
| `14_ProductionEngineering` | 承接发布、灰度、监控 |

## 1.3 阅读方式

| 方式 | 适合场景 |
|------|----------|
| 顺序通读 | 系统建立工程认知 |
| 按需跳读 | 解决具体工程问题 |

# 2. 学习目标

## 2.1 能力目标

- 用 Java 调用 OpenAI 兼容接口，处理同步/异步/流式。
- 实现结构化输出与函数调用。
- 掌握 Token 成本、缓存、重试降级、模型路由、护栏等工程细节。
- 形成一套可复用的 LLM 应用分层架构。

## 2.2 非目标（本模块不覆盖）

### 2.2.1 模型训练

微调（fine-tuning）、预训练、RLHF（基于人类反馈的强化学习）等训练侧内容不在本模块范围。

### 2.2.2 提示词方法论

提示词的写法、思维链（CoT）等技巧属于 `3_PromptEngineering`，本模块只处理"如何管理、版本化、评测"它们。

### 2.2.3 运维平台

Kubernetes 部署、网关、日志平台等通用基础设施属于 `14_ProductionEngineering`，本模块只强调"LLM 应用特有的工程点"。

## 2.3 学习产出

学完本模块，你应能独立交付以下产物：

| 产物 | 说明 |
|------|------|
| 一个可调用的 LLM 客户端 | 支持同步、异步、流式 |
| 一套结构化输出管线 | 含校验与失败重试 |
| 一套成本控制策略 | Token 预算 + 缓存 + 路由 |
| 一套容错机制 | 超时、重试、退避、降级 |
| 一套测试方案 | Mock + 契约 + 评测回归 |
| 一套 Prompt 管理流程 | 版本化 + 灰度 + 回滚 |


# 5. 关键知识点速览

## 5.1 核心结论

- 一切从"OpenAI 兼容协议"出发，换厂商成本最低。
- 结构化输出是 Agent 可靠性的前提。
- 函数调用是 Agent 工具能力的底层机制。
- 成本、延迟、可靠性三者的平衡是 LLM 工程的核心。
- 密钥与配置必须外置，绝不硬编码。

## 5.2 常见误区

| 误区 | 纠正 |
|------|------|
| 框架能屏蔽一切差异 | 多厂商协议差异仍需适配 |
| 流式就是快 | 首 Token 延迟才是体感关键 |
| 结构化输出百分百可靠 | 仍需校验与重试 |
| Prompt 是配置不是代码 | 必须版本化、评测、回滚 |
| 重试万能 | 需退避、幂等与降级 |

## 5.3 术语速查

| 术语 | 中文 | 含义 |
|------|------|------|
| Prompt | 提示词 | 发送给模型的指令与上下文 |
| Token | 词元 | 计费与上下文长度的基本单位 |
| SSE | 服务器推送事件 | 流式输出常用协议 |
| Function Calling | 函数调用 | 模型请求调用外部工具 |
| Fallback | 降级 | 主链路失败时的备用方案 |
| Guardrail | 护栏 | 输入输出的安全与格式约束 |
| Eval | 评测 | 对输出质量的量化回归 |
