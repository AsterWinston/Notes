# 2. 高频自检题

## 2.1 语法与类型

**问：`a = [1,2]; b = a; b.append(3)` 后 `a` 是什么？**

`a` 变成 `[1,2,3]`。赋值不复制对象，`a`、`b` 指向同一个列表。要独立副本用 `a.copy()` 或 `copy.deepcopy(a)`。

**问：`is` 和 `==` 的区别？**

`is` 比较对象身份（`id`），`==` 比较值。判断 `None` 用 `is None`；比较内容用 `==`。不要依赖小整数/短字符串的驻留行为。

**问：`0.1 + 0.2 == 0.3` 为什么是 False？**

二进制浮点无法精确表示 0.1 和 0.2，累加产生舍入误差。用 `math.isclose` 或 `decimal.Decimal`。

**问：`if x:` 和 `if x is not None:` 的区别？**

前者是真值测试，`0`、`""`、`[]` 都为假；后者只判断"有没有值"。要区分"缺失"和"值为 0"时必须用后者。

## 2.2 函数与 OOP

**问：为什么默认参数不能用 `[]`？**

默认值在函数定义时求值一次，所有调用共享同一个列表。用 `None` 占位，在函数体内创建。

**问：闭包为什么在循环里都返回同一个值？**

闭包捕获的是变量本身，不是当时的值。循环结束后变量停在最终值。用默认参数 `lambda i=i: i` 或工厂函数固定。

**问：类属性和实例属性的区别？**

类属性所有实例共享；实例赋值会在实例上新建属性并遮蔽类属性。可变类属性（如 `members = []`）会被所有实例共享，是经典陷阱。

**问：`__str__` 和 `__repr__` 的区别？**

`__str__` 给人看（`print`、f-string），`__repr__` 给开发者看（调试、容器打印）。只定义 `__repr__` 时 `__str__` 会复用它。

**问：`@classmethod` 和 `@staticmethod` 的区别？**

类方法第一参数是 `cls`，能访问类状态、常用于工厂方法；静态方法没有隐式参数，只是放在类里的普通函数。

## 2.3 并发与异步

**问：有 GIL 为什么多线程还有用？**

GIL 在 IO 阻塞时释放，其他线程可以继续跑。所以线程适合 IO 密集；CPU 密集要用多进程绕开 GIL。

**问：线程和进程怎么选？**

等 IO 用线程（或 asyncio），烧 CPU 用进程。判断标准是"任务在等还是在算"。

**问：`await` 两个协程是并发吗？**

不是。连续 `await` 是串行。要并发必须 `create_task`、`gather` 或 `TaskGroup`。

**问：异步代码里为什么不能 `time.sleep`？**

`time.sleep` 是阻塞的，会卡住整个事件循环，所有协程一起停摆。用 `await asyncio.sleep` 或 `asyncio.to_thread`。

**问：`CancelledError` 能吞吗？**

不能。它是控制信号，捕获后必须重新 `raise`，否则取消失效、循环无法正确清理。

## 2.4 工程实践

**问：`ModuleNotFoundError` 常见原因？**

装到了另一个解释器（用 `python -m pip`）、虚拟环境未激活、文件与标准库同名、包未被正确安装。先打印 `sys.executable` 和 `sys.path`。

**问：为什么改了模块代码不生效？**

模块首次导入后缓存在 `sys.modules`，不会自动重载。重启进程，或开发时用热重载工具。

**问：相对导入为什么报 "no known parent package"？**

直接运行了包内文件，`__name__` 是 `__main__`，解释器不知道父包。用 `python -m package.module`。

**问：测试里 mock 的 patch 路径写哪？**

写"被测代码使用它的地方"，不是"它定义的地方"。例如被测模块写 `from requests import get`，要 patch `app.get`。

**问：覆盖率 100% 就说明测试好吗？**

不代表。覆盖率只说明代码被执行过，不说明逻辑被验证。只调用不断言也能刷高覆盖率。看缺口，不当 KPI。

# 3. 常见坑清单

| 类别 | 坑 | 规避 |
|------|-----|------|
| 类型 | 浮点直接相等 | `math.isclose` |
| 类型 | `int("3.14")` | 先 `float` |
| 类型 | 用 `== None` | 用 `is None` |
| 类型 | 循环内 `s += x` | `"".join()` |
| 函数 | 可变默认参数 | `None` 占位 |
| 函数 | 闭包延迟绑定 | 默认参数 / 工厂 |
| 函数 | lambda 赋名 | 用 `def` |
| 模块 | 文件与标准库同名 | 重命名 |
| 模块 | 循环导入 | 延迟导入 / 抽公共模块 |
| OOP | 可变类属性 | `__init__` 里创建 |
| OOP | `__eq__` 无 `__hash__` | 补 `__hash__` |
| 异常 | `except: pass` | 记日志 + 重新抛 |
| 异常 | `finally` 里 `return` | 清理逻辑不返回 |
| IO | 不写 `encoding` | 显式 UTF-8 |
| IO | `"w"` 当追加 | 用 `"a"` |
| IO | CSV 用 `split` | 用 `csv` 模块 |
| 并发 | 线程跑 CPU 密集 | 进程池 |
| 并发 | 忘 `join` | `join` 或 daemon |
| 异步 | 协程里阻塞调用 | `await` / `to_thread` |
| 测试 | mock 路径错 | patch 使用处 |
| 打包 | 锁文件不入库 | 提交锁文件 |

★ **关键认知**：坑清单不用背，**用一次错一次比背十遍有效**。建议把每条坑写成一个小测试或小脚本，亲手复现一次——"见过它怎么坏"比"记住它坏"牢固得多。
