# 1. 高频面试题 11 道

## 1.1 盒模型与 box-sizing

**要点**:盒模型是 content/padding/border/margin 四层;`box-sizing: border-box` 让 width 含 padding+border,`content-box` 则不含。

```css
* { box-sizing: border-box; }   /* 现代工程标配 */
```

★ **关键认知**:border-box 让"写的宽即总宽",是现代项目全局 reset 的第一条(第 3 篇)。

## 1.2 水平/垂直居中

**要点**:四种居中——文字 `text-align`、块 `margin:0 auto`、常规元素 flex 居中、脱离流 absolute+translate。

```css
.flex-center { display: flex; justify-content: center; align-items: center; }
.abs-center  { position: absolute; top: 50%; left: 50%; transform: translate(-50%,-50%); }
```

★ **关键认知**:未知尺寸首选 flex,悬浮层用 absolute+translate(translate 百分比相对自身)(第 11 篇)。

## 1.3 层叠与 z-index

**要点**:z-index 只对**已定位**(非 static)元素生效;受**层叠上下文**约束——不同上下文的 z-index 不互通。

★ **关键认知**:"设了 999 还压不住"的真相是不在同一层叠上下文;opacity/transform 也会创建上下文(第 6 篇)。

## 1.4 BFC 及其作用

**要点**:BFC(块级格式化上下文)是独立的布局作用域,作用——**包裹浮动、阻止外边距折叠、隔离浮动侵入**。

```css
.bfc { overflow: hidden; }      /* 或 display: flow-root */
```

★ **关键认知**:flow-root 是"干净"的触发方式,BFC 是破解父塌陷、margin 合并的钥匙(第 15 篇)。

## 1.5 外边距折叠

**要点**:垂直相邻块级的 margin 会合并取较大值;水平不合并;flex/grid 内不合并;触发 BFC 可阻断。

★ **关键认知**:"间距怎么不够/父元素怎么动了"的元凶,多在 margin 折叠(第 15 篇)。

## 1.6 Flex 与 Grid 的区别

| 维度 | Flex | Grid |
|------|------|------|
| 维度 | 一维(单行/列) | 二维(行列) |
| 定位 | 沿主轴 | 按网格线/区域 |
| 典型 | 导航/按钮/居中 | 页面布局/卡片网格 |

★ **关键认知**:一维用 flex、二维用 grid,常"宏观 grid、微观 flex"(第 8、9、11 篇)。

## 1.7 transition 与 animation 的区别

**要点**:transition 需状态触发、单段(A→B);animation 可自动开始、多段、循环。

★ **关键认知**:反馈(悬停)用 transition,入场/循环用 animation(第 12 篇)。

## 1.8 为什么动画只用 transform 和 opacity

**要点**:它们只触发**合成(composite)**,GPU 加速、不回流不重绘;width/top/margin 会触发回流,代价高。

★ **关键认知**:性能层级"回流 > 重绘 > 合成"(第 21 篇)。

## 1.9 响应式的做法

**要点**:三支柱——viewport + 流式布局 + 媒体查询 + min/max/clamp;移动优先(min-width 增强)。

```css
.title { font-size: clamp(1rem, 4vw, 2rem); }   /* 流式字号 */
@media (max-width: 768px) { .grid { grid-template-columns: 1fr; } }
```

★ **关键认知**:先流动、按内容定断点、用 clamp/auto-fill 少写媒体查询(第 10 篇)。

## 1.10 CSS 变量 vs 预处理器变量

**要点**:CSS 变量(`--x`)是**运行时**的(继承、可 JS 改,做主题);SCSS 变量(`$x`)是**编译时**的(替换、可运算)。

★ **关键认知**:动态主题/换肤用 CSS 变量,编译期复用/运算用 SCSS 变量(第 14、17 篇)。

## 1.11 重排(回流)与重绘

**要点**:回流=几何变了重新布局(尺寸/位置,波及周边);重绘=仅视觉变(颜色/背景)。回流代价更高。

★ **关键认知**:减少回流——动画用合成属性、改动脱离流、JS 批量读写、contain 限定范围(第 21 篇)。

# 2. 手写/实践点

| 点 | 关键 |
|----|------|
| 一个两端对齐的导航 | flex + `justify-content: space-between` |
| 一个三栏/圣杯布局 | grid + grid-template-areas |
| 一个响应式卡片网格 | `repeat(auto-fill, minmax(240px, 1fr))` |
| 一个 fade-up 入场动画 | keyframes + opacity/transform |
| 一个暗色主题切换 | CSS 变量挂 `[data-theme]` |

# 4. 进阶方向

| 方向 | 做法 | 收益 |
|------|------|------|
| 布局狂练 | Flexbox Froggy、Grid Garden 游戏通关 | 布局直觉 |
| 设计系统 | 用 CSS 变量 + 组件化搭一套 token | 工程化落地 |
| 性能实战 | Lighthouse CSS 审计、动画掉帧排查 | 性能硬指标 |
| 现代特性 | 容器查询、:has()、subgrid、color-mix | 前沿能力 |
| 框架衔接 | 进入 Vue/React 系列,看样式方案(scoped/CSS-in-JS) | 打通全栈 |

★ **关键认知(全系列收束)**:CSS 的本质是**一套"层叠 + 布局 + 表现"的声明式语言**——选择器决定命中谁,层叠决定谁赢,盒模型/Flex/Grid 决定怎么摆,动画与特效决定质感。把 22 篇浓缩一句:**用选择器精准命中、用层叠理顺优先级、用现代布局(而非 hack)搭建结构、用合成属性守护性能**——到这,你就越过了 CSS 的"会用"线,站到了"懂"的那一侧。HTML 给了结构,现在你有了让它好看的完整能力。
