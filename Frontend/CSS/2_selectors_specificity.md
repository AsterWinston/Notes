选择器是 CSS 的"瞄准镜"——决定样式落到哪个元素;特异性(specificity)则是冲突时的"裁判"——决定哪个规则赢。本篇讲清选择器全集(基础/组合/属性/伪类/伪元素)与特异性计算的完整规则,把 `:is()` / `:where()` 这些"会改变特异性"的坑一并点破。

# 1. 基础选择器

## 1.1 四大基础

```css
* { }            /* 通配:所有元素 */
p { }            /* 类型/元素:所有 <p> */
.title { }       /* 类:class="title" 的元素 */
#app { }         /* ID:id="app" 的元素(唯一) */
```

★ **关键认知**：四个基础选择器——通配 `*`、元素、类 `.`、ID `#`。⚠ `*` 性能最差(命中一切),且 `*` 的样式极难维护,慎用;ID 特异性极高、不可复用,样式上**优先用 class**。

## 1.2 分组与并列

```css
/* 分组:多个选择器共享同一样式(逗号分隔) */
h1, h2, h3 { margin: 0; }

/* 并列:同一元素同时满足多个条件(不加空格) */
p.big { }            /* 既是 p 又有 class="big" */
```

★ **关键认知**：**逗号是"或"**(分组,命中任一),**空格/紧挨是"与"**(并列,须同时满足)。⚠ 逗号分隔的每个选择器是**独立完整**的——`h1, h2` 不是"h1 里的 h2",而是"h1 或 h2"。

# 2. 组合器

## 2.1 四种组合

```css
div p { }        /* 后代(空格):div 里任意深度的 p */
div > p { }      /* 子代(>):div 的直接子 p */
div + p { }      /* 相邻兄弟(+):紧跟 div 之后的 p */
div ~ p { }      /* 通用兄弟(~):div 之后所有同级 p */
```

★ **关键认知**：四种组合器的关系远近——**后代(空格)最宽(任意深度)**,**子代(>)只一层**,**相邻(+)只下一个**,**通用(~)所有后续兄弟**。⚠ `+` 是"**紧跟其后**"的一个,`~` 是"**后面的全部**",二者最容易混;用对了能少加很多 class。

# 3. 属性选择器

```css
[disabled] { }        /* 有 disabled 属性 */
[type="text"] { }     /* type 恰好等于 text */
[class~="btn"] { }    /* class 值列表中含 btn(空格分隔的词) */
[lang^="en"] { }      /* 以 en 开头 */
[href$=".pdf"] { }    /* 以 .pdf 结尾 */
[href*="example"] { } /* 包含 example */
```

★ **关键认知**：属性选择器按**属性及其值**匹配——存在、精确相等、前缀/后缀/包含,还有一个 `[attr|="zh"]`(等于或以 `zh-` 开头)。⚠ 它常用于"不带 class 也能命中"(如 `input[type="text"]`),减少为纯样式而加 class 的负担。

# 4. 伪类与伪元素

## 4.1 常用伪类(pseudo-class)

```css
a:hover { }         /* 悬停 */
a:focus { }         /* 聚焦 */
li:first-child { }  /* 是父元素的第一个子元素 */
li:last-child { }   /* 最后一个 */
li:nth-child(2n) { }/* 第偶数个(2n+1 奇数) */
input:checked { }   /* 勾选状态 */
p:not(.special) { } /* 排除 */
```

★ **关键认知**：伪类描述元素的**状态/位置**——交互态(`:hover`/`:focus`)、结构位置(`:first-child`/`:nth-child`)、状态(`:checked`)。⚠ 两类要分清:`:nth-child(n)` 按**在所有子元素中的序号**算,`:nth-of-type(n)` 按**在同类元素中的序号**算,后者更符合"第几个 p"的直觉。

## 4.2 伪元素(pseudo-element)

```css
p::before { content: "前插内容"; }
p::after  { content: "后插内容"; }
p::first-letter { }   /* 首字母 */
p::first-line   { }   /* 首行 */
::selection { }       /* 选中文本的样式 */
```

★ **关键认知**：伪元素 `::before`/`::after` 生成**虚拟元素**(必须配 `content`),常用来做小图标、清浮动、装饰线。⚠ **伪类是单冒号 `:`(如 :hover),伪元素是双冒号 `::`(如 ::before)**——老写法伪元素也兼容单冒号,但现代规范统一双冒号,别混。

# 5. 特异性计算

## 5.1 三元组规则

```css
/* 特异性 = (ID数, class/属性/伪类数, 元素/伪元素数),逐位比较 */
#nav a:hover      /* (1, 1, 1):1 id + 1 伪类 + 1 元素 */
.content .item    /* (0, 2, 0):2 个 class */
ul > li           /* (0, 0, 2):2 个元素 */

/* 比较:先比第一位(1>0,#nav... 赢);同一位再比下一位 */
```

★ **关键认知**：特异性是**(id, class, 元素)三元组**,不是拼成"111"的数字——逐位比较,高位比完才比下一位。⚠ 经典误区:**`ul > li`(0,0,2)永远打不过 `.item`(0,1,0)**——因为 class 位更高;再多的元素选择器也压不过一个 class。

## 5.2 会"改写"特异性的选择器

```css
/* :is() / :not() 取参数里最高的特异性 */
:is(h1, h2, .title) { }   /* 取 .title 的特异性 (0,1,0) */

/* :where() 特异性恒为 0,便于写"低优先级"的批量样式 */
:where(.btn, .link) { }   /* 特异性 (0,0,0),可被任何 class 轻松覆盖 */
```

★ **关键认知**：`:is()`/`:not()` 的特异性是**参数里最高的那个**;`:where()` 则**恒为 0**。⚠ 现代 CSS 里 `:where()` 常用于"定义一批可被轻易覆盖的默认样式"(如 reset),因为它永远不跟人抢优先级——这是新老特异性的一个优雅拐点。

## 5.3 行内样式与 !important 的位置

```html
<p id="x" style="color: red;">行内样式</p>
```

```css
#x { color: blue !important; }   /* !important 反超行内样式 */
```

★ **关键认知**：完整优先级链(从高到低):**!important 声明 → 行内 style → ID → class/属性/伪类 → 元素/伪元素**。⚠ `!important` 会**破坏层叠的可预测性**,是"核按钮"——一旦用开,后续想覆盖只能再加 !important,项目就此陷入军备竞赛。**先想"能否提高选择器特异性"替代它**。

# 6. 本篇小结与下一步

★ **关键认知**：选择器是"命中谁",特异性是"谁更该赢"。特异性三元组逐位比较,高阶永远压过低阶;`:where()`=0、`:is()`/`:not()`=参数最高值。!important 是最后的核武器,能不用就不用。
