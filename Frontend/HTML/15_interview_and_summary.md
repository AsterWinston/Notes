# 1. 高频面试题 10 道

## 1.1 块级元素与内联元素的区别

**要点**:块级(block)独占一行、可设宽高;内联(inline)随文字流动、宽高由内容决定。

```html
<div>块级:占满整行</div>
<p>块级段落</p>
<span>内联:行内排列</span>
<a>内联链接</a>
```

★ **关键认知**:块级/内联是**默认表现**,可通过 CSS `display` 互相转换;常见块级(div/p/h1~h6/ul/li)、内联(span/a/em/strong)。⚠ 内联里不能嵌套块级,这是**内容模型**的约束(第 14 篇)。

## 1.2 HTML 语义化是什么

**要点**:用有语义的标签描述内容(标题 h1、导航 nav、文章 article…),让机器(搜索/读屏)读懂结构,而非满屏 div。

★ **关键认知**:语义化的三大收益——**SEO、可访问性、可维护**;它不改变外观,是"给机器看的说明书"(第 9 篇)。

## 1.3 GET 与 POST 的区别

| 维度 | GET | POST |
|------|-----|------|
| 数据位置 | URL 查询串 | 请求体 |
| 可见性 | 可见(留历史) | 相对隐蔽 |
| 可缓存 | 可 | 不可 |
| 适用 | 查询 | 提交敏感/大量数据 |

★ **关键认知**:敏感数据(密码、token)**绝不能用 GET**;GET 适合无副作用的查询(第 6 篇)。

## 1.4 label 的作用

**要点**:把文字说明与表单控件关联,点击文字=聚焦/勾选控件,并让读屏播报字段名。

```html
<label for="email">邮箱</label>
<input id="email" type="email">
```

★ **关键认知**:`for` 指向控件 `id`;**别用 placeholder 替代 label**,它是可访问性的关键(第 6 篇)。

## 1.5 src 与 href 的区别

**要点**:`src`(source)把资源**嵌入**到当前内容(图片、脚本、iframe),浏览器会**立即加载并替换**;`href`(hypertext reference)是**引用/链接**(指向另一资源或文档)。

★ **关键认知**:`<img src>` 把图拿来显示,`<a href>` 指向跳转目标;`<script src>` 会阻塞解析,`<link href>`(样式)会阻塞渲染。

## 1.6 为什么图片要写 alt

**要点**:alt 是**替代文本**——图片加载失败时显示、屏幕阅读器朗读它。纯装饰图写 `alt=""` 让读屏忽略。

★ **关键认知**:每张图都应写 alt;它是可访问性头号考点(第 5 篇)。

## 1.7 defer 与 async 的区别

| 维度 | defer | async |
|------|-------|-------|
| 下载 | 并行 | 并行 |
| 执行时机 | DOM 解析完、按序 | 下载完立即、无序 |
| 适用 | 依赖 DOM/顺序 | 独立第三方脚本 |

★ **关键认知**:两者都不阻塞下载,区别在执行时机(第 12 篇);`type="module"` 自带 defer 语义。

## 1.8 浏览器如何解析 HTML

**要点**:字节 → 解码 → 分词(tokenizer)→ 构建 DOM 树(容错修正)→ 渲染;HTML 是容错解析,错了不报,自动修复。

★ **关键认知**:DOM 树是 JS/浏览器面对的结构;"能跑≠对",真正把关靠校验器(第 1、14 篇)。

## 1.9 viewport 的作用

**要点**:`<meta name="viewport" content="width=device-width, initial-scale=1.0">` 让布局视口等于设备宽度,是移动端/响应式的第一块砖。

★ **关键认知**:少了它,手机按桌面 980px 渲染再缩小,文字小到看不清(第 3 篇)。

## 1.10 什么是 Web Components

**要点**:浏览器原生组件化三件套——**customElements**(自定义标签)、**Shadow DOM**(样式隔离)、**template/slot**(结构模板);与框架的区别在"语言级 vs 框架级"。

★ **关键认知**:Web Components 跨框架通用,框架组件生态更完善,二者互补而非对立(第 11 篇)。

# 4. 进阶方向

| 方向 | 做法 | 收益 |
|------|------|------|
| CSS 精修 | 继续本仓库 CSS 系列(Flex/Grid/动画/工程化) | 让结构真正"美观与响应式" |
| 无障碍深挖 | 读 WCAG 规范、用 axe/读屏实测 | 把可访问性落成硬实力 |
| SEO 实践 | 结构化数据 + 核心 Web 指标(LCP/CLS) | 站点收录与排名 |
| 框架衔接 | 进入 Vue/React 系列,看模板如何被接管 | 打通 HTML→框架 |
| 性能工具 | Lighthouse/PageSpeed 实测优化 | 首屏速度硬指标 |

★ **关键认知(全系列收束)**:HTML 的本质是**语义化的结构描述语言**——它不"编程",却通过"结构 + 语义"为 CSS 的表现、JS 的行为、搜索引擎的理解、读屏的播报提供地基。把 15 篇浓缩一句:**用对标签表达结构,用对属性表达语义,让看得见的人与看不见的机器都读得懂**——做到这三点,HTML 你就真正入门了。下一步,带上这套结构功底,进入 CSS 的世界。
