一个 HTML 文档的顶层骨架只有三个元素——`<html>`、`<head>`、`<body>`——但它们的职责边界、以及那些"能挂在任何标签上"的全局属性（`id`、`class`、`data-*`、`lang`…），决定了你的结构是否规范。本篇讲清这三层的分工、全局属性全家福，以及 DOM 树的真实形态。

# 1. 顶层骨架的三个角色

## 1.1 html / head / body 各司其职

```html
<!DOCTYPE html>
<html lang="zh-CN">       <!-- 根元素：整个文档的容器 -->
  <head>                  <!-- 元信息：编码、标题、样式、SEO，不直接显示 -->
    <meta charset="UTF-8">
    <title>页面标题</title>
  </head>
  <body>                  <!-- 可见内容：用户实际看到的一切 -->
    <p>这里是正文。</p>
  </body>
</html>
```

★ **关键认知**：`<html>` 是**唯一根元素**，`<head>` 装**不可见的元信息**，`<body>` 装**可见内容**——三者各一个，缺一不可（虽然浏览器容错会帮你补）。⚠ `head` 里的内容"不显示"，不代表"可有可无"：`title` 决定标签页和搜索结果标题，`meta` 决定编码与移动端适配，漏了它们页面会"错得默默无闻"。

## 1.2 head 与 body 的边界

| 放哪 | 内容 | 可见? |
|------|------|-------|
| `<head>` | meta、title、link、style、script（部分） | 否 |
| `<body>` | 段落、图片、表单、脚本等一切结构 | 是 |

★ **关键认知**：判断一个元素该放 head 还是 body 的标准是**"它是不是内容本身"**——描述文档的（编码、标题、样式）进 head，构成页面内容的进 body。⚠ 例外是 `<script>`：它既能出现在 head（但会阻塞渲染，见第 12 篇），也能出现在 body；`title` 与 `meta` 则只能出现在 head。

# 2. 全局属性

## 2.1 id 与 class

```html
<p id="intro">全局唯一的段落</p>
<p class="card highlight">可复用的段落</p>
<!-- 一个元素可同时有 id 和多个 class，但不能有两个 id -->
```

★ **关键认知**：`id` 是**文档内唯一**的身份标识（一个 id 值全页只能出现一次），`class` 是**可复用**的分类标记（一个 class 可用于任意多个元素、一个元素可有多个 class）。⚠ 用途上：`id` 用于精确锚点定位（`#intro`）、JS 精确取元素；`class` 用于批量样式与"同一类元素"。历史遗留的乱用是：用 class 做唯一标识、或复制粘贴导致 id 重复——后者会让 `getElementById` 只返回第一个。

## 2.2 data-* 自定义属性

```html
<!-- data- 前缀：存放"不属于标准属性"的自定义数据，供 JS 读取 -->
<button data-id="42" data-action="delete">删除</button>
```

```javascript
// JS 通过 dataset 读取
const btn = document.querySelector('button')
btn.dataset.id      // "42"
btn.dataset.action  // "delete"
```

★ **关键认知**：`data-*` 是**官方留给你的自定义数据通道**——任何想挂在元素上、又不是标准属性的信息（记录 id、状态、配置），都规范地放进 `data-xxx`，JS 用 `dataset.xxx` 读取。⚠ `data-` 里的连字符名会转成驼峰（`data-user-id` → `dataset.userId`）；它只存字符串，复杂结构需 JSON 序列化。别再用 `rel="my-note"` 这类"借用标准属性"的 hack。

## 2.3 lang、title、dir 等

```html
<html lang="zh-CN">                        <!-- 文档语言 -->
<p title="悬停提示的文字">带提示的段落</p>     <!-- 原生 tooltip -->
<p dir="rtl">从右往左的文字（如阿拉伯语）</p>   <!-- 文字方向 -->
```

★ **关键认知**：`lang` 声明语言（供屏幕阅读器选发音、供浏览器做拼写/翻译判断），`title` 提供悬停提示，`dir` 控制文字方向（rtl 用于阿拉伯语/希伯来语）。⚠ `lang` 是**继承且可切换**的：整页中文时在 `<html>` 标 `zh-CN` 即可，局部出现外文可在那个元素上单独覆盖。`title` 的提示**对键盘/触屏用户不可见**，重要信息别只放在 title 里。

## 2.4 全局属性一览

| 属性 | 作用 | 注意 |
|------|------|------|
| `id` | 唯一标识 | 全页唯一 |
| `class` | 分类 | 可多个、可复用 |
| `data-*` | 自定义数据 | JS 用 dataset 读 |
| `lang` | 语言 | 影响无障碍与翻译 |
| `title` | 悬停提示 | 触屏不可见 |
| `dir` | 文字方向 | ltr / rtl |
| `hidden` | 隐藏 | 等价 display:none |
| `tabindex` | 键盘焦点顺序 | 可访问性相关 |

# 3. 元素与 DOM 树

## 3.1 嵌套规则：块级与内联

```html
<!-- 块级元素（block）占满整行；内联元素（inline）随文字流动 -->
<p>段落是<b>块级</b>元素</p>
<span>这是内联元素，</span><a href="#">跟着排在行内</a>
```

★ **关键认知**：元素按默认展示分**块级（block，独占一行：`<p>`、`<div>`、标题）**与**内联（inline，行内排列：`<span>`、`<a>`、`<em>`）**。⚠ 嵌套必须"合法"：**块级里可以放内联，内联里不能再放块级**（如 `<a><div>` 不规范）。浏览器虽容错，但非法嵌套会产生意外 DOM 结构。

## 3.2 源码结构 vs DOM 树

```html
<div id="a">
  <p>第一段</p>
  <p>第二段</p>
</div>
```

```
DOM 树：
      div#a
      /    \
   p(第一段)  p(第二段)
       │          │
    文本节点     文本节点
```

★ **关键认知**：DOM 树把每个元素、每段文字都变成**节点**——元素节点 + 文本节点交织成树。⚠ 源码里元素间的**空白（换行、缩进）也会成为文本节点**，这在"精确计数子节点""用 :first-child 选择器"时会造成困扰，是前端入门最隐蔽的坑之一。
