引用和 `const` 是 C++ 里出现频率最高、也最容易被"用是会用了，但说不清为什么"的两个东西。引用看起来像指针，行为却完全不同；`const` 看起来只是"不能改"，位置一变含义就全变。本篇把它们和 `constexpr`、值类别一起讲透，为后面讲移动语义和完美转发打底。

# 1. 引用

## 1.1 引用是什么

引用是变量的**别名**，必须在定义时绑定，绑定后不能改绑：

```cpp
int a = 10;
int& r = a;      // r 是 a 的别名

r = 20;          // 等价于 a = 20
std::cout << a;  // 输出 20，a 和 r 是同一块内存
```

底层实现上，编译器通常用指针来实现引用，但**语言层面引用不是指针**：它没有自己的地址语义，`&r` 得到的是 `a` 的地址，`sizeof(r)` 等于 `sizeof(int)`。

```text
变量 a            引用 r
┌──────────┐
│    20    │ ◄──── r 只是 a 的另一个名字
└──────────┘
  0x1000
```

★ **关键认知**：引用在**初始化之后就无法再指向别的对象**。`int& r = a; r = b;` 不是让 `r` 改绑到 `b`，而是把 `b` 的值赋给 `a`。这一点和指针的"重新赋值"完全不同，是理解引用语义的核心。

⚠ **关键认知**：引用必须初始化，也不存在"空引用"。`int& r;` 编译不过。如果你需要"可能不指向任何对象"的语义，那要用指针，而不是硬凑一个引用。

## 1.2 引用与指针的差异

| 维度 | 引用 | 指针 |
|------|------|------|
| 是否必须初始化 | 是 | 否（但野指针危险） |
| 能否改绑 | 否 | 是 |
| 是否可为空 | 否 | 是（`nullptr`） |
| 是否占独立存储 | 语言层面不要求 | 是，存放地址 |
| 算术运算 | 不支持 | 支持 |
| 访问方式 | 直接用，无需解引用 | 需 `*p` |
| 典型用途 | 传参、返回值、别名 | 可选对象、数组遍历、底层操作 |

★ **关键认知**：选择标准很简单——**这个参数允许"没有"吗？** 允许就用指针（或 `std::optional`），不允许就用引用。接口设计上，引用能把"必须传一个有效对象"写进类型里，减少调用方的分支判断。

## 1.3 引用的常见用途

**传参避免拷贝**：

```cpp
void print(const std::string& s);   // 只读，不拷贝
void fill(std::vector<int>& v);     // 要修改原对象
```

**返回引用**（注意生命周期）：返回的引用必须指向活得比函数更久的对象，否则就是悬垂引用。

**范围 for 中避免拷贝**：

```cpp
for (const auto& item : items) {    // 不拷贝，且只读
    std::cout << item << '\n';
}
```

⚠ **关键认知**：不要返回**局部变量的引用**。函数结束时局部对象已销毁，返回的引用变成悬垂引用，用它是未定义行为：

```cpp
int& bad() {
    int x = 42;
    return x;      // 错误：x 在函数返回后已销毁
}
```

# 2. const

## 2.1 const 修饰变量

`const` 表示"通过这个名字不能修改"，是编译期约束：

```cpp
const int max_size = 100;
// max_size = 200;   // 编译错误

int a = 1;
int b = 2;
const int* p1 = &a;   // 指向的内容不能改，指针本身可以改
int* const p2 = &a;   // 指针本身不能改，内容可以改
const int* const p3 = &a;  // 两者都不能改
```

读法技巧：**从变量名往左看，`const` 修饰它右边最近的东西**（`const int*` 读作"指向 const int 的指针"）。

⚠ **关键认知**：`const` 只是编译期承诺，`const_cast` 能绕过它。如果对象本身定义时就是 `const`，强行去掉 `const` 再写是未定义行为；如果对象本来非 const，只是通过 const 引用/指针访问，那么去掉 const 后修改是合法的。不要拿 `const_cast` 当日常工具。

## 2.2 指针与 const 的组合

| 写法 | 含义 | 能否改指向 | 能否改内容 |
|------|------|-----------|-----------|
| `int* p` | 普通指针 | 能 | 能 |
| `const int* p` | 指向常量的指针 | 能 | 不能 |
| `int* const p` | 常量指针 | 不能 | 能 |
| `const int* const p` | 两者都 const | 不能 | 不能 |

```cpp
int x = 1, y = 2;
const int* p = &x;
p = &y;        // 合法：改指向
// *p = 3;     // 错误：不能改内容

int* const q = &x;
*q = 3;        // 合法：改内容
// q = &y;     // 错误：不能改指向
```

## 2.3 const 成员函数

在成员函数参数列表后加 `const`，表示这个函数不修改对象状态：

```cpp
class Point {
public:
    int x() const { return x_; }   // 只读接口
    void setX(int x) { x_ = x; }   // 修改接口
private:
    int x_ = 0;
};
```

★ **关键认知**：`const` 成员函数里的 `this` 类型是 `const Point*`，因此只能调用其他 `const` 成员函数、只能读成员。**const 对象只能调用 const 成员函数**，这是编译器强制的。养成"能加 const 就加"的习惯，接口的只读性会一目了然。

```cpp
const Point p;
p.x();        // 可以
// p.setX(1); // 错误：const 对象不能调用非 const 成员函数
```

有时确实需要在 const 函数里改缓存，用 `mutable`：

```cpp
class Cache {
public:
    int get() const {
        if (!computed_) {
            value_ = 42;       // mutable 成员允许在 const 函数里修改
            computed_ = true;
        }
        return value_;
    }
private:
    mutable int value_ = 0;
    mutable bool computed_ = false;
};
```

⚠ **关键认知**：`mutable` 只该用于"对外不可见"的缓存或统计，滥用会破坏 const 语义，让调用方误以为对象没变。

## 2.4 const 引用传参

```cpp
void log(const std::string& msg);   // 最佳实践：只读大对象
```

const 引用有两个好处：避免拷贝，且能绑定临时对象：

```cpp
log("hello");   // 字面量先构造临时 string，再绑定到 const 引用
```

★ **关键认知**：**非 const 引用不能绑定临时对象**，const 引用可以。这就是为什么 `void f(std::string&)` 不能传 `"abc"`，而 `void f(const std::string&)` 可以。临时对象的生命周期会被延长到引用的作用域结束。

# 3. constexpr

## 3.1 编译期计算

`constexpr` 表示"这个值/函数可以在编译期求值"：

```cpp
constexpr int square(int x) { return x * x; }

constexpr int a = square(5);        // 编译期算出 25
int n = 5;
int b = square(n);                  // n 不是常量，退化为运行期调用
```

`constexpr` 函数**不强制**在编译期执行：参数是常量表达式时能编译期算，否则运行期算。

## 3.2 constexpr 的实用场景

```cpp
constexpr int days_in_year(int year) {
    return (year % 4 == 0 && year % 100 != 0) || (year % 400 == 0) ? 366 : 365;
}

constexpr int kDays = days_in_year(2024);   // 编译期常量，可直接做数组大小

template <int N>
struct Array { int data[N]; };

Array<days_in_year(2024)> arr;              // 编译期值可用于模板参数
```

C++17 起 `constexpr` 函数里可以使用 `if`、局部变量、循环（C++14 已放开），写起来接近普通函数。

## 3.3 const、constexpr 与 consteval

| 关键字 | 含义 | 求值时机 | 能否用于数组大小/模板参数 |
|--------|------|----------|--------------------------|
| `const` | 运行期只读 | 运行期 | 否（除非同时是常量表达式） |
| `constexpr` | 可编译期求值 | 能编译期就编译期 | 是 |
| `consteval` | 必须编译期求值 | 强制编译期 | 是 |

```cpp
int x = 10;
const int a = x;          // a 是只读，但值来自运行期
constexpr int b = 10;     // b 是编译期常量
// constexpr int c = x;   // 错误：x 不是常量表达式

consteval int must_compile(int v) { return v * 2; }
constexpr int d = must_compile(3);   // 必须能在编译期求值
```

★ **关键认知**：`const` 回答的是"**能不能改**"，`constexpr` 回答的是"**是不是编译期常量**"。`const int` 不一定是常量表达式，`constexpr` 一定是 const。把两者混为一谈，会在需要模板参数或数组大小时碰壁。

⚠ **关键认知**：`constexpr` 函数里不能有 `new`、`delete`（C++20 前）、`try`、虚函数调用等运行期专属操作。编译器报错时先看函数体里有没有这些。

# 4. 值类别入门

## 4.1 左值与右值

C++ 的每个表达式都有值类别，最常用的是左值和右值：

| 类别 | 特征 | 例子 |
|------|------|------|
| 左值（lvalue） | 有名字、有持久地址 | 变量、`*p`、`arr[0]` |
| 右值（rvalue） | 临时、即将销毁 | 字面量、`a + b`、函数返回的临时对象 |

```cpp
int a = 1;
int b = 2;

int& r1 = a;        // 左值引用绑定左值
int&& r2 = a + b;   // 右值引用绑定右值（临时结果）

// int& r3 = a + b;  // 错误：非 const 左值引用不能绑右值
const int& r4 = a + b;  // 正确：const 左值引用可以绑右值
```

## 4.2 引用绑定规则

| 引用类型 | 能绑左值 | 能绑右值 | 典型用途 |
|----------|---------|---------|----------|
| `T&` | 是 | 否 | 修改实参 |
| `const T&` | 是 | 是 | 只读传参 |
| `T&&` | 否 | 是 | 移动语义、完美转发 |

```cpp
void take_lref(int& x);        // 只接受左值
void take_cref(const int& x);  // 左右值都接受
void take_rref(int&& x);       // 只接受右值
```

★ **关键认知**：右值引用 `T&&` 的引入，是移动语义的语言基础。它让"这个对象马上要被销毁，可以安全地偷走它的资源"这件事能被类型系统表达出来。第 10 篇会详细展开。

# 5. 常见误用

| 误用 | 后果 | 正确做法 |
|------|------|----------|
| 返回局部变量引用 | 悬垂引用，未定义行为 | 返回值，或返回堆上对象 |
| 引用成员指向外部临时对象 | 对象销毁后悬垂 | 用值成员，或明确生命周期 |
| `const` 对象调用非 const 成员 | 编译错误 | 把只读函数标为 const |
| 用 `const_cast` 改真 const 对象 | 未定义行为 | 重新设计接口 |
| 非 const 引用传字面量 | 编译错误 | 改用 const 引用 |
| 把 `constexpr` 当运行期开关 | 编译期无法求值时报错 | 确认参数是常量表达式 |

⚠ **关键认知**：悬垂引用比悬垂指针更隐蔽，因为它用起来和正常引用一模一样，没有 `*` 提示你"这里在解引用"。任何返回引用或保存引用的地方，都要问一句：**被引用的对象活多久？**

# 7. 小结

| 概念 | 要点 |
|------|------|
| 引用 | 别名，必须初始化，不可改绑，无空引用 |
| 指针 | 可空、可改绑、可运算，需判空 |
| 选型 | 允许为空用指针，否则用引用 |
| `const` 变量 | 通过该名字不可改 |
| `const` 指针 | 看 const 在 `*` 左还是右 |
| const 成员函数 | 不修改对象，const 对象只能调它 |
| `constexpr` | 可编译期求值，非"必须" |
| `consteval` | 必须编译期求值 |
| 值类别 | 左值有地址，右值临时 |
