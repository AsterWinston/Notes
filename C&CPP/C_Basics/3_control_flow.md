控制流决定程序"走哪条路、走几遍、什么时候停"。`if` 和循环的语法几分钟就能学会，但悬空 `else`、`switch` 漏写 `break`、循环边界差一、`goto` 滥用这些问题，往往要在调试器里待上半天。本篇把分支、循环和跳转的机制与边界一次讲清楚。

# 1. 语句与代码块

## 1.1 复合语句

用一对花括号包起来的语句序列叫**复合语句**（代码块），在语法上等价于一条语句：

```c
{
    int x = 1;   // x 的作用域从这里开始
    x = x + 1;
}               // x 的作用域到这里结束
```

★ **关键认知**：C 的代码块同时决定**作用域**。在块内定义的变量出了块就不可见，这也解释了为什么在 `if` 分支里定义的变量，到了分支外就用不了。

## 1.2 表达式语句与空语句

```c
x = 1;   // 表达式语句
;        // 空语句，单独一个分号
```

⚠ **关键认知**：`if (x);` 后面那个分号是一个**空语句**，意味着"条件成立时什么都不做"。这是最常见的笔误之一，编译器通常不会报错。

# 2. 条件分支

## 2.1 if 与 else

```c
#include <stdio.h>

int main(void) {
    int score = 85;

    if (score >= 90) {
        printf("优秀\n");
    } else if (score >= 60) {
        printf("及格\n");
    } else {
        printf("不及格\n");
    }
    return 0;
}
```

条件表达式的结果是"零"或"非零"，C 没有真正的布尔类型（C99 的 `_Bool` 是整数类型）。任何非零值都为真：

```c
if (1)     { }   // 真
if (-1)    { }   // 真，非零即真
if (0)     { }   // 假
if (0.5)   { }   // 真
```

## 2.2 悬空 else

`else` 总是与**最近的、尚未配对的 `if`** 结合：

```c
if (a)
    if (b)
        printf("a 且 b\n");
else
    printf("else 属于哪个 if？\n"); // 实际属于内层 if
```

上面代码的 `else` 属于内层 `if (b)`，而不是外层 `if (a)`。正确做法是始终加花括号：

```c
if (a) {
    if (b) {
        printf("a 且 b\n");
    }
} else {
    printf("a 为假\n");
}
```

★ **关键认知**：花括号不改变语义，但能**消除歧义**。所有 `if`、`else`、循环体都加花括号，是避免悬空 `else` 和后续维护出错的最简单规则。

## 2.3 switch

`switch` 根据整数表达式的值跳转到对应 `case`：

```c
#include <stdio.h>

int main(void) {
    int op = 2;

    switch (op) {
        case 1:
            printf("加法\n");
            break;
        case 2:
        case 3:
            printf("乘法或除法\n"); // 多个 case 共用一个分支
            break;
        default:
            printf("未知操作\n");
            break;
    }
    return 0;
}
```

规则与限制：

| 规则 | 说明 |
|------|------|
| 表达式必须是整数类型 | `char`、`int`、`enum` 可以，`float` 不行 |
| `case` 必须是常量表达式 | 不能写运行时变量 |
| 不写 `break` 会**贯穿** | 继续执行下一个 `case` |
| `default` 可省略 | 但建议保留，便于处理意外值 |

★ **关键认知**：`switch` 的"贯穿"（fallthrough）是**特性不是 bug**，用来让多个值共享同一段逻辑。但意外贯穿极其危险，GCC 可以用 `-Wimplicit-fallthrough` 提醒；有意贯穿时写注释 `/* fallthrough */`。

```c
switch (x) {
    case 1:
        printf("一");
        /* fallthrough */   // 明确告诉读者和编译器：这是故意的
    case 2:
        printf("到二\n");
        break;
}
```

## 2.4 switch 与 if 的选择

| 场景 | 推荐 |
|------|------|
| 判断范围（`x > 10`） | `if` |
| 判断离散整数常量 | `switch` |
| 分支很多且值是连续的枚举 | `switch` |
| 条件包含逻辑组合 | `if` |

# 3. 循环

## 3.1 for 循环

`for` 适合**已知次数**或**有明确初始化与步进**的循环：

```c
#include <stdio.h>

int main(void) {
    for (int i = 0; i < 5; ++i) {
        printf("%d ", i);   // 输出 0 1 2 3 4
    }
    printf("\n");
    return 0;
}
```

执行顺序：

```text
初始化 i = 0
   │
   ▼
判断 i < 5 ──假──► 退出循环
   │真
   ▼
执行循环体
   │
   ▼
执行 ++i
   │
   └──► 回到判断
```

C99 起允许在 `for` 初始化里声明变量，其作用域仅限循环。

## 3.2 while 循环

`while` 适合**条件驱动**、次数不确定的循环：

```c
int n = 123;
int sum = 0;

while (n > 0) {
    sum += n % 10;  // 取最后一位累加
    n /= 10;        // 去掉最后一位
}
```

⚠ **关键认知**：`while` 循环体里必须有能**让条件最终变假**的语句，否则就是死循环。上面代码依赖 `n /= 10` 逐步把 `n` 变成 0。

## 3.3 do-while 循环

`do-while` 先执行一次，再判断条件，至少执行一次：

```c
int input;
do {
    printf("请输入 1-10：");
    scanf("%d", &input);
} while (input < 1 || input > 10);
```

| 循环 | 判断时机 | 最少执行次数 | 适用场景 |
|------|----------|-------------|----------|
| `for` | 每次迭代前 | 0 | 计数循环 |
| `while` | 每次迭代前 | 0 | 条件循环 |
| `do-while` | 每次迭代后 | 1 | 至少执行一次，如输入校验 |

★ **关键认知**：`do-while` 的 `while (...)` 后面**必须带分号**，这是三种循环里唯一需要分号结尾的。漏掉会引发后续莫名其妙的语法错误。

# 4. 跳转语句

## 4.1 break 与 continue

| 语句 | 作用 |
|------|------|
| `break` | 立即跳出**最内层**的 `switch` 或循环 |
| `continue` | 跳过本次迭代剩余部分，进入下一次迭代 |

```c
for (int i = 0; i < 10; ++i) {
    if (i == 3) continue;   // 跳过 3
    if (i == 7) break;      // 到 7 直接结束
    printf("%d ", i);       // 输出 0 1 2 4 5 6
}
```

⚠ **关键认知**：`break` 只跳出**一层**。嵌套循环里想一次跳出两层，要么用标志变量，要么把循环抽成函数后 `return`，要么用 `goto`（见下节）。

## 4.2 goto 的边界

`goto` 无条件跳转到同一函数内的标签：

```c
#include <stdlib.h>
int init(int *buf);   // 由调用方提供具体实现
int run(int *buf);

int process(void) {
    int *buf = malloc(1024);
    if (buf == NULL) {
        return -1;
    }

    if (init(buf) != 0) {
        goto cleanup;       // 出错时跳到统一清理
    }

    if (run(buf) != 0) {
        goto cleanup;
    }

    free(buf);
    return 0;

cleanup:
    free(buf);
    return -1;
}
```

★ **关键认知**：`goto` 在现代 C 里唯一被广泛接受的用法是**统一错误清理**。它把分散的 `free`、`fclose`、解锁集中到一处，避免遗漏。Linux 内核大量使用这种模式。

⚠ **关键认知**：`goto` 不能跳进变量作用域内部，也不能跨函数跳转。用 `goto` 写普通循环或往回跳，会让控制流难以理解，属于应当禁止的用法。

# 5. 常见错误

| 错误 | 表现 | 修复 |
|------|------|------|
| `if (x = 0)` | 赋值而非比较 | 写 `if (x == 0)`，或把常量放左边 |
| 悬空 `else` | 分支走错 | 所有分支加花括号 |
| `switch` 漏 `break` | 意外贯穿 | 补 `break` 或注释 `/* fallthrough */` |
| 循环边界 `<=` | 多执行一次或越界 | 明确区间是左闭右开还是闭区间 |
| `for` 里改循环变量 | 迭代次数失控 | 循环变量只在步进处修改 |
| `do-while` 漏分号 | 后续语法错误 | 补 `while (...);` |
| 浮点做循环条件 | 精度误差导致少跑或多跑 | 用整数计数 |

⚠ **关键认知**：`if (x = 0)` 这类错误在 `-Wall` 下会报 `suggest parentheses around assignment used as truth value`。让编译器保持高警告级别，比事后调试便宜得多。

# 6. 动手练习

1. 用 `switch` 实现一个四则运算器，处理除数为 0 的情况，并故意去掉一个 `break` 观察贯穿。
2. 用 `while` 和 `do-while` 各写一个"输入非法就重试"的循环，比较两者在首次输入就合法时的行为差异。
3. 把一段嵌套两层、用 `break` 跳出内层的代码改成用 `goto cleanup` 统一退出，体会可读性变化。

# 7. 小结

| 结构 | 要点 |
|------|------|
| `if` | 非零即真，始终加花括号避免悬空 `else` |
| `switch` | 只接受整数，注意 `break` 与有意贯穿 |
| `for` | 计数循环，初始化、条件、步进三要素 |
| `while` | 条件循环，循环体要推动条件变化 |
| `do-while` | 至少执行一次，结尾必须有分号 |
| `break` / `continue` | 只影响最内层循环 |
| `goto` | 仅推荐用于统一错误清理 |
