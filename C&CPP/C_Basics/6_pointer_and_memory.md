指针是 C 的灵魂，也是初学者最容易卡住的地方。它的本质只是一个存地址的整数，但围绕它衍生出数组退化、指针运算、函数指针、`const` 修饰和空指针、野指针等一整套规则。本篇从地址与解引用讲起，把指针的常见形态和陷阱逐一拆开。

# 1. 指针基础

## 1.1 地址与解引用

指针变量存放的是另一个对象的**内存地址**：

```c
#include <stdio.h>

int main(void) {
    int x = 42;
    int *p = &x;      // p 保存 x 的地址

    printf("%p\n", (void *)p); // 打印地址
    printf("%d\n", *p);        // 42，解引用读取 x
    *p = 100;                  // 通过指针修改 x
    printf("%d\n", x);         // 100
    return 0;
}
```

| 运算符 | 名称 | 作用 |
|--------|------|------|
| `&` | 取地址 | 得到对象的地址 |
| `*` | 解引用 | 访问指针指向的对象 |

★ **关键认知**：指针的类型决定了**解引用时读多少字节**，以及**指针加一时前进多少字节**。`int *` 一次读 4 字节，`char *` 一次读 1 字节，这就是类型不能随便乱转的根本原因。

## 1.2 指针运算

指针加减的是**元素个数**，不是字节数：

```c
int a[5] = {10, 20, 30, 40, 50};
int *p = a;

printf("%d\n", *p);       // 10
printf("%d\n", *(p + 2)); // 30
printf("%d\n", p[2]);     // 30，等价写法
```

```text
a:  [10] [20] [30] [40] [50]
      ▲    ▲    ▲
      p   p+1  p+2
地址: 100  104  108   （假设 int 为 4 字节）
```

指针相减得到的是**元素个数**：

```c
int *end = a + 5;
printf("%td\n", end - a); // 5，不是 20
```

⚠ **关键认知**：只有当两个指针指向**同一个数组**（或数组末尾后一位）时，相减才有定义。跨数组相减是未定义行为。

## 1.3 数组退化

数组名在多数表达式里退化为首元素指针，因此 `a[i]` 等价于 `*(a + i)`：

```c
int a[5];
// 下面四种写法完全等价
a[2] = 1;
*(a + 2) = 1;
*(2 + a) = 1;
2[a] = 1;      // 合法但不要这么写
```

★ **关键认知**：数组退化是"传参时长度丢失"的根源。函数参数写 `int arr[]` 或 `int *arr` 完全等价，`sizeof(arr)` 都是指针大小。想要长度，只能额外传一个参数。

# 2. 指针与函数

## 2.1 函数指针

函数名在表达式里退化为函数地址，可以存入函数指针：

```c
#include <stdio.h>

int add(int a, int b) { return a + b; }
int sub(int a, int b) { return a - b; }

int main(void) {
    int (*op)(int, int) = add;   // 声明函数指针并初始化

    printf("%d\n", op(3, 4));     // 7
    op = sub;
    printf("%d\n", op(3, 4));     // -1
    return 0;
}
```

函数指针的声明语法容易读错，记住结构：

```text
int (*op)(int, int);
 │   │  │
 │   │  └── 参数列表
 │   └───── 指针名，必须加括号
 └───────── 返回类型
```

## 2.2 回调

函数指针最常见的用途是把行为作为参数传入：

```c
#include <stdio.h>

void apply(int *arr, int n, int (*fn)(int)) {
    for (int i = 0; i < n; ++i) {
        arr[i] = fn(arr[i]);
    }
}

int square(int x) { return x * x; }

int main(void) {
    int a[3] = {1, 2, 3};
    apply(a, 3, square);
    for (int i = 0; i < 3; ++i) {
        printf("%d ", a[i]); // 1 4 9
    }
    return 0;
}
```

★ **关键认知**：函数指针是 C 实现**多态与回调**的核心机制。标准库的 `qsort` 就是典型例子：排序算法固定，比较逻辑由调用方通过函数指针注入。

## 2.3 typedef 简化

```c
typedef int (*binop)(int, int);

binop op = add;   // 比原始写法清晰得多
```

⚠ **关键认知**：`typedef` 定义的是**类型别名**，不是新类型。`binop` 与 `int (*)(int, int)` 完全等价。

# 3. const 与指针

`const` 与指针结合有四种组合，区别在于"指针本身能不能改"和"指向的内容能不能改"：

| 写法 | 指针可变 | 内容可变 | 记忆方法 |
|------|----------|----------|----------|
| `int *p` | 是 | 是 | 无 `const` |
| `const int *p` | 是 | 否 | 指向常量 |
| `int *const p` | 否 | 是 | 指针是常量 |
| `const int *const p` | 否 | 否 | 都不可变 |

```c
int x = 1;
int y = 2;

const int *p1 = &x;
// *p1 = 3;   // 错误：内容不可改
p1 = &y;      // 正确：指针可改

int *const p2 = &x;
*p2 = 3;      // 正确：内容可改
// p2 = &y;   // 错误：指针不可改
```

★ **关键认知**：读声明时从**右往左**读。`const int *p` 读作"p 是一个指针，指向 const int"；`int *const p` 读作"p 是一个 const 指针，指向 int"。这样就不会记混。

⚠ **关键认知**：函数参数用 `const char *` 表示"我不会修改你传进来的字符串"，这是接口契约的一部分，也能让调用方放心传入字符串字面量。

# 4. 空指针与野指针

## 4.1 空指针

空指针表示"不指向任何对象"：

```c
int *p = NULL;   // 推荐写法，NULL 定义在 <stddef.h>
if (p != NULL) {
    *p = 1;      // 使用前必须检查
}
```

★ **关键认知**：`NULL` 在 C 里通常展开为 `((void *)0)` 或 `0`。空指针**可以比较、可以赋值**，但**解引用一定崩溃**。所有可能为空的指针，使用前都要判断。

## 4.2 野指针

野指针指"指向未知或已释放内存"的指针，比空指针危险得多：

```c
int *p;          // 未初始化，值随机 —— 野指针
*p = 1;          // 未定义行为

int *q = malloc(sizeof(int));
free(q);
*q = 1;          // 悬空指针：内存已释放
```

防范手段：

| 手段 | 做法 |
|------|------|
| 初始化 | 定义时立即赋 `NULL` 或有效地址 |
| 释放后置空 | `free(p); p = NULL;` |
| 使用前检查 | `if (p != NULL)` |
| 不返回局部地址 | 用 `static`、堆内存或调用方缓冲区 |
| 打开警告 | `-Wall -Wextra` 捕捉未初始化使用 |

⚠ **关键认知**：`free(p)` 只释放内存，**不会把 p 变成 NULL**。释放后继续使用 `p` 就是悬空指针，很多"随机崩溃"都源于此。

# 5. 多级指针

指向指针的指针，常见于"函数内修改指针本身"：

```c
#include <stdlib.h>

void allocate(int **p, int n) {
    *p = malloc(n * sizeof(int)); // 修改调用方的指针
}

int main(void) {
    int *arr = NULL;
    allocate(&arr, 10);
    free(arr);
    return 0;
}
```

```text
arr ──► [指针] ──► [堆上的 int 数组]
          ▲
          └── p 指向 arr
```

★ **关键认知**：需要函数**改变指针指向**时，传二级指针；只需要改变指针**指向的内容**时，传一级指针就够了。多一级就多一层间接，不要滥用。

# 6. 常见错误

| 错误 | 表现 | 修复 |
|------|------|------|
| 解引用空指针 | 段错误 | 使用前判空 |
| 使用未初始化指针 | 随机崩溃 | 定义时初始化 |
| 释放后继续使用 | 悬空指针 | `free` 后置 `NULL` |
| 返回局部变量地址 | 悬空指针 | 改静态或堆内存 |
| 指针类型不匹配 | 读到错误字节数 | 保持类型一致或显式转换 |
| 忘记 `*` 的括号 | 声明成返回指针的函数 | `int (*f)(int)` |
| 跨数组指针相减 | 未定义行为 | 只在同一数组内运算 |

⚠ **关键认知**：指针错误往往**不在出错的那一行暴露**，而是写坏内存后在别处崩溃。排查时优先用 AddressSanitizer，它能在越界或释放后使用的当下报错，并给出调用栈。

# 8. 小结

| 概念 | 要点 |
|------|------|
| 指针 | 存地址，类型决定解引用宽度与步长 |
| 指针运算 | 加减元素个数，只在同一数组内有定义 |
| 数组退化 | 传参丢失长度，需额外传大小 |
| 函数指针 | 声明注意括号，用于回调与多态 |
| `const` | 从右往左读，区分指针与内容 |
| 空指针 | 可比较、可赋值，解引用必崩 |
| 野指针 | 未初始化或已释放，必须初始化并置空 |
