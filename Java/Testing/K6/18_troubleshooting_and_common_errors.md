# 1. 故障排查思路

## 1.1 先区分客户端与服务端问题
- 客户端瓶颈会导致吞吐下降但服务端指标正常
- 服务端瓶颈通常伴随延迟上升与错误率升高

## 1.2 结合指标定位
- `http_req_blocked` 与 `http_req_connecting` 用于判断连接问题
- `http_req_waiting` 反映服务端处理耗时

# 2. 常见错误与处理

## 2.1 连接超时
- 可能是网络问题或服务端负载过高
- 适当调整 timeout，检查网络路径

## 2.2 TLS 握手失败
- 证书链不完整或版本不兼容
- 检查证书与协议版本配置

## 2.3 429/503 大量出现
- 可能触发限流或服务降级
- 需要与业务侧确认限流策略

# 3. 脚本问题

## 3.1 语法错误
- 运行前进行 lint 或简单执行验证

## 3.2 逻辑错误
- 业务路径不完整导致失败率异常
- 需要对关键步骤加检查

# 4. 环境问题

## 4.1 DNS 解析异常
- DNS 抖动会显著影响延迟

## 4.2 代理与防火墙
- 代理配置错误会导致请求失败

# 5. 排查清单

## 5.1 快速检查项
- 脚本版本与配置是否正确
- 目标服务是否可访问
- 客户端资源是否充足
