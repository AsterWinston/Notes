# 1. 源码与架构概览

## 1.1 核心模块
- JS 运行时：负责执行脚本逻辑
- 调度器：管理 VU 生命周期
- 指标系统：采集与聚合指标

## 1.2 执行流程
- init 阶段加载脚本
- setup 阶段执行一次
- VU 循环执行 `default`
- teardown 收尾

# 2. 指标管线

## 2.1 采集
- 每次请求都会生成指标数据

## 2.2 聚合
- 指标按标签与分组聚合
- Trend 计算分位数

# 3. 执行器实现思路

## 3.1 闭合模型执行器
- 重点是维持固定 VU 数

## 3.2 开放模型执行器
- 重点是按到达率驱动请求

# 4. 扩展点

## 4.1 输出扩展
- 指标输出由独立模块处理

## 4.2 协议扩展
- 可通过 xk6 扩展新协议

# 5. 阅读源码的建议

## 5.1 关注关键路径
- 调度器、指标管线、HTTP 客户端
