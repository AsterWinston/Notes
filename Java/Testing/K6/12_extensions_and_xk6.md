# 1. 扩展机制概览

## 1.1 为什么需要扩展
- 内置能力不足以满足特定协议或输出需求
- 通过扩展增强功能而不修改核心代码

## 1.2 扩展类型
- 输出扩展（如自定义指标输出）
- 协议扩展（如非 HTTP 协议）
- 自定义逻辑扩展

# 2. xk6 的作用

## 2.1 xk6 构建方式
xk6 用于将扩展与 k6 编译为一个可执行文件：

```bash
xk6 build --with github.com/xxx/xk6-ext@v0.1.0
```

## 2.2 版本与兼容性
- 扩展版本需与 k6 版本匹配
- 编译后需在目标环境验证

# 3. 扩展使用策略

## 3.1 选型原则
- 优先选用活跃维护的扩展
- 关注许可证与安全风险

## 3.2 生产使用建议
- 构建可复现的二进制
- 保持扩展清单与版本记录

# 4. 常见问题

## 4.1 编译失败
- Go 环境缺失或版本不匹配

## 4.2 运行时崩溃
- 扩展不兼容导致运行时异常
