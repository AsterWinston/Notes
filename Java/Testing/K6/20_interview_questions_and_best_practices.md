# 2. 常见面试题

## 2.1 k6 与 JMeter 的区别
- k6 更适合工程化与自动化
- JMeter 适合 GUI 与录制场景

## 2.2 什么是 VU 与迭代
- VU 是并发执行单元
- 迭代是 VU 执行 `default` 的一次完整流程

## 2.3 如何设置阈值
- 根据历史基线与业务 SLO
- 关键路径应更严格

## 2.4 如何判断瓶颈
- 看延迟、吞吐、错误率的变化趋势
- 结合服务端与客户端指标

# 3. 常见误区

## 3.1 只看平均值
- 平均值无法反映尾部延迟

## 3.2 不区分业务失败与系统失败
- 业务失败要用 check 统计
