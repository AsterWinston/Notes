# 1. 最佳实践

## 1.1 测试命名规范

- `should_xxx_when_yyy`
- 使用 `@DisplayName` 提升可读性

## 1.2 AAA 结构

- Arrange
- Act
- Assert

## 1.3 保持测试独立

- 不依赖执行顺序
- 避免共享可变状态

# 2. 常见陷阱

## 2.1 Flaky Test

- 时间、随机数、外部依赖不稳定
- 解决：隔离依赖、固定随机种子、重试策略（谨慎）

## 2.2 过度 Mock

- 过度 Mock 导致测试锁定实现细节
- 应优先验证业务行为

## 2.3 大而慢的测试

- 使用 Slice 测试或拆分测试类
- 减少不必要的 Spring 启动

# 3. 面试高频问题

## 3.1 JUnit 4 与 JUnit 5 区别

- 架构：Runner vs Platform/Engine
- 扩展：Rule vs Extension
- 标签：Category vs Tag

## 3.2 单元测试与集成测试的边界

- 单测重隔离、快、稳定
- 集成测重协作、真实依赖

## 3.3 如何提高测试稳定性

- 控制外部依赖
- 避免并发冲突
- 使用 Testcontainers 或 Mock

# 4. 质量与维护策略

## 4.1 评估测试价值

- 是否覆盖高风险逻辑
- 是否易读、易维护

## 4.2 持续改进

- 定期清理失效测试
- 用缺陷驱动补充测试
