
# 1. Vim 简介

Vim（Vi IMproved）是 Linux 上最经典的文本编辑器，由 Bram Moolenaar 在 Vi 基础上发展而来。学习 Vim 是 Linux 使用者的必修课。

**核心理念**：模式编辑 —— 不同的模式对应不同的按键行为，大幅提高编辑效率。

# 2. Vim 的四种模式

```
正常模式（Normal）   ← 默认模式，用于导航和操作
    ↕ i / a / o     → 进入插入模式
    ↕ v / V / Ctrl+v → 进入可视模式
    ↕ :              → 进入命令行模式
    ↕ 其他键          → 执行编辑命令
```

| 模式 | 用途 | 如何进入 |
|------|------|----------|
| 正常模式 | 导航、复制、粘贴、删除、撤销 | 默认，或按 `Esc` |
| 插入模式 | 输入文本 | `i`（光标前）、`a`（光标后）、`I`（行首）、`A`（行尾）、`o`（下行）、`O`（上行） |
| 可视模式 | 选中文本 | `v`（字符）、`V`（行）、`Ctrl+v`（块） |
| 命令行模式 | 保存、退出、搜索、替换、设置 | `:`、`/`、`?` |

# 3. 启动与退出

```bash
vim file.txt          # 打开文件
vim +10 file.txt      # 打开并定位到第10行
vim +/pattern file    # 打开并定位到第一个匹配 pattern 的行
vim -R file.txt       # 只读模式打开（等价于 view file.txt）
vimdiff file1 file2   # 比较两个文件
```

**退出方式**（命令行模式）：

| 命令 | 作用 |
|------|------|
| `:q` | 退出（未修改时） |
| `:q!` | 强制退出（放弃修改） |
| `:w` | 保存 |
| `:w!` | 强制保存（只读文件需加 !） |
| `:wq` 或 `:x` | 保存并退出 |
| `ZZ` | 保存并退出（正常模式） |
| `ZQ` | 不保存退出 |

# 5. 编辑操作

## 5.1 插入文本

| 按键 | 作用 |
|------|------|
| `i` | 光标前插入 |
| `a` | 光标后插入 |
| `I` | 行首插入 |
| `A` | 行尾插入 |
| `o` | 下方新行插入 |
| `O` | 上方新行插入 |
| `s` | 删除光标字符并插入 |
| `S` | 删除整行并插入 |
| `r` | 替换单个字符 |
| `R` | 进入替换模式 |

## 5.2 删除

| 按键 | 作用 |
|------|------|
| `x` | 删除光标处字符 |
| `X` | 删除光标前字符 |
| `dd` | 删除当前行 |
| `3dd` | 删除3行 |
| `dw` | 删除一个单词 |
| `d0` | 删到行首 |
| `d$` | 删到行尾 |
| `dG` | 删到文件末尾 |
| `dgg` | 删到文件开头 |
| `D` | 等价于 d$ |
| `:3,5d` | 删除第3-5行 |
| `:.,$d` | 删除当前行到末尾 |

## 5.3 复制与粘贴

| 按键 | 作用 |
|------|------|
| `yy` | 复制当前行 |
| `3yy` | 复制3行 |
| `yw` | 复制一个单词 |
| `y0` | 复制到行首 |
| `y$` | 复制到行尾 |
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |

## 5.4 撤销与重做

| 按键 | 作用 |
|------|------|
| `u` | 撤销 |
| `Ctrl+r` | 重做 |
| `U` | 撤销对当前行的所有修改 |

## 5.5 缩进

| 按键 | 作用 |
|------|------|
| `>>` | 向右缩进 |
| `<<` | 向左缩进 |
| `==` | 自动缩进当前行 |
| `gg=G` | 自动缩进整个文件 |

## 5.6 重复命令

`.` 重复上一次修改，是 Vim 中最强大的快捷键之一：

```vim
dd     " 删除一行
.      " 再删除一行
.      " 再删除一行
```

`;` 和 `,` 重复上一次 f/t 查找。

# 6. 搜索与替换

## 6.1 搜索

```vim
/pattern       " 向下搜索
?pattern       " 向上搜索
n              " 下一个匹配
N              " 上一个匹配
*              " 搜索光标处的单词（向下）
#              " 搜索光标处的单词（向上）
```

搜索设置：
```vim
:set hlsearch     " 高亮匹配
:set nohlsearch   " 取消高亮
:nohlsearch       " 临时取消当前高亮（简写 :noh）
:set incsearch    " 增量搜索（边输入边匹配）
:set ignorecase   " 忽略大小写
:set smartcase    " 输入大写时区分大小写
```

## 6.2 替换

```vim
:s/old/new                    " 替换当前行第一个匹配
:s/old/new/g                  " 替换当前行所有匹配
:%s/old/new/g                 " 替换整个文件所有匹配
:%s/old/new/gc                " 替换并逐个确认
:3,10s/old/new/g              " 替换第3-10行
:.,$s/old/new/g               " 替换当前行到末尾
:%s/old/new/gi                " 忽略大小写替换
:%s/\<old\>/new/g             " 全词匹配替换
:%s/old/new/gI                " 询问确认（I 代替 c，反向确认）
```

# 7. 多文件操作

## 7.1 多窗口

```vim
:split file2.txt              " 水平分割窗口（简写 :sp）
:vsplit file2.txt             " 垂直分割窗口（简写 :vsp）

:new                          " 水平分割并新建文件
:vnew                         " 垂直分割并新建文件

Ctrl+w w                      " 切换窗口
Ctrl+w h/j/k/l                " 向方向切换窗口
Ctrl+w =                      " 等分窗口大小
Ctrl+w _                      " 最大化当前窗口高度
Ctrl+w |                      " 最大化当前窗口宽度
:q                            " 关闭当前窗口
:only                         " 关闭其他所有窗口
```

## 7.2 标签页

```vim
:tabnew file.txt              " 在新标签页打开
:tabedit file.txt             " 同上
:tabclose                     " 关闭当前标签页
:tabnext / gt                 " 下一个标签页
:tabprev / gT                 " 上一个标签页
:tabmove 3                    " 移到第3个位置
:tabs                         " 列出所有标签页
```

# 8. 配置文件（.vimrc）

Vim 的行为通过 `~/.vimrc` 配置：

```vim
" 基础设置
set nocompatible              " 不兼容 Vi
set number                    " 显示行号
set relativenumber            " 相对行号
syntax on                     " 语法高亮
set showmode                  " 显示模式
set showcmd                   " 显示命令

" 缩进
set tabstop=4                 " Tab 宽度为4空格
set shiftwidth=4              " 缩进宽度
set softtabstop=4             " 按退格时等效空格数
set expandtab                 " Tab 转换为空格
set autoindent                " 自动缩进
set smartindent               " 智能缩进

" 搜索
set hlsearch                  " 高亮搜索
set incsearch                 " 增量搜索
set ignorecase                " 忽略大小写
set smartcase                 " 大小写智能

" 编辑体验
set cursorline                " 高亮当前行
set wildmenu                  " 命令行补全菜单
set showmatch                 " 高亮匹配括号
set scrolloff=5               " 滚动时保留上下5行
set backspace=indent,eol,start " 允许退格删除

" 文件编码
set encoding=utf-8
set fileencodings=utf-8,gbk,gb2312

" 主题
colorscheme desert
```

# 9. 实用技巧

## 9.1 块的批量操作（Ctrl+v）

```
步骤：
1. 按 Ctrl+v 进入可视块模式
2. 移动光标选中多行首列
3. 按 I 进入插入模式
4. 输入内容（如 # 或 //）
5. 按 Esc 退出 → 所有选中行同时生效
```

## 9.2 宏录制

```vim
qa                  " 开始录制宏到寄存器 a
(执行一系列操作)
q                   " 停止录制
@a                  " 在当前行执行宏 a
@@                  " 重复上一次宏
10@a                " 执行10次宏
:.'$/norm @a        " 在当前行到末尾的每行执行宏
```

## 9.3 寄存器

```vim
"ayy               " 复制到寄存器 a
"ap                " 从寄存器 a 粘贴
:reg               " 查看所有寄存器内容
"+y                " 复制到系统剪贴板
"+p                " 从系统剪贴板粘贴
"*y                " 复制到选择剪贴板（X11）
```

## 9.4 补全

```vim
Ctrl+n / Ctrl+p    " 普通补全（根据当前文件）
Ctrl+x Ctrl+f      " 文件名补全
Ctrl+x Ctrl+o      " Omni-completion（需要语言支持）
```
