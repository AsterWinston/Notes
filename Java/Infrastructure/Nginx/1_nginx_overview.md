
> 版本说明：本文档基于 **Nginx 1.24.x / 1.26.x**（Stable/Mainline），操作系统以 Linux（CentOS 7+/Ubuntu 20.04+）为主。

---

# 1. 什么是 Nginx

- **Nginx**（engine x）是一款高性能的 **HTTP 服务器** 和 **反向代理服务器**，同时支持 **IMAP/POP3/SMTP 邮件代理**。
- 由俄罗斯程序员 **Igor Sysoev** 于 2004 年发布，采用 **事件驱动（Event-Driven）** 架构，专门为解决 **C10K 问题**（单机万级并发连接）而设计。

| 特性 | 说明 |
|------|------|
| 高性能 | 单机可支撑数万甚至十万级并发连接 |
| 低内存消耗 | 基于异步非阻塞模型，内存占用远低于传统多进程模型 |
| 热部署 | 支持平滑升级、不停机修改配置 |
| 模块化 | 核心精简，功能通过模块扩展（官方/第三方） |
| 生态丰富 | OpenResty、Tengine、Kong 等二次开发版本 |

# 2. Nginx 主要应用场景

| 场景 | 说明 |
|------|------|
| **静态资源服务器** | 高效处理 HTML、CSS、JS、图片、视频等静态文件 |
| **反向代理** | 隐藏后端服务器，统一入口，分发请求 |
| **负载均衡** | 将请求分发到多台后端服务器，提高可用性 |
| **SSL 终结** | HTTPS 证书集中管理，后端 HTTP 通信 |
| **HTTP 缓存** | 缓存后端响应，加速访问 |
| **API 网关** | 鉴权、限流、日志、协议转换 |
| **四层代理** | TCP/UDP 流转发（Stream 模块） |
| **WebSocket 代理** | WebSocket 反向代理与负载均衡 |

# 3. Nginx vs Apache vs Tomcat

| 对比维度 | Nginx | Apache | Tomcat |
|----------|-------|--------|--------|
| 定位 | HTTP 服务器 + 反向代理 | HTTP 服务器 | Servlet 容器 / Java 应用服务器 |
| 并发模型 | 异步非阻塞、事件驱动 | 同步多进程 / 多线程（prefork/worker/event） | 多线程（基于 Java NIO/BIO） |
| 静态资源 | 高性能，首选 | 较好，但不如 Nginx | 弱，不建议直接暴露 |
| 动态内容 | 反向代理到后端 | 通过模块（mod_php 等） | 原生支持 Servlet/JSP |
| 内存消耗 | 低且稳定 | 较高，并发增加时明显增长 | 较高（JVM 内存） |
| 配置灵活性 | 简洁直观 | 丰富（.htaccess 等） | 中等 |
| 热部署 | 支持平滑重载 | 需重启 | 通常需重新部署 |

> **典型架构**：`Nginx（前端）→ Tomcat / Spring Boot / Go / Node.js（后端应用）`

# 4. Nginx 发展历史与生态

| 版本线 | 说明 |
|--------|------|
| **Nginx Open Source** | 开源社区版，官方维护（Stable/Mainline） |
| **Nginx Plus** | 商业版，提供高级负载均衡、主动健康检查、Dashboard 等 |
| **OpenResty** | 基于 Nginx + LuaJIT 的 Web 平台，国内广泛使用（章亦春开发） |
| **Tengine** | 阿里巴巴开源的 Nginx 分支，增加动态模块加载等特性 |
| **Kong / APISIX** | 基于 OpenResty 的 API 网关 |

# 5. 版本选择建议

| 版本类型 | 特点 | 适用场景 |
|----------|------|----------|
| **Mainline**（主线版） | 奇数版本号（如 1.25.x），功能最新，迭代快 | 追求新特性，非关键环境 |
| **Stable**（稳定版） | 偶数版本号（如 1.24.x），只修复 Bug，长期维护 | 生产环境推荐 |

> 生产环境 **推荐使用 Stable 版本**。国内也可考虑 OpenResty 或 Tengine。
