
# 1. 概述

Sentinel 是阿里巴巴开源的一款**面向分布式服务架构的流量防护组件**，以流量为切入点，从**流量控制、熔断降级、系统自适应保护**等多个维度保障微服务的稳定性。

Sentinel 于 2018 年开源，2020 年发布 1.8.0 GA 版本，目前是 Spring Cloud Alibaba 生态中流量防护的默认选择。

核心能力矩阵：

| 能力 | 说明 | 典型场景 |
|------|------|---------|
| **流量控制** | QPS/并发线程数限流，支持 WarmUp、匀速排队 | 秒杀防刷、API 配额 |
| **熔断降级** | 慢调用比例/异常比例/异常数触发熔断 | 下游服务故障隔离 |
| **系统保护** | Load/CPU/RT/线程数/QPS 自适应 | 防止系统雪崩 |
| **热点保护** | 针对热点参数（如商品ID）精细化限流 | 热门商品防刷 |
| **授权控制** | 黑白名单，来源应用控制 | 服务调用方鉴权 |

# 2. 为什么要用 Sentinel

## 2.1 微服务架构的稳定性挑战

在分布式系统中，某个服务的延迟增加或不可用可能沿调用链向上传导，最终导致**雪崩效应**：

```
服务 A → 服务 B → 服务 C（慢/故障）
   ↑         ↑
   └─ 线程堆积 ── 线程耗尽 ── 整体不可用
```

Sentinel 通过多维度的流量防护来应对：

- **流量整形**：将突发流量平滑为均匀请求，避免后端过载
- **熔断降级**：快速失败不可用的下游，释放线程资源
- **系统保护**：监控整体负载，在系统崩溃前主动限流

## 2.2 Sentinel vs Hystrix vs Resilience4j

| 维度 | Sentinel | Hystrix | Resilience4j |
|------|----------|---------|-------------|
| **维护状态** | ✓ 活跃 | ✗ 停止维护 | ✓ 活跃 |
| **限流** | 丰富（QPS/线程/WarmUp/匀速排队） | 线程池/信号量隔离 | 信号量隔离 |
| **熔断** | 慢调用/异常比例/异常数 | 异常比例 | 异常比例/慢调用 |
| **系统保护** | ✓ 自适应 | ✗ | ✗ |
| **热点参数** | ✓ | ✗ | ✗ |
| **控制台** | ✓ 可视化管理 | ✓ Dashboard | ✗ 无官方 |
| **规则推送** | 拉/推模式，多数据源 | 配置管理 | 代码定义 |
| **性能** | 高（滑动窗口 + 内存计算） | 中（线程池开销大） | 较高 |

**结论**：Sentinel 在规则丰富度、可视化管理、性能表现上均优于 Hystrix，是 Spring Cloud Alibaba 体系的推荐选择。

# 3. 核心设计理念

1. **Resource（资源）**：Sentinel 中一切需要保护的代码点。通过 API 或注解声明，构成防护的最小单元。

2. **SlotChain（责任链）**：围绕资源构建的 ProcessorSlot 链，每个 Slot 负责一类检查（流量控制/熔断降级/系统保护/统计），链式执行。

3. **滑动窗口统计**：基于 LeapArray 的高效统计引擎，以固定时间窗口采集 RT、QPS、异常数等指标，支持秒级精度实时计算。

4. **规则即配置**：所有防护策略通过 Rule 对象表达，支持动态推送，无需重启。

5. **流量效果多样化**：不仅支持快速失败，还支持 WarmUp（预热）、RateLimiter（匀速排队）等高级控制。

# 4. 一句话架构

```
                 ┌──────────────────────┐
                 │   Sentinel Dashboard  │  ← 规则管理 & 监控可视化
                 └──────────┬───────────┘
                            │ 规则推送 / 拉取
       ┌────────────────────┼────────────────────┐
       ▼                    ▼                    ▼
 ┌──────────┐       ┌──────────────┐      ┌──────────┐
 │ 服务 A    │       │   服务 B      │      │ 服务 C    │
 │ Sentinel │       │   Sentinel   │      │ Sentinel │
 │ Client   │       │   Client     │      │ Client   │
 └──────────┘       └──────────────┘      └──────────┘
```

每个服务内嵌 Sentinel Client，通过 SlotChain 机制在本地执行规则判断。Dashboard 提供集中规则管理和监控能力。
