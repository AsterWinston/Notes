
# 1. 概述

Apache SkyWalking 是一款**开源的应用性能管理（APM）系统**，提供分布式追踪、服务网格遥测分析、度量聚合和可视化一体化能力。2019 年从 Apache 孵化器毕业成为顶级项目。

# 2. APM 三大支柱

| 支柱 | 说明 | SkyWalking 实现 |
|------|------|----------------|
| **Tracing**（追踪） | 记录请求在分布式系统中的完整调用链路 | Java Agent 自动埋点，Trace/Span/Segment 模型 |
| **Metrics**（指标） | 聚合统计系统的运行指标（QPS/RT/错误率） | OAL 引擎定义指标，OAP 聚合计算 |
| **Logging**（日志） | 关联日志与追踪上下文 | TraceId 注入 MDC，日志与 Trace 联动 |

**一体化优势**：Tracing + Metrics + Logging 在同一个平台内关联，无需跨系统切换。

# 3. SkyWalking vs 其他 APM

| 维度 | SkyWalking | Jaeger | Zipkin | Pinpoint |
|------|-----------|--------|--------|----------|
| **Apache 顶级项目** | ✓ | ✗（CNCF） | ✗ | ✗ |
| **自动埋点** | ✓ Java/.NET/Go/Python... | 有限 | 有限 | ✓ Java（强）|
| **Metrics 聚合** | ✓ 内置 OAL | ✗ 需外接 | ✗ | ✓ |
| **存储后端** | ES/MySQL/H2/BanyanDB | ES/Cassandra/memory | ES/MySQL/Cassandra | HBase |
| **代码级诊断** | ✓（Profiling） | ✗ | ✗ | ✓（强，代码级） |
| **告警** | ✓ 内置 DSL | ✗ | ✗ | ✓ |
| **性能开销** | 低（~3-8%） | 低 | 中 | 中 |

# 4. 核心能力

| 能力 | 说明 |
|------|------|
| **全链路追踪** | 跨服务、跨进程的调用链追踪 |
| **服务拓扑** | 自动生成服务依赖关系拓扑图 |
| **性能剖析** | CPU/内存/线程栈的连续剖析 |
| **服务网格** | Istio Envoy ALS 协议集成 |
| **告警** | 基于 OAL 指标的 Webhook/gRPC/钉钉/微信告警 |
| **日志关联** | TraceId 自动注入日志，一站式关联查询 |
| **eBPF 集成** | 内核级网络和性能监控 |

# 6. 核心设计理念

1. **Agent 零侵入**：Java Agent 字节码增强，无需修改业务代码
2. **OAL 可编程**：观测分析语言（Observability Analysis Language）自定义指标
3. **插件化架构**：所有功能通过插件扩展，Agent 和 OAP 两层的插件体系
4. **流式处理**：OAP 接收数据后流式聚合，支持水平扩展
5. **多协议支持**：兼容 Zipkin/Jaeger 数据格式，降低迁移成本
