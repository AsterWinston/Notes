
# 1. 概述

Kibana Machine Learning 基于 ES 的 ML 引擎，提供**异常检测、分类和回归**能力，无需编写代码。

```
ML 工作流:
  1. 选择索引/Data View
  2. 选择 ML Job 类型
  3. 配置 Detector（检测器）
  4. 运行 Datafeed 输入数据
  5. 查看 Anomaly Explorer 结果
  6. 设置告警
```

# 2. Job 类型

| Job | 说明 | 适用场景 |
|-----|------|---------|
| **Single Metric** | 单指标异常检测 | CPU 异常、QPS 异常 |
| **Multi Metric** | 多指标联合分析 | CPU + Memory + Disk |
| **Population** | 群体行为异常 | 某台服务器行为异常 |
| **Categorization** | 非结构化日志分类 | 错误日志自动归类 |

## 2.1 Single Metric Job

```
ML → Create job → Single metric
  Index: metricbeat-*
  Time field: @timestamp
  Detector: high_mean(system.cpu.user.pct)
  Bucket span: 15m

结果: 按 15 分钟窗口统计 CPU 均值，检测超出正常范围的窗口
  
Anomaly Score:
  0-25: 正常
  25-50: 轻微异常
  50-75: 中度异常
  75-100: 严重异常
```

## 2.2 Categorization Job

```
ML → Create job → Categorization

Index: logs-*
Detector: Count → By → mlcategory
Categorization field: message

效果: 自动将相似的日志消息归类
  - Category 1: "Connection refused to {host}:{port}" (150次)
  - Category 2: "OOM killer killed process {pid}" (3次)
  - Category 3: "Disk usage exceeded {percent}%" (1次)
```

# 3. Anomaly Explorer

```
ML → Anomaly Explorer
  ├── 时间线: 异常分数随时间变化
  ├── 异常列表: 按严重程度排序
  ├── 详细视图: 选定异常的上下文数据分析
  └── Forecast: 基于历史数据预测未来值
```

# 4. Data Visualizer

```
ML → Data Visualizer
  ├── 选择索引 → 分析字段分布
  ├── 数值字段: min/max/avg/percentiles 分布
  ├── 关键字字段: Top values + 占比
  └── 建议: 哪些字段适合做 ML Job 的 Detector
```

# 5. ML 告警

```
创建 ML 规则:
Rule → Create rule → Machine Learning
  Job: cpu_anomaly
  Anomaly Score: > 75
  Check every: 15m

Action:
  Connector: Slack
  Message: "CPU anomaly detected: score={{context.anomalyScore}}"
```

# 6. Inference 推断

ML 模型可用于 Ingest Pipeline 中做实时推断：

```json
PUT /_ingest/pipeline/ml_inference
{
  "processors": [
    {
      "inference": {
        "model_id": "my-model",
        "target_field": "ml_result",
        "field_map": { "message": "text_field" }
      }
    }
  ]
}
```
