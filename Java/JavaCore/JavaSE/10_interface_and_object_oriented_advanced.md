# 1.static

## 1.1static修饰成员变量

```
1.1.1static修饰的成员变量称为静态成员变量（这种变量在不存在类对象时就加载了）
1.1.2static修饰的变量可以直接用类名访问（当然，使用特定的类对象也可以调用，推荐使用类名调用）
1.1.3所有类对象共享（放在静态区，jdk8以前在方法区，jdk8以后在堆内存）
```

## 1.2static修饰成员函数

### 1.2.1static修饰的方法叫静态方法

```
static修饰的方法叫静态方法
```

### 1.2.2工具类

```
1.2.2.1类名见名知意
1.2.2.2私有化构造方法:为了禁止类外创建类对象，而仅仅能在本类内创建
1.2.2.3方法定义为静态:为了可以通过类名调用方法
```

### 1.2.3静态方法只能访问静态变量和静态方法（以及构造方法），非静态方法可以访问静态变量或者静态方法，也可以访问非静态的成员变量和非静态的成员方法，静态方法中没有this关键字

# 2.继承

## 2.1子类（派生类）和父类（基类或超类）

```
子类（派生类）和父类（基类或超类）
```

## 2.2extends关键字

```
<authority> class <class_name1> extends <class_name2>{<class_def>}//class1继承class2
```

## 2.3继承内容

### 2.3.1构造方法

```
2.3.1.1public:不能继承，可以调用
2.3.1.2protected:不能继承，可以调用（仅限同包或子类）
2.3.1.3缺省:不能继承，可以调用（仅限同包）
2.3.1.4private:不能继承，不能调用
```

### 2.3.2成员变量

```
2.3.2.1public:能，可以直接访问到
2.3.2.2protected:能，可以直接访问到（仅限同包或子类）
2.3.2.3缺省:能，可以直接访问到（仅限同包）
2.3.2.4private:能，但是不能直接访问到（被隐藏）
```

### 2.3.3成员方法:同成员变量，唯一的不同在于，private修饰成员方法，该成员方法不会被继承

```
成员方法:同成员变量，唯一的不同在于，private修饰成员方法，该成员方法不会被继承
```

## 2.4继承的特点

```
2.4.1Java只支持单继承，不支持多继承，但支持多层继承
2.4.2每一个类都直接或者间接的继承于Object类（默认继承类）
```

## 2.5继承中成员变量的访问特点

```
2.5.1继承中成员变量访问是就近原则
2.5.2变量重名搭配this和super使用
2.5.3间接父类的重名变量无法直接访问到
```

## 2.6继承中成员方法的访问特点

```
2.6.1this默认先找本类的，再找父类继承的
2.6.2super直接到父类中找
```

## 2.7继承中构造方法的特点

```
2.7.1子类不能继承父类的构造方法，但是可以通过super调用（如果构造函数不是private修饰）
2.7.2子类构造方法的第一行，有一个默认的super()，这是JVM的默认行为，可以自己手动指明即改变使用父类的某个构造而放弃使用父类默认构造
2.7.3默认先访问父类中无参的构造方法，再执行自己，如果父类的无参构造不可用如private权限，那么需要在子类的每一个构造函数中第一行明确指定需要调用的父类的构造寒素
2.7.4如果想要访问父类有参构造，需要将对应参数加到super()调用中，且要写在第一行
```

## 2.8this和super

### 2.8.1this:理解为一个变量，表示当前方法调用者的地址值

```
2.8.1.1this([params])//可以调用本类的其他构造方法
2.8.1.2this.var//优先访问本类的成员变量
2.8.1.3this.func()//优先访问本类的成员方法
```

### 2.8.2super:代表父类存储空间

```
2.8.2.1super([params])//可以显式调用父类的构造函数，要放在子类构造函数第一行，不适用于构造父类对象，如果要构造对象，还是得使用父类名，而不能用super
2.8.2.2super.var//调用父类的成员变量
2.8.2.3super.func()//调用父类的成员方法
```

# 3.多态

## 3.1多态格式

```
父类类型 对象名=子类对象;
```

## 3.2多态前提

```
3.2.1有继承/实现关系
3.2.2有父类引用指向子类对象
3.2.3有方法重写
```

## 3.3注意事项

```
3.3.1访问成员变量:编译看左边，运行看左边（如果父类有这个成员变量，且可以访问，那么可以编译通过，且运行时访问父类的成员变量，而不会访问子类的成员变量，即使子类中也定义了）
3.3.2访问成员方法:编译看左边，运行看右边（如果父类有这个成员方法，且可以访问，那么可以编译通过，且运行时优先在子类中寻找，如果子类重写了父类中的这个方法，调用子类的，否则调用父类的）
```

## 3.4多态的优势

```
3.4.1在多态形式下，右边对象可以实现解耦合，便于扩展和维护
3.4.2定义方法的时候，使用父类作为参数，可以接收所有子类对象，体现多态的扩展性与便利
```

## 3.5多态的弊端

```
3.5.1不能调用子类的特有功能。可以用强制转换转回子类，然后使用子类特有方法
3.5.2instanceof:用于判断一个对象是否是一个类的实例，如cat instanceof Cat，用于判断cat对象是不是Cat类实例，在jdk14中，加入了更方便的语法，即cat instanceof Cat c，如果cat是Cat类型实例，那么将cat转Cat类型的c
```

# 4.包、final、权限修饰符、代码块

## 4.1包:包就是文件夹，用来管理各种不同功能的java类

```
4.1.1包名的规则:公司域名反写+包的作用，需要全部英文小写，见名知意
4.1.2当不同包类名重复，使用时要用全类名即包名+类名
```

### 4.1.3使用其他类的规则

```
4.1.3.1使用同一个包中的类时，不需要导包
4.1.3.2使用java.lang包中的类时，不需要导包
4.1.3.3其他情况需要导包
4.1.3.4如果同时使用两个包中的同类名时，需要使用全类名
```

## 4.2final

```
4.2.1修饰方法:final修饰的方法不能重写
4.2.2修饰类:final修饰的类不能被继承
```

### 4.2.3修饰变量:final修饰的变量叫常量，只能被赋值一次，且定义时就必须初始化

```
4.2.3.1常量命名规范
4.2.3.1.1单个单词:全部大写
4.2.3.1.2多个单词:全部大写，单词之间用下划线隔开
4.2.3.2final修饰两种类型
4.2.3.2.1基本类型:变量存储的数据值不能发生改变
4.2.3.2.2引用类型:变量存储的地址值不能发生改变，对象内部的值可以改变
```

## 4.3权限修饰符:是用来控制一个成员能够被访问的范围的，可以修饰成员变量、方法、构造方法、内部类

```
4.3.1private:同一个类中可以
4.3.2缺省/默认/空着不写:同一个类中可以，同一个包中其他类可以
4.3.3protected:同一个类中可以，同一个包中可其他类可以，不同包下的子类可以
4.3.4public:同一个类可以，同一个包中其他类可以，不同包下的子类可以，不同包下的无关类可以
```

## 4.4代码块

### 4.4.1局部代码块:为了节约内存，早早销毁变量

```
局部代码块:为了节约内存，早早销毁变量
```

### 4.4.2构造代码块:写在成员位置的代码块，没有前后顺序的要求

```
4.4.2.1作用:可以把多个构造方法中重复的代码抽取出来
4.4.2.2执行时机:在创建对象时会优先执行构造代码块再执行构造方法，这样的方法不灵活
```

### 4.4.3静态代码块（静态初始化器）

```
4.4.3.1格式:static{<code>}
4.4.3.2需要通过static关键字修饰，随着类的加载而加载，并且自动触发，只执行一次
4.4.3.3使用场景:在类加载的时候，做一些数据初始化的时候使用
4.4.3.4注意:静态代码块只能使用静态成员
```

# 6.接口

## 6.1接口的定义和使用

```
6.1.1使用interface关键字定义
6.1.2接口不能实例化
6.1.3接口和类之间是是实现关系，通过implements关键字表示
6.1.4接口的子类（实现类）要么重写接口中所有抽象方法，要么是抽象类
6.1.5接口和类之间是实现关系，可以单实现，也可以多实现
6.1.6实现类还可以在继承一个类的同时实现多个接口
```

## 6.2接口中成员的特点

### 6.2.1成员变量

```
6.2.1.1只能是常量
6.2.1.2默认修饰符:public static final
```

### 6.2.2构造方法:没有

```
构造方法:没有
```

### 6.2.3成员方法

```
6.2.3.1只能是抽象方法
6.2.3.2默认修饰符:public abstract
6.2.3.3jdk7以前只能定义抽象方法，jdk8时接口可以定义有方法体的方法(称之为默认方法)，jdk9时可以定义私有方法
```

## 6.3接口和类之间的关系

```
6.3.1类和类的关系:只能单继承，不能多继承，但可以多层继承
6.3.2类和接口的关系:实现可以单实现，也可以多实现，还可以在继承一个类的同时实现多个接口（多个接口有重名方法只需要重写一次）
6.3.3接口和接口的关系:继承关系，可以单继承，也可以多继承
```

## 6.4jdk8开始接口中新增的方法

### 6.4.1默认方法

```
6.4.1.1允许在接口中定义默认方法（这在类中不支持），需要用关键字default修饰，这是为了解决接口升级的问题
6.4.1.2接口中默认的定义格式:public deault <ret_val_type> <func_name>(params){}//不可再加abstract
6.4.1.3注意事项
6.4.1.3.1默认方法不是抽象方法，所以不强制被重写，但是如果重写，重写的时候去掉default关键字
6.4.1.3.2public可以省略，但是default不能省略
6.4.1.3.3如果实现了多个接口，多个接口中存在相同名字的默认方法，子类就必须对该方法进行重写
```

### 6.4.2静态方法(jdk8)

```
6.4.2.1jdk8以后允许在接口中定义静态方法，需要用static修饰
6.4.2.2接口中静态方法的定义格式:public static <ret_val_type> <func_name>(params){<func_body>}
6.4.2.3注意事项
6.4.2.3.1静态方法只能通过接口名调用，不能通过实现类名或者对象名调用
6.4.2.3.2public可以省略，static不能省略
```

### 6.4.3私有方法（jdk9）

```
6.4.3.1默认私有方法:private <ret_val_type> <func_name>(params){}//给默认方法服务的（default修饰的方法）
6.4.3.2静态私有方法:private static <ret_val_type> <func_name>(params){}//给静态方法服务的（static修饰的方法）
```

## 6.5接口的应用

```
6.5.1接口是代表规则，是行为的抽象
6.5.2当一个方法是接口时，可以传递接口所有实现类的对象，这种方式称为接口多态
```

## 6.6适配器设计模式

```
6.6.1当一个接口中抽象方法过多，但是只需要用到其中一部分，那么就可以使用适配器设计模式
6.6.2做法:设计一个中间类***Adapter，实现对应的接口，对接口中的抽象方法进行空实现，并重写需要用的方法，为了避免其他类创建适配器的对象，中间的适配器类用abstract修饰
```

# 7.内部类

## 7.1内部类的访问特点

```
7.1.1内部类可以直接访问外部类的成员，包括私有
7.1.2外部类要访问内部类的成员，必须创建对象（创建内部类对象，再用内部类对象调用）
```

## 7.2内部类的分类

### 7.2.1成员内部类:写在成员位置的，属于成员外部类的成员

```
7.2.1.1书写
7.2.1.1.1书写在成员位置
7.2.1.1.2成员内部类可以被一些修饰符所修饰，如priavte、默认、protected、public、static等等
7.2.1.1.3在成员内部类里面，jdk16之前不能定义静态变量，jdk16开始才可以定义静态变量
7.2.1.2创建成员内部类的对象
7.2.1.2.1方式一:在外部类中编写方法（不能是静态方法，否则无法创建），对外提供内部类的对象
7.2.1.2.2方式二:外部类名.内部类名 对象名=外部类对象.内部类对象（直接创建格式，外内部对象用new创建，可以一次创建，也可以两次创建，即可以先<outer_class> <var_name1> = new <outer_class>();再<outer_class>.<inner_class> <var_name2> = <var_name1>.new <class_inner>();。还可以用一步完成，即<outer_class>.<inner_class> <var_name> = new <outer_class>().new <inner_class>();）
7.2.1.3成员内部类获取外部类的成员变量:当外部类和内部类成员变量或者局部变量重名时，使用<outer_class_name>.this.<var_name>即可（<outer_class_name>.this是一个隐含的指向外部类对象的指针，每个Inner对象创建都会有这么一个指针指向其对应的外部类对象）
```

### 7.2.2静态内部类:内部类用static修饰，静态内部类也是成员内部类中的一种

```
7.2.2.1注意:静态内部类只能访问外部类中的静态变量和静态方法，如果想要访问非静态的需要创建对象（创建外部类对象）
7.2.2.2创建静态内部类对象的格式:外部类名.内部类名 对象名=new 外部类名.内部类名()
7.2.2.3调用静态内部类中的方法的方式
7.2.2.3.1调用非静态方法的格式:先创建内部类对象，再通过对象调用
7.2.2.3.2调用静态方法的格式:直接通过<outer_class_name>.<inner_class_name>.<static_func_name>()即可调用，当然，通过对象调用也没错
```

### 7.2.3局部内部类

```
7.2.3.1将局部类定义到方法中的类叫做局部内部类，类似于方法中的局部变量（定义在静态方法中只能访问静态成员，在非静态方法中则可以访问全部）
7.2.3.2外界是无法直接使用，需要在方法内部创建对象使用
7.2.3.3该类可以直接访问外部类的成员，也可以访问方法内的局部变量
```

### 7.2.4匿名内部类（没有名字的局部内部类）:new \<class\_name\>/\<interface\_name\>(){\<rewrite\_func\>};//包含了继承或实现，以及重写，创建对象

## 9.3注意事项

```
9.3.1重写方法的名称、形参列表必须和父类中的保持一致
```
