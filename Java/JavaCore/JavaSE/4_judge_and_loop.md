# 2.分支结构

## 2.1if语句

### 2.1.1if(f){s}//大括号建议写行尾，只有一句可以省大括号

```
实践建议：即使只有一句代码，也强烈建议保留大括号，以增强代码的可读性和避免潜在的逻辑错误（如悬挂 else）。
```

### 2.1.2if(){}else{}

```
用于执行两个互斥的分支中的一个。
```

### 2.1.3if(){}else if(){}...else{}

```
用于处理多个互斥的条件分支，一旦其中一个条件满足，后续的条件将不再检查。
```

## 2.2switch:switch(f){case v1:s1;break; case v2:s2;break; ...default:s\_n;break;}

### 2.2.1f:将要匹配的值，取值为byte、short、int、char，jdk5以后可以是枚举，jdk7以后可以是String

```
注意：switch 语句不支持 long, float, double, boolean 类型作为匹配值。
```

### 2.2.2case:后面的值只能是字面量，不能是变量，且各个case后的值不相同，在多个值对应一个代码段时，可以用case穿透，且可以将多个case合并，值用','连接即可，这样就可以避免写多个case而对应一个代码块

```
**Case 穿透 (Fall-through) 机制：** 如果一个 case 代码块结尾没有 break 语句，程序将继续执行下一个 case 的代码，直到遇到 break 或 switch 结束。这是 switch 语句的经典特性，但也是常见的 bug 源头。
**JDK 13+ 新特性：** 支持使用逗号 `,` 连接多个 case 值，例如：`case v1, v2, v3: s; break;`
```

### 2.2.3deault:可以省略，不建议省略，位置不一定要放在最后

```
如果匹配不到任何 case，则执行 default 代码块。如果 default 省略且所有 case 均不匹配，则 switch 语句不执行任何操作。
```

### 2.2.4switch新特性（jdk12）:case后使用-\>，只能跟一条语句（其实可以用大括号包裹代码段，这样就可以实现-\>多行代码执行，但是大括号最后要用yield返回一个值），自动返回结果，不会造成case穿透

```
**JDK 14+ 完整特性 (Switch 表达式)：**
1.  使用 `->` 代替 `:`，简化了语法，并且默认不再穿透 (自动 break)。
2.  如果使用 `->` 后面跟多条语句，必须使用大括号 `{}` 包裹，并且需要使用 `yield` 关键字来返回一个值（如果 switch 作为表达式使用）。
3.  作为表达式使用时，可以直接赋值给一个变量。
```

# 3.循环结构

## 3.1for(;;){}:for条件不写默认为true，Java支持范围for循环（适用于实现了java.lang.Iterable接口类型对象或者是数组对象）

```
**增强型 for 循环 (Enhanced for loop/foreach)：** 格式为 `for(ElementType element : collectionOrArray){}`，专用于遍历数组或集合，优点是代码简洁，但无法获取当前元素的索引。
**普通 for 循环：** 适用于需要控制循环次数、需要索引或需要灵活控制循环变量变化的场景。
```

## 3.2while(){}

```
先判断条件，后执行循环体。适用于循环次数不确定，但需要在循环开始前进行条件判断的场景。
```

## 3.3do{}while();

```
先执行一次循环体，后判断条件。确保循环体至少执行一次。
```

# 4.continue

```
用于跳过当前循环体中 **continue 之后** 的代码，直接进入下一次循环的条件判断。
```

# 5.break

## 5.1break;

```
用于终止当前所在的 switch 语句或 **最近一层** 的循环（for, while, do-while）。
```

## 5.2break \<flag\>;//可以用于跳出多层循环（这个flag只能存在于代码块如label:{}或者循环语句之前如label:for(;;){}）扩展一些实用java内容

````
**Labeled Break (标签化 break)：** 用于跳出由标签（Label）标识的 **任意一层** 外部循环或代码块。
使用场景：当有多层嵌套循环时，需要从内层循环直接跳出到所有外层循环之外。
示例：
```java
outerLoop:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i * j == 4) {
            break outerLoop; // 直接跳出到标识为 outerLoop 的外部循环之外
        }
    }
}
```
**Labeled Continue (标签化 continue) 扩展：**
Continue 也可以配合标签使用。`continue <flag>;` 的作用是跳过当前内层循环的剩余部分，直接进入由 `flag` 标识的 **外层循环的下一次迭代** 的条件判断。
````
