# 1.方法的定义:程序中最小的执行单元

```
方法（Method），在某些编程语言中也称为函数（Function），是完成特定功能的代码块。
使用方法的目的：
1.  实现代码的模块化，便于组织和管理。
2.  实现代码的重用性，避免重复编写相同的逻辑。
```

# 2.方法的格式

## 2.1方法的定义:public static \<ret\_val\_type\> \<func\_name\>(params){scentence;...;return \<ret\_val\>;}//void无需return，如果写，那不能返回任何东西，方法不能嵌套定义，注意在return语句后不能写任何内容，不然会报错

```
**返回类型 (`<ret_val_type>`):** 指定方法执行完毕后返回的数据类型。如果方法不需要返回任何值，则使用 `void`。
**`return` 语句：**
1.  用于将方法执行的结果返回给调用者。
2.  一旦执行 `return`，方法立即结束，`return` 语句之后的任何代码（除了 finally 块）都是不可达代码，会导致编译错误。
3.  `void` 方法中可以有不带值的 `return;` 语句，用于提前结束方法。
**方法嵌套：** Java 不允许在方法内部定义另一个方法（方法不能嵌套定义）。
```

## 2.2方法的调用

```
调用格式：`方法名(实际参数列表);`
如果方法有返回值，通常需要使用一个同类型的变量来接收返回值，例如：`<ret_val_type> result = 方法名(参数);`
```

# 3.方法的重载:在同一个类中，同名的方法，形参不同（java不支持默认参数，所以只能通过方法重载实现了）

```
方法重载 (Overloading) 是指在同一个类中，可以定义多个名称相同但参数列表不同的方法。
**重载的判断依据（只需满足以下任意一条即可）：**
```

## 3.1不同的参数类型

```
例如：`add(int a, int b)` 和 `add(double a, double b)`
```

## 3.2不同的参数个数

```
例如：`sum(int a, int b)` 和 `sum(int a, int b, int c)`
```

## 3.3不同的参数顺序（不建议这种重载）

```
例如：`func(int a, String s)` 和 `func(String s, int a)`。虽然编译器允许，但会使代码难以阅读和维护。
**注意：** 方法的返回类型、权限修饰符（public/private等）和 static 关键字**不作为**重载的判断依据。
```

# 4.方法的内存

```
方法的调用和执行主要涉及 **栈内存**。每当一个方法被调用，JVM 就会为该方法在栈内存中创建一个独立的 **栈帧 (Stack Frame)**。
```

## 4.1方法调用的额基本内存原理

```
当方法被调用时，栈帧被推入栈顶；当方法执行完毕或遇到 return 语句时，栈帧被弹出，方法结束。
```

## 4.2方法传递基本数据类型的内存原理（基本数据类型有整数类型，浮点数类型，布尔类型，字符类型）

```
基本数据类型作为参数传递时，传递的是值的**副本** (Pass by Value)。
方法内对形参的修改，不会影响到方法外实参的值。
```

## 4.3方法传递引用数据类型的内存原理（new出来的都是引用数据类型）

```
引用数据类型作为参数传递时，传递的也是值的副本，但这个值是对象在堆内存中的**地址**（引用）。
因此，方法内可以通过这个地址对堆内存中的对象进行修改，修改会影响到方法外实参引用的对象。
```

# 5.二维数组

```
二维数组本质上是元素为**一维数组**的数组。它在逻辑上可以看作是一个矩阵或表格。
```

## 5.1定义格式

### 5.1.1完整格式:TYPE[][] \<array\_name\> = new TYPE[][]{{e1,e2,...},{e1,e2,...},...}//也可以TYPE \<array\_name\>[][] = ...;当然，[]在数组名前的方式更为规范。同时，和一维数组一样，可以省略new TYPE[][]

```
静态初始化，每个内部一维数组的长度可以不同（即**不规则**二维数组）。
```

### 5.1.2不初始化格式:TYPE \<array\_name\>[][] = new TYPE[size1][size2];//size2可以省略

```
**动态初始化：**
1.  `new TYPE[size1][size2]`：创建了一个规则的矩阵，`size1` 是行数，`size2` 是列数。
2.  `new TYPE[size1][]`：只确定了行数，内部的列数组需要后续单独创建，可以创建**不规则**数组。
```

### 5.1.3只定义格式:TYPE \<array\_name\>[][]

```
只声明了一个引用变量，未分配内存，需要后续初始化才能使用。
```

## 5.2元素访问

```
格式：`array_name[row_index][col_index]`
`array_name.length` 返回行数 (即一维数组的个数)。
`array_name[i].length` 返回第 `i` 行的列数 (即第 `i` 个一维数组的长度)。
```

# 6.可变参数

```
可变参数（Variable Arguments），使用 `...` 符号，允许方法接受**零个或多个**指定类型的参数。
```

## 6.1定义

```
<authority> <ret_val_type> <func_name>([..., ]<TYPE>...<var_naem>){
	<func_body>
}
例如：`public static int sum(int... numbers)`
```

## 6.2注意

```
6.2.1可变参数必须是方法参数列表中的最后一个
这是为了避免编译器在解析方法调用时产生歧义。
6.2.2可变参数会被转换为数组即var\_name是一个数组名
在方法内部，可变参数 `var_name` 被视为一个类型为 `<TYPE>[]` 的数组，可以使用数组的所有特性（如 `for` 循环遍历）。
6.2.3一个方法只能有一个可变参数
出于解析的唯一性考虑。
6.2.4传递空参数时，var\_name是一个空数组名
如果调用时没有传递任何参数，`var_name` 是一个长度为 0 的数组，而不是 `null`，这使得处理更加安全和方便。
```
