# 1.数组介绍

```
数组是一种引用数据类型，用于存储**相同类型**的多个数据。
数组是定长的，一旦创建，其长度不可改变。
数组中的每个元素都有对应的数字索引 (index)。
```

# 2.数组的定义和静态初始化

## 2.1定义

### 2.1.1格式一:TYPE [] \<array\_name\>

```
这是 Java 中推荐的定义方式，可读性更好。
```

### 2.1.2格式二:TYPE \<array\_name\>[]

```
这是 C/C++ 风格的定义方式，Java 也兼容，但不推荐。
```

## 2.2初始化

```
数组初始化后，其元素会自动获得默认值（数值类型为 0，布尔类型为 false，引用类型为 null）。
```

### 2.2.1TYPE [] \<array\_name\> = new TYPE[]{e1,e2,...}//完整格式

````
这称为**静态初始化**，在定义时指定了数组元素的值，由 JVM 自动确定数组长度。
例如：
```java
int[] numbers = new int[]{10, 20, 30};
```
````

### 2.2.2TYPE [] \<array\_name\> = {e1,e2,...}//简化格式

````
这是静态初始化的简化写法，只能在定义数组变量时使用。
例如：
```java
String[] names = {"Alice", "Bob", "Charlie"};
```
````

### 2.2.3TYPE [] \<array\_name\> = new TYPE[size];//size可以是变量

````
这称为**动态初始化**，只指定数组的长度，元素的值使用默认值。
例如：
```java
int size = 5;
double[] scores = new double[size];
```
````

# 3.数组元素访问

## 3.1格式:\<array\_name\>[index]

```
<array_name>[index]
```

## 3.2索引:从零开始

```
数组的索引从 0 开始，到 `数组长度 - 1` 结束。
```

# 4.数组遍历

## 4.1\<array\_name\>.length

````
`length` 是数组的属性，表示数组中元素的个数（即数组的长度）。
**普通 for 循环遍历：**
```java
for (int i = 0; i < array_name.length; i++) {
    System.out.println(array_name[i]);
}
```
**增强 for 循环 (foreach) 遍历：**
```java
for (TYPE element : array_name) {
    System.out.println(element);
}
```
````

# 5.数组动态初始化

```
在创建数组时只指定长度，由系统为数组元素分配默认值。适用于事先知道数组长度但不知道具体元素值的场景。
例如：`boolean[] flags = new boolean[10];` 此时所有元素均为 `false`。
```

# 6.数组内存图

```
数组对象本身存储在**堆内存**中，数组变量（引用）存储在**栈内存**中，该变量保存着堆内存中数组对象的地址。
```

# 7.数组常见问题

## 7.1初始化错误

### 7.1.1数组未初始化

```
如果只定义了数组变量而没有初始化（即没有 `new` 关键字分配堆内存），直接使用会导致编译错误或运行时 `NullPointerException`。
例如：`int[] arr; arr[0] = 1;` 会报错。
```

### 7.1.2数组用于初始化的size未初始化

```
动态初始化时，用于指定 size 的变量必须事先初始化或赋值。
```

## 7.2数组越界:抛出异常

```
当访问的索引值超出了 `[0, length - 1]` 的范围时，会抛出 `ArrayIndexOutOfBoundsException` 运行时异常。
```

## 7.3数组长度:length属性

```
`length` 属性是数组固定的，不可修改。
```

````
**获取最大/最小值：** 遍历数组，设置初始最大值/最小值。
**排序：** 使用 `java.util.Arrays.sort(array)` 方法进行快速排序。
**复制：**
```java
// 方式一：使用 Arrays.copyOf(original, newLength)
// 方式二：使用 System.arraycopy()
```
````

# 9.java内存发分配

## 9.1栈:方法运行时使用的内存，比如main方法运行，进入方法栈中执行

```
特点：存储局部变量、方法参数、以及对象的引用（地址）。遵循先进后出 (FILO)。生命周期短。
```

## 9.2堆:存储对象或者数组，new来创建的，都存储在堆内存

```
特点：存储所有通过 `new` 创建的实例对象和数组。是 Java 垃圾回收器 (GC) 关注的主要区域。
```

## 9.3方法区:存储可以运行的class文件

```
特点：存储类信息、静态变量、常量池等数据。
```

## 9.4本地方法栈:JVM在使用操作系统功能的时候使用

```
为 JVM 调用的 Native 方法服务。
```

## 9.5寄存器:给cpu使用

```
速度最快的存储区域。
```

# 10.数组共享内存，如int[] arr2 = arr1;

````
这是一种引用复制。`arr1` 和 `arr2` 都是栈中的引用变量，它们都指向堆内存中的**同一个数组对象**。
因此，通过 `arr2` 修改数组中的元素，会影响到通过 `arr1` 访问的结果。
例如：
```java
int[] arr1 = {1, 2, 3};
int[] arr2 = arr1;
arr2[0] = 99;
// 此时 arr1[0] 也是 99
```
````
