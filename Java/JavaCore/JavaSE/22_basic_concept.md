# 2.关键字

```
关键字：关键字的字母全部小写（如 public, class, void, if, else 等）。
```

# 3.字面量

## 3.1字面量的作用

```
字面量的作用: 指明数据在程序中的书写格式。
```

## 3.2字面量类型

```
3.2.1整数类型（如 10, 100）
3.2.2小数类型（如 3.14, 0.5）
3.2.3字符串类型: 用双引号引起来（如 "hello"，可以用 + 连接两个字符串类型字面量）
3.2.4字符类型: 用单引号引起来（如 'A', '1'，只能包含单个字符）
3.2.5布尔类型: true 和 false
3.2.6空类型: null（只能赋值给引用数据类型）
```

# 4.变量

## 4.1格式

```
数据类型 变量名 = 数据值;
```

## 4.2主意事项

```
4.2.1只能存一个值
4.2.2变量名不允许重复定义
4.2.3一条语句可以定义多个变量（但不推荐）
4.2.4变量在使用之前一定要进行赋值（初始化）
4.2.5变量的作用域范围（通常为其所在的一对花括号 {} 内）
```

# 5.进制

```
5.1二进制: 在代码中由 0 和 1 组成，代码中以 0b 开头（如 0b1010）
5.2十进制: 由 0~9 组成，没有前缀（如 10）
5.3八进制: 由 0~7 组成，代码中以 0 开头（如 012）
5.4十六进制: 由 0~9 还有 a~f 组成，代码以 0X 开头（如 0XF 或 0xa3）
```

# 6.基础语法

## 6.1数据类型

### 6.1.1基本数据类型

```
6.1.1.1byte (1字节)
6.1.1.2short (2字节)
6.1.1.3int (4字节)
6.1.1.4long (8字节): 在定义并赋值时，值后使用 L，且最好是大写的（如 100L）
6.1.1.5float (4字节): 在定义并赋值时，字面量后要加 f，可以是大写的（如 3.14F）
6.1.1.6double (8字节)
6.1.1.7char (2字节): 只能赋值正数（0~65535，对应 Unicode 字符）
6.1.1.8boolean: true 和 false
```

### 6.1.2引用数据类型

```
引用数据类型（如类、接口、数组等）
```

## 6.2标识符:类、方法、变量等的名字

### 6.2.1规则

```
6.2.1.1由数字、字母、下划线 (_)、美元符 ($) 组成
6.2.1.2不能以数字开头
6.2.1.3不能是关键字
6.2.1.4区分大小写
```

### 6.2.2规范

```
6.2.2.1小驼峰命名法: 一个单词时全小写，多个单词仅仅第一个单词首字母小写，其他单词首字母大写，适用于方法和变量（如 variableName, runMethod）
6.2.2.2大驼峰命名法: 所有单词首字母大写，适用于类名（如 ClassName, MyFirstClass）
```

## 6.3键盘录入

```
6.3.1导包: import java.util.Scanner; // 必须要写在类定义的上面
6.3.2创建对象: Scanner <obj_name> = new Scanner(System.in);
6.3.3接受数据: <var_name> = <obj_name>.next***(); // 例如 nextInt(), nextLine(), nextDouble()
```
