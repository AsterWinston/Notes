# 1.IO流分类

## 1.1按照流的方向

```
1.1.1输入流（从数据源读取数据，如 `InputStream`, `Reader`）
1.1.2输出流（向数据目标写入数据，如 `OutputStream`, `Writer`）
```

## 1.2按操作文件类型

### 1.2.1字节流

```
1.2.1.1InputStream（字节输入流的基类）
1.2.1.2OutputStream（字节输出流的基类）
```

### 1.2.2字符流（只用于纯文本文件）

```
1.2.2.1Reader（字符输入流的基类）
1.2.2.2Writer（字符输出流的基类）
```

# 2.FileOutputStream（继承于OutputStream）

## 2.1构造方法（参数是字符串或者File对象，如果文件不存在会自动创建，但是要保证父级路径存在）

```
2.1.1public FileOutputStream(String name[, boolean append])// append 为 true 时追加写入
2.1.2public FileOutputStream(File file[, boolean append])// append 为 true 时追加写入
```

## 2.2成员方法

```
2.2.1public void write(int b)throws IOException{}//写入参数 b 的低 8 位。Windows 换行 \r\n，Linux 换行 \n，Mac 换行 \r。
2.2.2public void close() throws IOException{}//关闭流并释放资源，如果有多个 IO 流对象，遵循“先开的后关”原则
2.2.3public void write(byte[] b)...{}//写入整个字节数组
2.2.4public void write(byte[] b, int off, int len)...{}//从 off 索引开始，写入 len 个字节
```

# 3.FileInputStream（继承于InputStream）

## 3.1构造方法

```
3.1.1public FileInputStream(File file) throws FileNotFoundException{}
3.1.2public FileInputStream(String name) throws FileNotFoundException{}
```

## 3.2成员方法

```
3.2.1public int read() throws IOException{}//读取单个字节，返回 0 到 255 范围内的整数值（-1 表示读到结尾）
3.2.2public void close() throws IOException{}
3.2.3public int read(byte b[]) throws IOException{}//读取数据到字节数组 b，返回值为读取到的个数，一个也读不到返回 -1
```

# 11.序列化流

## 11.1ObjectInputStream（实际上是 ObjectOutputStream）

### 11.1.1构造方法

```
11.1.1.1public ObjectOutputStream(OutputStream out)
```

### 11.1.2成员方法

```
11.1.2.1public final void writeObject(Object obj)//把对象序列化到文件中去（仅仅序列化非 static 和非 transient 修饰的成员变量），注意要写入的对象的类要实现 Serializable 接口（标记性接口）
```

## 11.2ObjectOutputStream（实际上是 ObjectInputStream）

### 11.2.1构造方法

```
11.2.1.1public ObjectInputStream(InputStream in)
```

### 11.2.2成员方法

```
11.2.2.1public Object readObject()//从流中读取对象
```

## 11.3序列号

```
要将一个对象序列化到本地文件中，除了要实现 Serializable 接口外，还需要给类加上序列化版本号，例如 `private static final long serialVersionUID = nL;`。如果不加，Java 自动生成，当修改类时可能导致版本号不一致，反序列化失败。
```

## 11.4transient

```
transient：让某个成员变量在序列化时不序列化到文件中，给该成员变量加上 transient 关键字即可，反序列化后该成员变量将为默认值（如 null 或 0）。
```

# 12.打印流

## 12.1PrintStream（继承于FileOutputStream）

### 12.1.1构造方法

```
12.1.1.1public PrintStream(OutputStream/File/String)
12.1.1.2public PrintStream(String fileName, Charset charset)//指定字符编码
12.1.1.3public PrintStream(OutputStream out, boolean autoFlush)//自动刷新（字节流底层没有缓冲区，所以开不开自动刷新都一样）
12.1.1.4public PrintStream(OutputStream out, boolean autoFlush, String encoding)//指定字符编码并且自动刷新
```

### 12.1.2成员方法

```
12.1.2.1public void write(...)//继承自父类，不具备打印流特有的便捷功能
12.1.2.2public void println(...)//写入任意数据，自动刷新，自动换行，如果是对象，则底层调用 toString() 方法，将这个方法的返回值写入文件，print() 同理
12.1.2.3public void print(...)//写入任意数据，不换行
12.1.2.4public void printf(String format, Object...args)//带有占位符的打印语句，不换行
```

## 12.2PrintWriter（继承于Writer）

### 12.2.1构造方法

12.2.1.4public PrintWriter(OutputStream out, boolean autoFlush, Charset charset)//通过 OutputStream 构造，指定编码和自动刷新
