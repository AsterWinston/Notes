# 2.自增自减运算符

## 2.1前置自增

```
先对变量自身进行 +1 运算，然后将 **新值** 用于表达式计算。
例如：int a = 5; int b = ++a; // 此时 a 是 6, b 也是 6
```

## 2.2后置自增

```
先将变量 **原值** 用于表达式计算，然后变量自身再进行 +1 运算。
例如：int a = 5; int b = a++; // 此时 b 是 5, a 是 6
```

## 2.3前置自减

```
先对变量自身进行 -1 运算，然后将 **新值** 用于表达式计算。
```

## 2.4后置自减

```
先将变量 **原值** 用于表达式计算，然后变量自身再进行 -1 运算。
```

# 5.逻辑运算符

## 5.1&&和&:与//两个&&有短路效果，一个则没有

```
&& (短路与)：如果左侧表达式结果为 false，则右侧表达式不再执行（短路），直接判定整个表达式为 false。
& (非短路与)：无论左侧结果如何，右侧表达式都会被执行。
实用建议：在大多数情况下，推荐使用 **&&** 以提高效率和避免不必要的副作用。
```

## 5.2||和|:或//两个||有短路效果，一个则没有

```
|| (短路或)：如果左侧表达式结果为 true，则右侧表达式不再执行（短路），直接判定整个表达式为 true。
| (非短路或)：无论左侧结果如何，右侧表达式都会被执行。
实用建议：在大多数情况下，推荐使用 **||** 以提高效率和避免不必要的副作用。
```

# 6.三元运算符:formula?f1:f2

```
语法：条件表达式 ? 表达式1 : 表达式2;
说明：条件表达式必须是 boolean 类型。表达式1 和 表达式2 的结果类型必须兼容。
用途：是 if-else 结构的一种简洁写法，常用于简单的赋值操作。
例如：int max = (a > b) ? a : b;
```

# 7.运算符优先级

```
实用建议：为了避免因优先级不明确而导致的错误和提高代码可读性，**强烈建议使用括号 ()** 来明确运算的先后顺序。
基本优先级顺序（从高到低）：
1. 括号 ()
2. 后置自增自减 (a++, a--)
3. 前置自增自减 (++a, --a), 逻辑非 (!), 强制类型转换
4. 乘除模 (*, /, %)
5. 加减 (+, -)
6. 关系运算符 (<, >, <=, >=)
7. 相等运算符 (==, !=)
8. 逻辑与 (&&), 逻辑或 (||)
9. 三元运算符 (?:)
10. 赋值运算符 (=, +=, -=, ...)
```

## 8.4\<\<:左移，低位补0

```
实用：左移 N 位相当于乘以 $2^N$。例如：a << 3 相当于 a * 8。
```

## 8.5\>\>:符号右移，高位补0或1（高0补0，高1补1）

```
实用：右移 N 位相当于除以 $2^N$，对于正数和负数，其结果是向下取整。
```

## 8.6\>\>\>:无符号右移，高位补0

```
实用：常用于将负数的二进制表示转换为正数，或处理 Java 中没有的无符号整数类型。
```

## 8.7\~:按位取反

```
实用：~a 等于 $-(a+1)$。例如：~10 的结果是 -11。
```
