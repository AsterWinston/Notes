# 2. assert

```
用于调试，检查某个条件是否为 true，若为 false，抛出 AssertionError。一般在开发中使用，生产环境中可禁用。格式如assert <condition>[:<expr>]，其中expr可以是任意类型
```

# 16. enum

```
用于定义枚举类型，枚举是一组常量的集合。enum定义可以有成员变量和成员函数以及构造函数，如
enum Direction {
    NORTH(0), EAST(90), SOUTH(180), WEST(270);
    private int degree;
    Direction(int degree) {
        this.degree = degree;
    }
    public int getDegree() {
        return degree;
    }
}
```

# 40. strictfp

```
用于限制浮点运算的精度，保证不同平台上浮点数运算结果的一致性。用于类、接口、函数上，确保所有浮点数的计算遵循严格的标准（IEEE 754），这样无论在哪个平台上运行，浮点运算的结果都是一致的。
```

# 50. volatile

```
用于定义一个变量，表明该变量可能会被多个线程同时访问，因此禁止对该变量进行优化。volatile 是 Java 中用于声明变量的关键字，表示该变量可能会被多个线程同时访问，因此禁止对该变量进行优化。它确保每次读取该变量时都会从主内存中获取最新值，而不是从 CPU 缓存中获取。
```
