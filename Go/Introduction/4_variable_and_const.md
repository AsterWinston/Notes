变量与常量是任何语言的基础，但 Go 在这一层有几个独特设计：零值机制（杜绝未初始化变量）、短变量声明（`:=`）、以及用 `iota` 优雅实现枚举。理解它们能让你写出更符合 Go 惯用法的代码。

# 1. 变量声明

## 1.1 四种声明方式

```go
// 1. 标准声明（显式类型）
var age int
var name string = "tom"

// 2. 类型推断（省略类型，编译器从值推断）
var name = "tom"

// 3. 短变量声明（只能在函数内使用，最常用）
name := "tom"

// 4. 批量声明
var (
    a int
    b string = "hello"
    c bool
)
```

★ **关键认知**：`:=` 短变量声明**只能用在函数体内部**，包级变量必须用 `var`。这是新手最常见的编译错误来源：`syntax error: non-declaration statement outside function body`。

## 1.2 短变量声明的重声明规则

```go
x := 1
x := 2        // 错误：同一作用域内重复声明

// 但多变量短声明中，只要有一个新变量，就能"重声明"旧变量：
x, y := 1, 2
x, z := 3, 4  // 合法：z 是新变量，x 被重新赋值
```

★ **关键认知**：`:=` 的"重声明"只在**至少引入一个新变量**且**类型不变**时允许。这保证了代码简洁，同时避免意外覆盖。理解这条规则对读懂 Go 里大量 `err :=` 与 `x, err :=` 的混用至关重要。

# 2. 零值机制

## 2.1 零值表

★ **关键认知**：Go 中**声明即初始化**——所有变量声明后都会被自动赋予对应类型的零值，不存在"未初始化变量"。

| 类型 | 零值 |
|------|------|
| 数值（int/float 等） | 0 |
| bool | false |
| string | ""（空串） |
| 指针 / 函数 / 接口 / map / slice / channel | nil |

```go
var i int        // 0
var s string     // ""
var p *int       // nil
var m map[string]int   // nil（但 nil map 不能直接赋值，见 map 章节）
```

★ **关键认知**：零值是 Go 的安全基石。C/C++ 里读未初始化变量是著名的 UB（未定义行为），Go 通过"声明即零值"从语言层面消除了整类 bug。这也解释了为什么 Go 不需要构造函数——变量天然有一个"合法"的初始状态。

# 3. 常量

## 3.1 const 声明

```go
const pi = 3.14159
const (
    StatusOK   = 200
    StatusFail = 500
)
```

## 3.2 常量的特性

```
1. 常量必须在编译期确定值，只能是基本类型（string/bool/数值）
2. 常量可以无类型（untyped），赋值时才决定类型
3. 常量不能取地址（&pi 非法，因为常量没有存储位置）
```

★ **关键认知**：Go 常量默认是**无类型**的，直到被使用。这带来极大灵活性：`const x = 1` 既可以当 `int` 用，也可以当 `float64` 用，还能参与需要显式类型的场景。只有当它被赋给具体变量或传入具体类型参数时，才隐式转成目标类型。

# 4. iota —— 枚举生成器

## 4.1 基本用法

```go
const (
    Sunday = iota   // 0
    Monday          // 1
    Tuesday         // 2
    Wednesday       // 3
    Thursday        // 4
    Friday          // 5
    Saturday        // 6
)
```

★ **关键认知**：`iota` 是**行计数器**——在每个 `const` 块内从 0 开始，每出现一行（无论是否显式使用 iota）自动加 1。省略右侧表达式时，会自动继承上一行的表达式。

## 4.2 iota 的高级技巧

```go
// 位掩码（每项左移一位）
const (
    FlagRead  = 1 << iota  // 1
    FlagWrite              // 2
    FlagExec               // 4
)

// 跳过一个值
const (
    A = iota   // 0
    _          // 1（跳过）
    B          // 2
)

// 自增计数器
const (
    _  = iota        // 丢弃 0
    KB = 1 << (10 * iota)  // 1<<10 = 1024
    MB                  // 1<<20
    GB                  // 1<<30
)
```

# 5. 作用域与生命周期

## 5.1 作用域层次

```
Go 的作用域：
1. 文件块级：import 的包名
2. 包块级：包级变量、函数、常量
3. 函数块级：函数参数、函数内声明的变量
4. 语句块级：if/for/switch 的花括号内
```

★ **关键认知**：Go 是**词法作用域**（静态作用域），变量在哪个花括号内声明就在哪个块可见。内层作用域可以遮蔽（shadow）外层同名变量，编译器不会报错——这是常见 bug 来源，可用 `go vet` 的 `shadow` 检查器辅助发现。

## 5.2 逃逸分析预告

★ **关键认知**：变量的"生命周期"不完全等同于"作用域"。编译器通过**逃逸分析**判断一个变量该分配在栈上还是堆上（见内存章节）。一个"局部"变量如果被闭包引用、或返回其指针，就会"逃逸"到堆上，生命周期随之延长到 GC 回收为止。

# 6. 小结

| 概念 | 要点 |
|------|------|
| 声明 | var / := / 批量声明 |
| := | 仅函数内，至少一个新变量可重声明 |
| 零值 | 声明即初始化，杜绝未初始化变量 |
| const | 编译期常量，默认无类型 |
| iota | const 块内行计数器，实现枚举 |
| 作用域 | 词法作用域，内层可遮蔽外层 |
